## Notas da plataforma

O Claude Code se conecta usando o protocolo compatível com Anthropic. Se o cliente oferecer campos personalizados de Base URL / API Key, preencha-os com as informações acima; a URL base é `https://api.fishxcode.com`. Se o cliente exigir um endereço completo, acrescente caminhos como `/v1/messages`.
