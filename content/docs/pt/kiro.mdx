O Kiro se conecta usando o protocolo compatível com OpenAI. Se o cliente oferecer campos personalizados de Base URL / API Key, preencha-os com as informações acima; se ele aceitar apenas endpoints compatíveis com OpenAI, verifique se a URL inclui `/v1`.
