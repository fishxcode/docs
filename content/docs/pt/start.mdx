## 1. Preparação do ambiente

### Instalar o Node.js

O Claude Code é instalado via npm; primeiro confirme que o Node.js está pronto.

```bash tab="macOS - Verificar"
node -v
npm -v
```

```bash tab="macOS - Instalar via Homebrew"
brew install node
```

```bash tab="Windows - Verificar (CMD/PowerShell)"
node -v
npm -v
```

Se não estiver instalado, baixe o instalador da sua plataforma em [nodejs.org/zh-cn/download](https://nodejs.cn/download/current/). Após instalar, **o Windows precisa ser reiniciado**.

### Passo extra no Windows: instalar o Git Bash

O Claude Code depende de um ambiente bash; usuários Windows precisam instalar o Git Bash:

1. Download: [git-scm.com/install/windows](https://git-scm.com/install); escolha a versão correspondente e instale.
2. Verificação: clique com o botão direito na área de trabalho; se aparecer a opção **Open Git Bash here**, a instalação foi bem-sucedida.

## 3. Configurar o FishXCode

1. Digite `npx zcf` no terminal e pressione Enter para executar.
   Quando aparecer `Ok to proceed? (y)`, digite `y` e pressione Enter.

2. Escolha o idioma de exibição do ZCF:
   selecione **简体中文**.

3. Após a instalação, escolha:
   `1. Inicialização completa - Instalar Claude Code + importar workflows + configurar API ou proxy CCR + configurar serviços MCP`

4. Deseja alterar a configuração de idioma dos templates:
   escolha `No`

5. Idioma de saída da IA:
   escolha `简体中文`

6. Deseja instalar o Claude:
   escolha `Yes`

7. Modo de configuração da API:
   escolha `Configuração de API personalizada`

8. Provedor da API:
   escolha `Configuração personalizada`

9. Nome da configuração:
   um nome personalizado em inglês

10. Tipo de autenticação:
    escolha `API Key`

11. URL base da API:
    ```
    https://api.fishxcode.com
    ```
    <Callout type="idea" title="Endereço de acesso">
      `https://api.fishxcode.com` e `https://fishxcode.com` podem ser usados como endereço de acesso; ambos se comportam da mesma forma — escolha qualquer um.
    </Callout>

12. Chave da API:
    informe a API Key criada no console do FishXCode (Console → Chaves API)

13. Configurações relacionadas ao modelo:
    basta pressionar Enter para pular (padrão)

14. Tipo de workflow:
    escolha `Ferramentas gerais`

15. Estilo de saída:
    escolha conforme sua preferência

16. Deseja configurar MCP:
    escolha `Yes`

17. Serviços MCP:
    selecione os serviços desejados com a barra de espaço e pressione Enter para executar

18. Configurar CCometixLine:
    apenas pressione Enter

19. De volta ao menu principal, digite:
    ```
    q
    ```

20. Digite no terminal:
    ```
    claude
    ```
    - escolha `Yes, I trust this folder`
- na escolha da API, selecione obrigatoriamente **YES (a primeira)**

## 5. Troca de modelos

Na interface de conversa do Claude Code, digite `/model` para trocar de modelo:

| Opção | Modelo real | Descrição |
| - | - | - |
| **Default** | `claude-fable-5-2` + `claude-haiku-5-5` | Escolha automática conforme a tarefa; recomendado para uso diário |
| **Opus** | `claude-opus-5-5` | Raciocínio mais poderoso; consumo mais alto |
| **Haiku** | `claude-haiku-5-5` | Leve e rápido |

Também é possível fixar o modelo por variável de ambiente:

```bash tab="macOS/Linux"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL="claude-fable-5-2"
claude
```

<Callout type="idea" title="Atualizar o Claude Code">
  Se a versão do modelo não estiver atualizada, execute o comando de atualização e reinicie as ferramentas relacionadas:

  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
</Callout>

## 6. Integração com IDEs

### IntelliJ IDEA

Caminho: Arquivo → Configurações → Plugins → Marketplace → pesquise `claude code`, localize o **Claude Code Terminal** e instale:

![Instalar Claude Code Terminal](/img/start/idea-01-install.png)

Após instalar, reinicie o IDEA e verifique se o plugin foi carregado:

![Verificar carregamento do plugin](/img/start/idea-02-verify.png)

<Callout type="info">
  Se o plugin não aparecer no marketplace, a versão atual do IDEA está muito antiga e precisa ser atualizada para a mais recente.
</Callout>

### VSCode

Pressione `Ctrl + Shift + X` para abrir o painel de extensões, pesquise `claude code` e instale o **Claude Code for VSCode**.

![Pesquisar e instalar o plugin Claude Code](/img/start/vscode-01-install.png)

Após a instalação, o plugin oferece três formas de conexão:

![Formas de conexão do plugin Claude Code](/img/start/vscode-02-login.png)

Recomendamos conectar ao FishXCode via `settings.json`. Clique no **ícone de engrenagem** no canto inferior direito do plugin → **Editar em settings.json**:

![Abrir settings.json para editar](/img/start/vscode-03-settings.png)

Adicione ao `settings.json` do VSCode:

```json
{
  "claudeCode.preferredLocation": "panel",
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "substitua pela sua API Key" },
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.fishxcode.com/" }
  ]
}
```

<Callout type="idea" title="Endereço de acesso">
  No `ANTHROPIC_BASE_URL` também é possível usar `https://fishxcode.com/`; os dois endereços se comportam da mesma forma — escolha qualquer um.
</Callout>

![Exemplo de configuração no settings.json](/img/start/vscode-04-config.png)

Depois de salvar, **feche e reabra o VSCode**; o plugin passará a se conectar normalmente ao FishXCode.

![Usando Claude Code no VSCode](/img/start/vscode-05-demo.gif)

## 7. Perguntas frequentes

### Erro 403

Saldo insuficiente; recarregue no console e tente novamente.

### Erro de conexão anormal ou 400/401 no Windows

Execute novamente o comando `setx` no PowerShell para gravar as variáveis de sistema e reabra o terminal:

```powershell
setx ANTHROPIC_AUTH_TOKEN "sk-xxx"
setx ANTHROPIC_BASE_URL "https://api.fishxcode.com/"
```

### Mensagem "Unable to connect to Anthropic services"

O erro completo é:

```
Unable to connect to Anthropic services
Failed to connect to api.anthropic.com: ERR_BAD_REQUEST
Please check your internet connection and network settings.
```

Isso acontece porque o Claude Code ainda não concluiu o onboarding e continua tentando conectar ao `api.anthropic.com` oficial. **Não é necessário VPN**. Basta adicionar `"hasCompletedOnboarding": true` ao final do arquivo `~/.claude.json` (atenção: é o `.claude.json` no diretório home, não o `.claude/settings.json`):

```json
{
  "installMethod": "unknown",
  "autoUpdates": true,
  "projects": { ... },
  "hasCompletedOnboarding": true
}
```

<Callout type="idea">
  Ao adicionar, atenção à vírgula no final do campo anterior (exigência da sintaxe JSON). Após a alteração, execute `claude` novamente e a conexão funcionará normalmente.
</Callout>
