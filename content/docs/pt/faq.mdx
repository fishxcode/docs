## Geral

### O que é o FishXCode?

O FishXCode é uma plataforma de acesso a modelos de IA e serviços de contas tudo-em-um, cobrindo Claude, Codex, Kiro, Grok, modelos chineses e multimodais, utilizável em diversas ferramentas e plataformas.

### Quais ferramentas são suportadas?

Atualmente as seguintes ferramentas são suportadas:

- **Claude Code** — CLI oficial da Anthropic
- **OpenAI Codex** — assistente de programação oficial da OpenAI
- **RooCode** — plugin de programação com IA para VS Code
- **Qwen Code** — ferramenta de programação do Qwen (Tongyi Qianwen) da Alibaba
- **Droid CLI** — CLI leve de programação com IA
- **OpenCode** — ferramenta de terminal de programação com IA de código aberto

### Como a privacidade dos dados é garantida?

O FishXCode atua apenas como serviço de retransmissão de API e não armazena seu código nem o conteúdo das conversas. Todas as requisições são encaminhadas diretamente ao provedor do modelo correspondente.

<Callout type="idea" title="Recomendação">
  Para projetos sensíveis, recomendamos ler as políticas de privacidade de cada provedor de modelo antes de usar.
</Callout>

## Conta e API Key

### Como me registrar?

Acesse [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW), preencha nome de usuário, senha e e-mail, e digite o código de verificação recebido por e-mail para concluir o registro. Também é possível fazer login diretamente por autorização de terceiros com GitHub / LinuxDO / Google (a conta é criada automaticamente na primeira autorização).

<Callout type="idea" title="Domínios de e-mail suportados">
  O registro por e-mail atualmente suporta apenas quatro domínios: **qq.com, 126.com, 163.com, gmail.com**.
</Callout>

### Como obter a API Key?

Após o registro, faça login no console e acesse a [página de Chaves API](https://fishxcode.com/keys) para criar uma nova API Key.

### Quais formas de recarga são aceitas?

Acesse **Console → Carteira** para recarregar. Formas aceitas:

- **Alipay**: método mais comum, sem valor mínimo
- **Waffo Pancake**: recarga mínima de $100
- **Código de resgate**: insira na área de resgate de cota da página da carteira

### Qual é a validade da API Key?

A chave permanece válida até ser excluída manualmente ou regenerada. Recomenda-se rotacioná-la periodicamente por segurança.

### Qual é a cota de uso?

O FishXCode fornece uma cota de uso para cada usuário; o valor exato é ajustado dinamicamente conforme os recursos da plataforma. Acompanhe as informações de uso no console.

<Callout type="warn" title="Atenção">
  Quando a cota se esgota, as requisições são recusadas; planeje seu uso com moderação.
</Callout>

## Configuração de ferramentas

### Defini variáveis de ambiente mas não surtem efeito. O que verificar?

Verifique as causas comuns a seguir:

1. **Terminal não reiniciado** — após editar `.bashrc` / `.zshrc`, é necessário executar `source ~/.bashrc` ou abrir um novo terminal
2. **Nome da variável digitado errado** — atente para maiúsculas e minúsculas; por exemplo, `ANTHROPIC_BASE_URL` não pode ser escrito como `Anthropic_Base_Url`
3. **Aspas ou espaços em excesso** — em `export KEY="value"`, não deixe espaços extras antes ou depois de value

<Accordions type="single">
  <Accordion title="Comando de diagnóstico rápido">
    ```bash
    # Verificar se as variáveis estão definidas
    echo $ANTHROPIC_BASE_URL
    echo $ANTHROPIC_AUTH_TOKEN

    # Se estiverem vazias, significa que as variáveis não surtiram efeito
    ```
  </Accordion>
</Accordions>

### Onde ficam os arquivos de configuração?

| Ferramenta | Caminho do arquivo de configuração |
| - | - |
| Claude Code | configuração via variáveis de ambiente |
| Codex | `~/.codex/config.toml` e `~/.codex/auth.json` |
| RooCode | JSON de configurações do VS Code |
| Qwen Code | configuração via variáveis de ambiente |

### Não consigo conectar ao serviço do FishXCode. O que fazer?

1. Confirme que `BASE_URL` está definido como `https://api.fishxcode.com/` ou `https://fishxcode.com/` (ambos funcionam, comportamento idêntico)
2. Verifique se a rede consegue acessar `fishxcode.com`
3. Em redes corporativas, confirme se as configurações de proxy estão corretas

## Escolha de modelos

### Como escolher o modelo adequado?

Escolha conforme o cenário de uso:

| Cenário | Modelo recomendado | Motivo |
| - | - | - |
| Programação diária | `claude-fable-5-2` | Equilíbrio entre capacidade e velocidade |
| Autocompletar rápido | `claude-haiku-5-5` | Tempo de resposta curto |
| Arquiteturas complexas | `claude-fable-5-2` | Forte capacidade de raciocínio |

### Quais as diferenças entre os modelos?

- **Série Sonnet**: capacidade abrangente, adequada para a maioria das tarefas de programação
- **Série Haiku**: leve e rápida, adequada para autocompletar e tarefas de formatação simples
- Para diferenças detalhadas de capacidade, consulte a documentação oficial de cada provedor

### Como trocar de modelo?

Especifique pela variável de ambiente `ANTHROPIC_MODEL`:

```bash
export ANTHROPIC_MODEL=claude-fable-5-2
```

## Solução de problemas

### Mensagem de falha de autenticação (Auth Error)

<Callout type="warn" title="Causas comuns">
  - Chave digitada incorretamente (espaços extras ou incompleta)
  - Chave já excluída ou regenerada
  - `API_KEY` e `AUTH_TOKEN` não definidos simultaneamente
</Callout>

Solução: acesse a [página de Chaves API](https://fishxcode.com/keys), confirme o estado da chave e copie/cole novamente.

### Como ver e interpretar os logs de erro?

Acesse [Console → Logs de uso](https://fishxcode.com/usage-logs/common), altere o tipo de log para **Logs de erro** e filtre por hora, modelo, chave, grupo, ID de requisição, mensagem de erro e código de status.

<Callout type="idea" title="Dicas de diagnóstico">
  - Copie primeiro o `request_id` da resposta da API ou do log e pesquise-o com precisão nos logs de uso para localizar a mesma requisição
  - Use "mensagem de erro" para buscar palavras-chave no `content`, por exemplo `Invalid token`, `Upstream request failed`
  - Use "código de status" para agregar rapidamente os tipos de problema, por exemplo `400`, `401`, `403`, `413`, `429`, `500`, `502`, `503`, `504`
  - Se o mesmo erro se concentrar em um mesmo grupo, avalie primeiro pelo grupo se se trata de problema de configuração, de uso ou de disponibilidade do upstream
</Callout>

Para a descrição completa dos campos, classificação de códigos de status e tabela de erros comuns, veja [Explicação dos logs de erro](/pt/error-logs).

### Como avaliar o alcance de um problema de grupo?

Nos [Logs de uso](https://fishxcode.com/usage-logs/common), filtre por grupo e observe se os erros se concentram no mesmo grupo: falhas isoladas costumam ser anomalias pontuais; o mesmo erro se repetindo em um mesmo grupo indica que o pool de recursos dele esta afetado — tente mais tarde ou troque de grupo, e use o `request_id` para localizar requisições específicas.

Para a descrição dos campos, as categorias de códigos de status e a tabela de erros comuns, veja [Explicacao dos logs de erro](/pt/error-logs).

### Tempo limite da requisição (Timeout)

Causas possíveis:

1. Latência de rede muito alta
2. Contexto da requisição muito longo, o modelo leva mais tempo para processar
3. Carga do serviço no momento está alta

Recomendação: reduza o contexto de entrada ou tente novamente mais tarde.

### Limite de frequência ou de cota atingido (Rate Limit)

Receber o código de status `429` geralmente indica requisições demais em pouco tempo; também pode indicar que a cota diária da conta de upstream se esgotou ou que a credencial do modelo atual está em cooldown.

<Callout type="idea" title="Como lidar">
  - Reduza a frequência de requisições e tente novamente após alguns segundos
  - Evite loops sem intervalo chamando a API em scripts
  - Verifique se outro processo está usando a mesma chave simultaneamente
  - Se o log contiver `Max 10/min` ou `Max 5/min`, siga a orientação e reduza a concorrência e as requisições por minuto abaixo do limite
  - Se o log contiver `daily limit exceeded`, aguarde a redefinição da cota diária ou troque para outro modelo/grupo disponível
  - Se o log contiver `cooling down`, não repita tentativas em sequência imediata; aguarde o fim do cooldown ou troque temporariamente de modelo
</Callout>

### Retorno de modelo indisponível (Model Not Available)

Verifique se o nome do modelo especificado está correto, consultando a lista de modelos recomendados no [Início rápido](/pt/start). Alguns modelos podem ainda não estar disponíveis no FishXCode.
