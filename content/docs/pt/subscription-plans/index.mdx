O pacote mensal do pool Codex Pro usa o pool de contas oficiais Codex Pro e é comprado por mês, com crédito fixo. Ele é indicado para programação intensiva com Codex e desenvolvimento de agentes. No momento, é a única série de pacotes à venda e oferece três níveis:

| Pacote | Preço | Crédito do pacote | Multiplicador de custo real | Validade | Redefinição do crédito | Ideal para |
| - | - | - | - | - | - | - |
| Pacote mensal com 2000 USD de crédito | $260 | $2,000 | 0.13x | 1 mês-calendário | Não é redefinido | Desenvolvimento intensivo e equipes corporativas |
| Pacote mensal com 200 USD de crédito | $30 | $200 | 0.15x | 1 mês-calendário | Não é redefinido | Crédito intermediário, a escolha preferida para o desenvolvimento diário |
| Pacote mensal com 20 USD de crédito | $3.60 | $20 | 0.18x | 1 mês-calendário | Não é redefinido | Para começar e usar com flexibilidade |

Preço e disponibilidade de venda seguem a [página de preços](https://fishxcode.com/pricing).

## Como usar após a compra

1. Compre o pacote mensal Codex com o crédito desejado.
2. No console, selecione o grupo `codex-sub-june`.
3. Crie um novo token de API com esse grupo.
4. Configure o token em um cliente compatível para começar a usar, por exemplo [Codex](/pt/codex) ou [Codex Desktop](/pt/codex-desktop).

## Regras de cobrança

- O grupo `codex-sub-june` usa sempre o **multiplicador de 1x**.
- Multiplicador de custo real = preço do pacote ÷ crédito do pacote.
- Cada requisição desconta do crédito do pacote conforme o consumo real de tokens.
- A validade do pacote é de 1 mês-calendário.
- O crédito do pacote não é redefinido, e o crédito não utilizado não é prorrogado automaticamente.

<Callout type="idea" title="Exemplo">
  Ao pagar $260 por $2,000 de crédito, o multiplicador de custo real é **0.13x**, mas o grupo continua exibindo o multiplicador de 1x.
</Callout>

## Pontos de atenção

<Callout type="warn" title="Só o grupo codex-sub-june pode usar o crédito do pacote mensal">
  Para o pacote mensal Codex, o token precisa ser criado no grupo `codex-sub-june`; os outros grupos não usam o crédito desse pacote.
</Callout>

- O pacote mensal não tem crédito ilimitado: quando o crédito acaba ou o pacote expira, não é mais possível continuar usando.
- Se não quiser comprar um pacote mensal, você também pode chamar os grupos da série Codex com pagamento por uso, descontado do saldo; veja [Regras de cobrança e grupos](/pt/billing-groups).
