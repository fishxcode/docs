## Notas da plataforma

O Gemini CLI se conecta usando o protocolo compatível com OpenAI. Se o cliente oferecer campos personalizados de Base URL / API Key, preencha-os com as informações acima; se ele aceitar apenas endpoints compatíveis com OpenAI, verifique se a URL inclui `/v1`.

## Opcional: Importação com um clique pelo CC Switch

Se você mantém vários canais Gemini, pode usar o [CC Switch](https://github.com/farion1231/cc-switch) para alternar rapidamente; se o FishXCode é seu único canal, a configuração por variáveis de ambiente acima geralmente basta.

Na página **Chaves API** do console FishXCode, localize a linha da chave desejada e clique em **Abrir menu → CC Switch**:

![Escolher Preencher no CC Switch no console FishXCode](/img/start/gemini-cli/cc-switch-import-channel.png)

O console mostra o formulário «Preencher no CC Switch». Defina **Aplicativo** como `Gemini`, mantenha **Nome** como `FishXCode` (fácil de reconhecer na lista de canais), defina **Modelo principal** como `gemini-3.6-flash` e clique em **Abrir CC Switch**:

| Campo | Valor recomendado do FishXCode |
| - | - |
| Aplicativo | `Gemini` |
| Nome | `FishXCode` |
| Modelo principal | `gemini-3.6-flash` |

O CC Switch mostra o diálogo «Confirmar importação do provedor». Verifique se o endpoint da API é `https://fishxcode.com` e o modelo é `gemini-3.6-flash`, então clique em **Importar**:

![Confirmar a importação do FishXCode no CC Switch](/img/start/gemini-cli/cc-switch-select-model.png)

Após a importação, o FishXCode aparece na lista de provedores:

![FishXCode importado e visível na lista de provedores](/img/start/gemini-cli/cc-switch-import-success.png)

<Callout type="warn" title="Atenção">
  Quando «Alternar para este provedor logo após a importação» está ativado, o CC Switch regrava a configuração local do Gemini CLI (`~/.gemini/.env`). Ao voltar para o canal oficial, selecione-o novamente no CC Switch para não enviar requisições a um endereço inesperado.
</Callout>
