## 1. Registro e login

### 1.1 Criar conta

Acesse [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW) para abrir a página de registro:

![Página de registro do FishXCode](/img/start/api-v2-01-home.png)

Preencha o formulário de registro: defina o nome de usuário e a senha (8 a 128 caracteres, recomendamos incluir letras maiúsculas e minúsculas, números e símbolos) e informe o e-mail que receberá o código de verificação:

![Preencher informações de registro](/img/start/api-v2-03-register-form.png)

<Callout type="idea" title="Domínios de e-mail suportados">
  O registro por e-mail atualmente suporta apenas quatro domínios: **qq.com, 126.com, 163.com, gmail.com**. Outros domínios podem não receber o código de verificação.
</Callout>

Clique em **Enviar código de verificação**. Após concluir a verificação humana do Cloudflare, o código será enviado para seu e-mail. Localize o código (combinação de 6 caracteres alfanuméricos) na caixa de entrada e preencha o formulário:

![Inserir código de verificação do e-mail](/img/start/api-v2-02-register-verify.png)

Clique em **Criar conta** para concluir o registro. A página redirecionará para o login com a mensagem "Conta criada! Faça login".

<Callout type="warn" title="Não recebeu o código de verificação?">
  1. Confirme se o domínio do e-mail está na lista de suportados (qq.com / 126.com / 163.com / gmail.com)
  2. Verifique a pasta de spam
  3. Aguarde 1 a 2 minutos e tente novamente, evitando requisições frequentes
  4. Se ainda assim não receber, use o login por autorização de terceiros
</Callout>

### 1.2 Login

Após o registro, faça login com nome de usuário e senha. Também é possível fazer login com um clique usando autorização de contas de terceiros:

![Página de login](/img/start/api-v2-04-login.png)

| Método de login | Descrição |
| - | - |
| Conta registrada por e-mail | Login com nome de usuário/e-mail + senha |
| GitHub | Login por autorização, recomendado para desenvolvedores |
| LinuxDO | Login por autorização para usuários da comunidade |
| Google | Login por autorização com conta Google |

<Callout type="info" title="Autorização de terceiros cria a conta automaticamente">
  Ao fazer login pela primeira vez com GitHub / LinuxDO / Google, a conta é criada automaticamente; não é necessário registrar-se separadamente.
</Callout>

Após o login, você entra no console (página de visão geral):

![Visão geral do console](/img/start/api-v2-05-console.png)

## 2. Obter API Key

### 2.1 Criar API Key

Acesse **Console → Chaves API** e clique em **Criar API Key** no canto superior direito:

![Diálogo de criação de API Key](/img/start/api-v2-06-token-create.png)

Descrição dos campos do formulário:

| Campo | Descrição |
| - | - |
| Nome | Nome personalizado da chave, facilita identificar sua finalidade |
| Grupo | Define os modelos disponíveis e o multiplicador de consumo; veja a explicação abaixo |
| Expiração | Nunca / 1 mês / 1 dia / 1 hora |
| Quantidade | Permite criar várias chaves de uma vez (sufixo aleatório adicionado automaticamente ao nome) |
| Cota ilimitada | Ativada por padrão; ao desativar, é possível limitar o consumo máximo desta chave |
| Configurações avançadas | Lista de permissões de IP (suporta CIDR), permitir consulta de cota do usuário |

- Recomendamos escolher o grupo **claude** (1.5x): é o pool de contas oficial a preço cheio do Claude Max 20, com desempenho pleno. Ao usar o pacote mensal do Codex, é obrigatório escolher `codex-sub-june`. Todos os grupos e multiplicadores estão em [Regras de cobrança e grupos](/pt/billing-groups).
- A **lista de permissões de IP** é adequada para IPs de saída fixos de servidores; use com cautela em desenvolvimento local, pois mudanças de IP impedirão as chamadas.

Clique em **Salvar alterações** para concluir a criação. Na lista de chaves, clique no botão **Copiar** para obter a API Key (formato `sk-xxx`):

![Copiar API Key](/img/start/api-v2-07-token-copy.png)

<Callout type="idea" title="Endereço da API">
  Clique em **Endereço da API** no canto superior direito da página para ver o endereço de acesso. O console exibe por padrão `https://fishxcode.com`; `https://api.fishxcode.com` também funciona, ambos se comportam da mesma forma — escolha qualquer um.
</Callout>

### 2.2 Recarga

Acesse **Console → Carteira**. A página tem duas abas: **Recarga de saldo** e **Planos de assinatura**:

![Recarga de saldo na carteira](/img/start/api-v2-08-wallet.png)

**Recarga de saldo**: escolha um valor predefinido ($1 / $5 / $10 / $100 / $500 / $1.000, valores altos têm 1%–3% de desconto) ou insira um valor personalizado, e depois escolha a forma de pagamento:

![Formas de pagamento e códigos de resgate](/img/start/api-09-payment.png)

| Método | Descrição |
| - | - |
| Alipay | Método de recarga mais comum, sem valor mínimo |
| Waffo Pancake | Recarga mínima de $100 |
| Código de resgate | Insira na área "Tem um código de resgate?" e clique em **Resgatar cota** |

**Planos de assinatura**: compre o pacote mensal do pool de contas Codex (três faixas de cota: $20 / $200 / $2.000). Após a compra, crie chaves com o grupo `codex-sub-june` para usar. Veja detalhes em [Planos de assinatura](/pt/subscription-plans):

![Aba de planos de assinatura](/img/start/api-10-subscription.png)

<Callout type="idea" title="Benefício para novos usuários">
  Contas recém-registradas recebem automaticamente um saldo de teste de **$0.2**, que pode ser usado diretamente para testar chamadas à API.
</Callout>

<Callout type="idea" title="Sobre os multiplicadores">
  O multiplicador no nome do grupo é o coeficiente de consumo: quanto menor o valor, menos se cobra pelo mesmo pedido. Por exemplo, consumir ¥1 (yuan) em um grupo `0.5x` equivale ao volume de Tokens que custaria ¥2 no preço oficial original. Veja detalhes em [Regras de cobrança e grupos](/pt/billing-groups).
</Callout>

## 3. Segurança da conta

Acesse **Console → Segurança e acesso** para gerenciar as configurações de segurança da conta:

![Página de segurança e acesso](/img/start/api-12-security.png)

| Recurso | Descrição |
| - | - |
| Alterar senha | Troque periodicamente; 8 caracteres ou mais, com letras maiúsculas, minúsculas e números |
| Vínculos da conta | Após vincular GitHub / LinuxDO / Google, é possível fazer login por autorização com um clique |
| Sessões de login | Veja os dispositivos atualmente logados e encerre outras sessões remotamente |
| Tokens de acesso | Usados para chamar a API do painel; crie marcando as permissões desejadas |
| Login com Passkey | Login por chave de acesso, sem senha |
| Verificação em duas etapas | Adiciona uma camada extra de segurança à conta |

### Recomendações de segurança das chaves

- **Rotação periódica**: recomenda-se trocar a chave a cada 30–90 dias para reduzir o risco de vazamento
- **Não armazene em texto puro**: evite gravar a API Key diretamente no código ou enviá-la ao repositório Git; prefira variáveis de ambiente
- **Princípio do menor privilégio**: crie chaves separadas por projeto, facilitando gestão e rastreamento
- **Em caso de vazamento**: se suspeitar que a chave foi exposta, exclua-a imediatamente na página **Chaves API** e crie uma nova

<Callout type="warn" title="Atenção">
  A exclusão de uma chave é irreversível. Após excluir, a chave fica imediatamente inválida e as ferramentas que a utilizam não conseguirão mais fazer chamadas.
</Callout>

## 4. Perguntas frequentes

### Não recebo o código de verificação ao me registrar

1. Confirme se o domínio do e-mail está na lista de suportados (qq.com / 126.com / 163.com / gmail.com)
2. Verifique as pastas de spam/lixo eletrônico
3. Aguarde 1 a 2 minutos e tente novamente, evitando requisições frequentes
4. Se ainda assim não receber, use o login por autorização de terceiros com GitHub / LinuxDO / Google

### Onde vejo a API Key depois de criá-la?

Acesse **Console → Chaves API**; as chaves criadas aparecem na lista. Clique no botão copiar para obter a API Key no formato `sk-xxx`.

### A recarga não caiu na conta. O que fazer?

1. Confirme se o pagamento foi concluído (verifique o histórico de transações do Alipay ou outro canal)
2. Aguarde 1 a 5 minutos; o sistema pode ter uma pequena demora
3. Atualize a página da carteira no console
4. Se após 10 minutos ainda não tiver caído, entre em contato por [Fale conosco](https://fishxcode.com/contact) apresentando o comprovante de pagamento para obter ajuda

### Como ver os detalhes de consumo?

Acesse **Console → Logs de uso**, onde é possível ver, para cada chamada à API:

- Data/hora da chamada e nome do modelo
- Consumo de Tokens e custo
- IP da requisição e registros detalhados

Outros tipos de log (logs de auditoria, logs de tarefas) podem ser alternados na barra lateral.
