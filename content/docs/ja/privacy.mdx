**発効日：2026年2月11日**

FishXCode は、「中華人民共和国個人情報保護法」、「サイバーセキュリティ法」、「データセキュリティ法」およびその他の関連法令を厳格に遵守します。

## 1. 当社が収集する情報とその利用目的

| 場面 | 収集する内容 | 利用目的 |
| - | - | - |
| アカウント登録 | 携帯電話番号またはメールアドレス、パスワード、ユーザー名 | アカウントの作成、本人確認、アカウントのセキュリティの維持 |
| API の利用 | 呼び出し時刻、リクエストパス、消費トークン数 | サービスの課金、不正および濫用の防止 |
| デバイスとネットワーク | IP アドレス、デバイス識別子、ブラウザーの種類、オペレーティングシステム | サービスの安全かつ安定した運用の確保 |
| 支払い | 第三者（Alipay、WeChat Pay）が処理 | 取引の完了。FishXCode は完全な銀行カード情報を保存しません |
| カスタマーサポートとのやり取り | 連絡先、通信記録 | 本人確認、問題の解決 |

<Callout type="idea" title="モデルのトレーニングについて">
  お客様が「履歴」や「デバッグモード」などのオプション機能を自ら有効にしない限り、FishXCode はお客様の入力または出力を AI モデルのトレーニングに使用**しません**。
</Callout>

## 2. 情報の共有と開示

- **第三者モデルプロバイダー**：お客様の API リクエストに応答するため、当社は入力内容をお客様が選択したプロバイダーに送信する必要があります（当該プロバイダーのプライバシーポリシーをご確認いただくことをおすすめします）。
- **認可されたパートナー**：クラウドサービス事業者、データ分析サービス事業者などであり、厳格なデータ保護契約を締結する必要があります。
- **法的要件**：法令または政府の所管部門の要請に基づき、当社が情報を共有する場合があります。
- 当社はお客様の個人情報を**販売することはなく**、許可のない公開開示も行いません。

## 3. データの越境移転

FishXCode の運営主体は中国国内に所在し、個人情報は国内に保存されます。越境移転が真に必要な場合は、国家インターネット情報部門の規定を厳格に遵守し、法令に従ってお客様の個別の同意を取得します。

## 4. 保存とセキュリティ

- **保存期間**：目的の達成に必要な期間および法令で定められた期間に限り保持し、期間の経過後は削除または匿名化します。
- **安全対策**：暗号化、非識別化、アクセス制御、定期的なセキュリティ監査。

## 5. お客様の権利

「個人情報保護法」に基づき、お客様は以下の権利を有します：

- **閲覧と複製**：お客様の個人情報を閲覧、複製すること
- **訂正**：不正確または不完全な情報を訂正すること
- **削除**：特定の場合に削除を申請すること
- **同意の撤回**：同意に基づく処理の承諾をいつでも撤回すること
- **アカウントの解約**：解約後は処理を停止し、法令に従って個人情報を削除または匿名化します

権利を行使する場合は、下記の連絡先から申請してください。当社は 15 営業日以内に回答します（本人確認が必要となる場合があります）。

## 6. 未成年者の保護

当社のサービスは主に成人を対象としており、**未成年者の個人情報を故意に収集することはありません**。未成年者が保護者の同意なく個人情報を提供したことが判明した場合は、直ちに当社までご連絡ください。

## 7. ポリシーの更新

変更がお客様の権利に実質的な影響を与える場合、当社はウェブサイトの目立つ位置での告知、または登録メールアドレスへの通知の送信によりお知らせします。
