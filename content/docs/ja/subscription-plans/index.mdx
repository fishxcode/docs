Codex Pro アカウントプール月額パックは、Codex Pro の公式アカウントプールをベースに、固定の利用枠を月単位で購入するプランです。高頻度の Codex プログラミングや Agent 開発に適しています。現在販売中のプランはこのシリーズのみで、次の 3 種類があります：

| プラン | 販売価格 | プラン利用枠 | 実質コスト倍率 | 有効期間 | 利用枠のリセット | 向いている場面 |
| - | - | - | - | - | - | - |
| 利用枠 2000 ドルの月額パック | $260 | $2,000 | 0.13x | 1 暦月 | リセットなし | 高頻度の開発、企業チームでの利用 |
| 利用枠 200 ドルの月額パック | $30 | $200 | 0.15x | 1 暦月 | リセットなし | 中程度の利用枠で、日常の開発に最適 |
| 利用枠 20 ドルの月額パック | $3.60 | $20 | 0.18x | 1 暦月 | リセットなし | 入門・お試し用。柔軟に使える |

価格と販売状況は [料金ページ](https://fishxcode.com/pricing) の表示が優先されます。

## 購入後の使い方

1. 必要な利用枠に合った Codex 月額パックを購入します。
2. コンソールで `codex-sub-june` グループを選択します。
3. このグループで新しい API トークンを作成します。
4. トークンを [Codex](/ja/codex)、[Codex Desktop](/ja/codex-desktop) などの対応クライアントに設定すれば、すぐに使えます。

## 課金ルール

- `codex-sub-june` グループは **1x 倍率** で固定されています。
- 実質コスト倍率 = プランの販売価格 ÷ プラン利用枠。
- リクエストごとに、実際のトークン消費量に応じてプラン利用枠から差し引かれます。
- プランの有効期間は 1 暦月です。
- プラン利用枠はリセットされず、未使用の利用枠が自動で延長されることもありません。

<Callout type="idea" title="例">
  $260 で $2,000 分の利用枠を購入した場合、実質コスト倍率は **0.13x** ですが、グループに表示される倍率は 1x のままです。
</Callout>

## 注意事項

<Callout type="warn" title="月額パックの利用枠は codex-sub-june グループでのみ使えます">
  Codex の月額パックを使うには、必ず `codex-sub-june` グループでトークンを作成してください。他のグループではこのプランの利用枠を使えません。
</Callout>

- 月額パックの利用枠は無制限ではありません。利用枠を使い切るか、プランの有効期限が切れると、それ以降は利用できなくなります。
- 月額パックを購入しない場合は、残高による従量課金で Codex シリーズのグループを呼び出すこともできます。詳しくは [課金ルールとグループ](/ja/billing-groups) をご覧ください。
