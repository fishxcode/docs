Claude シリーズでは、[ClaudeMax](https://claudemax.fishxcode.com/) を通じて Claude Max のサブスクリプション代行と Claude Code のホスティングサービスを提供しています。Claude Code を安定して使いたい中国語圏の開発者向けのサービスで、支払い、アカウントの状態、ネットワーク、ローカル環境の設定に関する問題を解決します。

## 1. 解決する主な課題

Claude Code の使い方がわからないのではなく、利用を始めて安定して使えるようになるまでの前提条件でつまずくユーザーが多くいます。

- **米国での支払いのハードル**：SSN / ITIN がなく、中国国内のカードはリスク管理の審査に引っかかりやすく、代理決済は手数料が高いうえに不安定です。
- **アカウントの状態が不安定**：自分で登録したアカウントや一時的なチャネルで入手したアカウントでは、リスク管理による制限、サブスクリプションの中断、不明確なアフターサポートといった問題が起こりやすく、長期的な開発のペースに影響します。
- **ネットワーク接続が不安定**：Anthropic への直接接続では `403`、タイムアウト、接続品質の変動が起こることがあり、VPS のデフォルト回線も API に対して不安定な場合があります。

ClaudeMax では、Claude Max のサブスクリプションを代行し、Claude Code の環境をプリインストールし、低遅延の中継を設定したうえで、ローカルプロジェクトのマウントツールを提供します。ユーザーは接続情報を受け取ったら、SSH でサーバーに入るだけで Claude Code を使い始められます。

## 2. プランの説明

- これは公式アカウントのサブスクリプション特典であり、通常の残高による従量課金ではありません。
- Claude Code の利用を想定したプランで、Claude Max のサブスクリプション代行、海外サーバー、低遅延の中継、Claude Code の環境が含まれます。
- 主なプランは ClaudeMax x5 と ClaudeMax x20 です。個人利用なら通常は ClaudeMax x5、チーム、ヘビーユース、長時間のセッション、チームでの PoC なら通常は ClaudeMax x20 を選びます。
- アカウントは個人専用で、他人とは共有しません。利用分は購入者のものです。
- ローカルプロジェクトのマウントに対応しており、ローカルのコードとサーバー上のコードを双方向に同期できます。
- 請求書の発行に対応しています。
- 利用できるモデル、回数、有効期間、納品方法、開通時期、アフターサポート、保証のルールは、購入ページの表示が優先されます。

## 4. サブスクリプションの流れ

1. [ClaudeMax](https://claudemax.fishxcode.com/) または FishXCode のサブスクリプションプランのページを開きます。
2. ClaudeMax x5、ClaudeMax x20、またはページに表示されているその他の Claude シリーズのプランを選択します。個人利用なら x5、チームやヘビーユースなら x20 をまず検討してください。
3. プランに含まれる内容、有効期間、アカウントの保証、開通方法、請求書、アフターサポートのルールを確認します。
4. 支払いを完了します。
5. ページ、サイト内通知、またはカスタマーサポートからのメッセージで納品情報を受け取ります。主な納品内容には、サーバーへの接続方法、SSH の使い方、アクティベーションコード、その他の開通手順が含まれます。
6. SSH でホスティングサーバーに入り、プリインストールされた Claude Code の環境で開発を始めます。
7. ローカルのプロジェクトを編集したい場合は、ページの説明に従ってローカルプロジェクトのマウントツールを使い、ローカルのコードとサーバー環境を同期します。

手動発行または事前予約が必要と記載されているプランは、管理者による処理を待つ必要があります。ページに表示されている「30 分以内に開通」「事前予約のご連絡」などの説明は、購入ページの実際の状態が優先されます。大量に購入する場合は、在庫、サーバー、アカウントの納品スケジュールが利用に影響しないよう、事前に予約のご連絡をお願いします。

## 5. 自分でサブスクリプションを契約する場合との違い

| 項目 | 自分で Claude Max を契約 | ClaudeMax |
| - | - | - |
| 支払い条件 | 海外での支払い、電話番号、アカウントの条件を自分で用意する必要がある | サービス提供者がサブスクリプションを代行 |
| Claude Code の環境 | 自分でインストール、保守、トラブル対応を行う | サーバー環境にプリインストール済みで、SSH で直接接続して利用 |
| ネットワーク接続 | 直接接続、プロキシ、VPS の回線を自分で用意する | 低遅延の中継を含む |
| アカウントの状態 | 公式のルールやアカウントの異常に自分で対処する | ページのルールに従い、アカウントの異常やサブスクリプションの中断に対する保証を提供 |
| コスト構成 | 公式のサブスクリプション料金のほかに、サーバーや中継のコストがかかる場合がある | プラン価格に Max のサブスクリプション、サーバー、中継が含まれる |

## 7. 想定される利用シーン

- 米国での支払いや海外アカウントの条件を満たしにくい開発者。
- 環境を自分でインストール・保守せずに、すぐに Claude Code を使いたいユーザー。
- より安定したネットワーク接続と、Anthropic への低遅延のアクセスを必要とするユーザー。
- ローカルプロジェクトのマウント、リモート編集、長期的な開発環境を必要とする個人や小規模チーム。
- 請求書の発行、アフターサポート、アカウントの異常に対する保証を求める企業やチーム。

## 8. セキュリティとサーバーの納品

ClaudeMax が納品するのは、独立したサーバー環境とアカウントの利用環境で、ユーザーは SSH でサーバーに入って Claude Code を使います。該当するサーバーが譲渡に対応している場合は、アフターサポートのルールに従ってサーバーまたは利用権の譲渡をサポートできます。詳細は、実際の納品形態とページの説明が優先されます。

サーバーの接続情報、アクティベーションコード、アカウント情報、関連する認証情報は適切に管理し、無関係な人に公開・転送しないでください。

## 9. 譲渡、アカウント停止、返金

- Claude シリーズは Claude のツールチェーンと ClaudeMax のホスティングサービスで使うもので、通常の残高としては扱いません。
- プランによって、アカウントの特典、利用の強度、安定性の保証、利用できるモデルが異なる場合があります。
- プランの納品後は、接続情報、アクティベーションコード、アカウント情報、関連する認証情報を適切に保管し、公開・転送しないでください。
- サーバー、サブスクリプションの状態、アカウントの状態に異常がある場合は、ページのアフターサポートのルールに従ってサポートに連絡してください。

譲渡のルール：

- 初回の譲渡は無料です。
- 2 回目以降の譲渡は、1 回につきサーバー費用として 50 元がかかります。
- 譲渡できるかどうかは、具体的なサーバー、アカウント、納品形態によって異なります。カスタマーサポートの確認結果が優先されます。

アカウント停止と返金のルール：

- アカウントの異常や停止が保証の対象に該当する場合は、未使用の残り日数の割合に応じて返金できます。
- 例：プランを 10 日間使用し、残りが 20 日の場合は、残り 20 日分に相当する金額を返金します。
- 引き続き利用したい場合は、使用済みの 10 日分に相当する費用をお支払いいただければ、新しいアカウントを開設して引き続き納品します。
- 違法な用途、規約違反、不適切な利用によって停止された場合は、返金できません。ClaudeMax と Claude Code は適切かつ正当に利用してください。

## 10. アフターサポートについて

ClaudeMax のプランの返金、アカウントの異常、サブスクリプションの中断、譲渡、未使用日数の保証は、購入ページ、サイト内通知、[ClaudeMax のよくある質問](https://claudemax.fishxcode.com/faq)、[返金ポリシー](/ja/refund) が優先されます。納品や利用で問題が発生した場合は、調査のため、注文番号、プラン名、購入日時、接続情報、エラーのスクリーンショットまたはリクエスト日時をお知らせください。
