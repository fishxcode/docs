## VSCode に RooCode をインストールする

1. VSCode で [RooCode](https://marketplace.visualstudio.com/items?itemName=RooVeterinaryInc.roo-cline) を検索してインストールします
2. [https://fishxcode.com/console/token](https://fishxcode.com/console/token) にアクセスして API Key を取得します

## プロバイダーを追加する

RooCode のインストールが完了したら、RooCode を開いてプロバイダーの設定を選択し、OpenAI Compatible のプロバイダーを新しく追加します。

| 設定項目 | 値 |
| - | - |
| **OpenAI ベース URL** | `https://api.fishxcode.com/v1` |
| **API Key** | FishXCode で作成したキー |
| **モデル** | `gpt-5` |

<Callout type="idea" title="ヒント">
  モデルは `glm-4.5`、`glm-4.6`、`deepseek-v3.1` など、ほかのモデルに変更することもできます。
</Callout>

設定が完了したら、保存すればすぐに使えます。
