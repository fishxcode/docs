## 1. 環境準備

### Node.js のインストール

Claude Code は npm でインストールします。先に Node.js が用意できているか確認してください。

```bash tab="macOS - 検証"
node -v
npm -v
```

```bash tab="macOS - Homebrew でインストール"
brew install node
```

```bash tab="Windows - 検証（CMD/PowerShell）"
node -v
npm -v
```

未インストールの場合は [nodejs.org/zh-cn/download](https://nodejs.cn/download/current/) からお使いのプラットフォームのインストーラーをダウンロードし、インストール完了後に **Windows は再起動が必要**です。

### Windows の追加手順：Git Bash のインストール

Claude Code は bash 実行環境に依存するため、Windows ユーザーは Git Bash をインストールする必要があります：

1. ダウンロード先：[git-scm.com/install/windows](https://git-scm.com/install)。対応するバージョンを選んでインストールします。
2. 検証：デスクトップを右クリックし、**Open Git Bash here** という項目が表示されればインストール成功です。

## 3. FishXCode の設定

1. ターミナルに `npx zcf` と入力して Enter で実行します。
   `Ok to proceed? (y)` と表示されたら `y` を入力して Enter を押します。

2. ZCF の表示言語を選択：
   **简体中文** を選びます。

3. インストール完了後、次を選択：
   `1. 完全初期化 - Claude Code のインストール + ワークフローのインポート + API または CCR プロキシの設定 + MCP サービスの設定`

4. テンプレートの言語設定を変更するかどうか：
   `No` を選択

5. AI の出力言語：
   `简体中文` を選択

6. Claude をインストールするかどうか：
   `Yes` を選択

7. API 設定モード：
   `カスタム API 設定` を選択

8. API プロバイダー：
   `カスタム設定` を選択

9. 設定名：
   任意の英字名を付けます

10. 認証タイプ：
    `API Key` を選択

11. API ベース URL：
    ```
    https://api.fishxcode.com
    ```
    <Callout type="idea" title="接続アドレス">
      `https://api.fishxcode.com` と `https://fishxcode.com` はどちらも接続アドレスとして使えます。両者の動作は同一で、どちらか好きな方を選べます。
    </Callout>

12. API キー：
    FishXCode コンソールで作成した API Key を入力します（コンソール → API キー）

13. モデル関連の設定：
    デフォルトのまま Enter でスキップして構いません

14. ワークフロータイプ：
    `汎用ツール` を選択

15. 出力スタイル：
    好みに応じて選択してください

16. MCP を設定するかどうか：
    `Yes` を選択

17. MCP サービス：
    スペースキーで必要なサービスを選び、Enter で実行します

18. CCometixLine の設定：
    そのまま Enter を押します

19. メインメニューに戻ったら入力：
    ```
    q
    ```

20. ターミナルに入力：
    ```
    claude
    ```
    - `Yes, I trust this folder` を選択
- API の選択では、必ず **YES（1 番目）** を選んでください

## 5. モデル切り替え

Claude Code のチャット画面で `/model` と入力するだけでモデルを切り替えられます：

| 選択肢 | 実際のモデル | 説明 |
| - | - | - |
| **Default** | `claude-fable-5-2` + `claude-haiku-5-5` | タスクに応じて自動選択。日常利用に推奨 |
| **Opus** | `claude-opus-5-5` | 最も強い推論能力。消費は多め |
| **Haiku** | `claude-haiku-5-5` | 軽量かつ高速 |

環境変数でモデルを固定することもできます：

```bash tab="macOS/Linux"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL="claude-fable-5-2"
claude
```

<Callout type="idea" title="Claude Code のアップグレード">
  モデルのバージョンが最新でない場合は、アップグレードコマンドを実行してから関連ツールを再起動してください：

  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
</Callout>

## 6. IDE 統合

### IntelliJ IDEA

操作手順：ファイル → 設定 → プラグイン → Marketplace → `claude code` で検索し、**Claude Code Terminal** を見つけてインストールします：

![Claude Code Terminal のインストール](/img/start/idea-01-install.png)

インストール完了後に IDEA を再起動し、プラグインが読み込まれていることを確認します：

![プラグインの読み込み確認](/img/start/idea-02-verify.png)

<Callout type="info">
  プラグインマーケットで見つからない場合は、現在の IDEA のバージョンが古すぎます。最新バージョンへアップグレードしてください。
</Callout>

### VSCode

`Ctrl + Shift + X` で拡張機能パネルを開き、`claude code` で検索して **Claude Code for VSCode** をインストールします。

![Claude Code プラグインの検索とインストール](/img/start/vscode-01-install.png)

インストールが完了すると、プラグインは 3 つの接続方法を提供します：

![Claude Code プラグインの接続方法](/img/start/vscode-02-login.png)

FishXCode への接続は `settings.json` での設定を推奨します。プラグイン右下の**歯車アイコン**をクリック → **settings.json で編集**を選択します：

![settings.json を開いて編集](/img/start/vscode-03-settings.png)

VSCode の `settings.json` に以下を追加します：

```json
{
  "claudeCode.preferredLocation": "panel",
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "ご自身の API Key に置き換えてください" },
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.fishxcode.com/" }
  ]
}
```

<Callout type="idea" title="接続アドレス">
  `ANTHROPIC_BASE_URL` には `https://fishxcode.com/` を指定することもできます。両アドレスの動作は同一で、どちらか好きな方を選べます。
</Callout>

![settings.json 設定例](/img/start/vscode-04-config.png)

保存したら **VSCode を終了して再び開きます**。プラグインが FishXCode に正常に接続できるようになります。

![VSCode で Claude Code を使う](/img/start/vscode-05-demo.gif)

## 7. よくある質問

### 403 エラーが発生する

Token の残高が不足しています。コンソールでチャージしてから再試行してください。

### Windows で接続異常や 400/401 エラーが出る

PowerShell で `setx` コマンドを再実行してシステム変数に書き込み、その後ターミナルを開き直してください：

```powershell
setx ANTHROPIC_AUTH_TOKEN "sk-xxx"
setx ANTHROPIC_BASE_URL "https://api.fishxcode.com/"
```

### 「Unable to connect to Anthropic services」と表示される

エラーの全文は以下のとおりです：

```
Unable to connect to Anthropic services
Failed to connect to api.anthropic.com: ERR_BAD_REQUEST
Please check your internet connection and network settings.
```

これは Claude Code がまだ onboarding を完了しておらず、公式の `api.anthropic.com` に接続しようとしているためです。**VPN 等は不要**です。`~/.claude.json`（home ディレクトリ直下の `.claude.json` です。`.claude/settings.json` ではありません）の末尾に `"hasCompletedOnboarding": true` を追加すればスキップできます：

```json
{
  "installMethod": "unknown",
  "autoUpdates": true,
  "projects": { ... },
  "hasCompletedOnboarding": true
}
```

<Callout type="idea">
  追加する際は、直前のフィールド末尾にカンマを補うことに注意してください（JSON の構文上の要件です）。修正後に `claude` を再実行すれば正常に接続できます。
</Callout>
