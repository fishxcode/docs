## 1. API Key を取得する

### 1. アカウントを登録する

[fishxcode.com](https://fishxcode.com/register?aff=9CTW) にアクセスし、**登録**をクリックします。

![FishXCode のホーム](/img/start/api-01-home.png)

登録方法（GitHub、LinuxDO、またはユーザー名での登録）を選択します。

![登録方法の選択](/img/start/api-02-register.png)

ユーザー名、パスワード、確認用パスワードを入力して登録を完了します。

![登録情報の入力](/img/start/api-03-register-form.png)

### 2. ログインする

登録が完了したら、ユーザー名とパスワードでログインします。

![ログインページ](/img/start/api-04-login.png)

ログインするとコンソールに移動します。

![コンソールのホーム](/img/start/api-05-console.png)

### 3. トークンを作成する

**コンソール → トークン管理 → トークンを追加**に進み、フォームに入力します。

![トークンを追加](/img/start/api-06-token-create.png)

- **トークングループ**は**公式チャネル**を選択することをおすすめします。このグループには Claude の全モデルが含まれ、タスクの複雑さに応じて自動でモデルが選ばれるため、手動で切り替える必要はありません。具体的なチャネルとモデルは公式サイトの実際の内容が優先されます。最新情報は [料金ページ](https://fishxcode.com/pricing) でご確認ください。

作成後、トークン一覧の**コピー**ボタンをクリックすると API Key（形式は `sk-xxx`）を取得できます。

![トークンをコピー](/img/start/api-07-token-copy.png)

### 4. チャージする

**コンソール → ウォレット管理**に進みます。Alipay、WeChat Pay、引き換えコードに対応しています。

![チャージページ](/img/start/api-08-wallet.png)

| 方法 | 操作手順 |
| - | - |
| Alipay | 金額を入力/選択 → Alipay |
| WeChat Pay | 金額を入力/選択 → WeChat Pay |
| 引き換えコード | 引き換えコード欄に入力 → 引き換えボタンをクリック |

<Callout type="idea" title="倍率について">
  グループ名にある `0.5x倍率` は消費倍率を表します。数値が小さいほど多くのトークンを利用できます。たとえば `0.5x` なら、1 元で公式の 1000 万トークン分を利用できます（公式の通常価格では 500 万トークン）。
</Callout>

## 2. トークン管理

### トークングループについて

トークンを作成するときはグループを選択する必要があります。グループによって、利用できるモデルの範囲と消費倍率が決まります。

| グループの種類 | 説明 | 適したケース |
| - | - | - |
| **公式チャネル** | Claude の全モデルを含み、自動でルーティング | ほとんどのユーザーにおすすめ |
| **低倍率グループ** | 消費倍率が低く、コストパフォーマンスが高い | 高頻度の呼び出しや、コストを重視する場合 |

<Callout type="idea" title="おすすめ">
  どのグループを選べばよいかわからない場合は、**公式チャネル**を選択してください。タスクの複雑さに応じて、システムが最適なモデルを自動で選択します。
</Callout>

### トークンのセキュリティ対策

- **定期的にローテーションする**：漏えいのリスクを下げるため、30〜90 日ごとにトークンを交換することをおすすめします
- **平文で保存しない**：API Key をコードに直接書き込んだり Git リポジトリにコミットしたりせず、環境変数を使うことをおすすめします
- **権限を最小限にする**：プロジェクトごとに個別のトークンを作成すると、管理や追跡がしやすくなります
- **漏えい時の対応**：トークンが漏えいした疑いがある場合は、すぐにコンソールでそのトークンを削除し、新しいトークンを作成してください

### トークンの変更と削除

**コンソール → トークン管理**ページでは、次の操作ができます。

- **詳細を表示**：トークン名をクリックすると、グループ、モデルの範囲、作成日時を確認できます
- **トークンをコピー**：一覧のコピーボタンをクリックします
- **トークンを削除**：削除ボタンをクリックします。削除したトークンは即座に無効になり、そのトークンを使っているツールからは呼び出せなくなります

<Callout type="warn" title="注意">
  削除は取り消せません。今後使わないことを確認してから削除してください。
</Callout>

## 3. アカウントのセキュリティ

### パスワードとログインのセキュリティ

- **強力なパスワード**（8 文字以上で、大文字・小文字・数字を含む）を使用してください
- 複数のサービスで同じパスワードを使い回さないでください
- パスワードを忘れた場合は、ログインページのパスワード再設定の手順でリセットできます

### 外部アカウントとの連携

FishXCode は次の外部アカウントでのログインに対応しています。

| 方法 | 説明 |
| - | - |
| **GitHub** | 開発者におすすめ。ワンクリックで認可してログイン |
| **LinuxDO** | コミュニティのユーザーはそのままログイン可能 |

外部アカウントを連携すると、パスワードを入力せずに、そのサービスの認可でログインできます。

### 異常の検知と対処

次のような異常に気づいた場合は、すぐに対処することをおすすめします。

1. **消費が異常に増えた** → トークンが漏えいしていないか確認し、必要に応じてすべてのトークンを削除して作り直してください
2. **ログインできない** → パスワードの再設定を試し、それでも解決しない場合は公式サポートに連絡してください
3. **残高が想定外に減った** → 使用ログで具体的な呼び出し記録を確認し、正常な消費かどうかを確かめてください

<Callout type="idea" title="サポートへの連絡">
  アカウントに関する問題が発生した場合は、[お問い合わせ](https://fishxcode.com/contact) ページからサポートを受けてください。
</Callout>

## 4. よくある質問

### 登録時に認証コードが届かない場合は？

1. メールアドレスが正しく入力されているか確認してください（スペルやドメインに注意）
2. 迷惑メールフォルダーを確認してください
3. 1〜2 分待ってから再試行してください。短時間に何度もリクエストしないでください
4. それでも届かない場合は、別のメールアドレスを使うか、外部アカウントでログインしてください

### 作成したトークンはどこで確認できますか？

**コンソール → トークン管理**に進むと、作成済みのトークンが一覧に表示されます。コピーボタンをクリックすると `sk-xxx` 形式の API Key を取得できます。

### チャージが反映されない場合は？

1. 支払いが成功したか確認してください（Alipay / WeChat Pay の取引履歴を確認）
2. システムに一時的な遅延がある場合があるため、1〜5 分待ってください
3. コンソールのウォレットページを再読み込みしてください
4. 10 分以上経っても反映されない場合は、支払いのスクリーンショットを添えて公式カスタマーサポートに連絡してください

### 利用明細はどこで確認できますか？

**コンソール → 使用ログ**に進むと、API 呼び出しごとに次の内容を確認できます。

- 呼び出し日時とモデル名
- トークンの消費量と料金
- リクエスト元の IP と詳細な記録
