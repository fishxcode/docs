## 1. 登録とログイン

### 1.1 アカウント登録

[fishxcode.com/register](https://fishxcode.com/register?aff=9CTW) にアクセスすると、登録ページが開きます：

![FishXCode 登録ページ](/img/start/api-v2-01-home.png)

登録フォームに入力します：ユーザー名とパスワード（8〜128 文字。英大文字・小文字、数字、記号を含めることを推奨）を設定し、確認コードを受け取るためのメールアドレスを入力してください：

![登録情報の入力](/img/start/api-v2-03-register-form.png)

<Callout type="idea" title="対応しているメールドメイン">
  現在、メール登録は **qq.com、126.com、163.com、gmail.com** の 4 つのドメインに対応しています。その他のドメインでは確認コードを受け取れない場合があります。
</Callout>

**確認コードを送信**をクリックし、Cloudflare のボット判定を完了すると、確認コードがメールアドレスに送信されます。受信トレイで確認コード（6 桁の英数字の組み合わせ）を見つけてフォームに入力してください：

![メール確認コードの入力](/img/start/api-v2-02-register-verify.png)

**アカウントを作成**をクリックすると登録が完了し、ログインページへ遷移して「アカウントが作成されました！ログインしてください」と表示されます。

<Callout type="warn" title="確認コードが届かない場合">
  1. メールドメインが対応リストに含まれているか確認する（qq.com / 126.com / 163.com / gmail.com）
  2. 迷惑メールフォルダを確認する
  3. 1〜2 分待ってから再試行する。連続してリクエストしない
  4. それでも届かない場合は、サードパーティー認証ログインに切り替える
</Callout>

### 1.2 ログイン

登録が完了したら、ユーザー名とパスワードでログインできます。サードパーティーアカウントによるワンクリック認証ログインにも対応しています：

![ログインページ](/img/start/api-v2-04-login.png)

| ログイン方法 | 説明 |
| - | - |
| メールで登録したアカウント | ユーザー名/メールアドレス + パスワードでログイン |
| GitHub | 認証ログイン。開発者に推奨 |
| LinuxDO | コミュニティユーザー向けの認証ログイン |
| Google | Google アカウントでの認証ログイン |

<Callout type="info" title="サードパーティー認証で登録も同時に完了">
  GitHub / LinuxDO / Google で初めて認証ログインすると、アカウントが自動的に作成されます。別途登録する必要はありません。
</Callout>

ログインするとコンソール（概要ページ）に入ります：

![コンソール概要](/img/start/api-v2-05-console.png)

## 2. API Key の取得

### 2.1 API Key の作成

**コンソール → API キー**へ進み、右上の **API Key を作成**をクリックします：

![API Key 作成ダイアログ](/img/start/api-v2-06-token-create.png)

フォームの各項目の説明：

| 項目 | 説明 |
| - | - |
| 名前 | Key の名前を自由に設定。用途の識別に便利 |
| グループ | 利用できるモデルと消費倍率が決まります。下記の説明を参照 |
| 有効期限 | 無期限 / 1 か月 / 1 日 / 1 時間 |
| 数量 | 一度に複数作成できます（名前にランダムなサフィックスが自動付加） |
| 無制限クォータ | デフォルトで有効。オフにするとこの Key の最大消費額を制限できます |
| 詳細設定 | IP ホワイトリスト（CIDR 対応）、ユーザークォータ照会の許可 |

- **グループ**は **claude**（1.5x）を選ぶことを推奨します。このグループは Claude Max 20 の公式正価格アカウントプールで、フルスペックの性能を発揮します。Codex 月額パッケージ利用時は必ず `codex-sub-june` を選択してください。全グループと倍率の一覧は [課金ルールとグループ](/ja/billing-groups) をご覧ください。
- **IP ホワイトリスト**は、サーバー側の固定グローバル IP 向けの機能です。ローカル開発では IP が変わると呼び出せなくなるため、使用には注意してください。

**変更を保存**をクリックして作成を完了します。Key 一覧の **コピー**ボタンをクリックして API Key（`sk-xxx` 形式）を取得してください：

![API Key のコピー](/img/start/api-v2-07-token-copy.png)

<Callout type="idea" title="API アドレス">
  ページ右上の **API アドレス**をクリックすると、接続先アドレスを確認できます。コンソールにはデフォルトで `https://fishxcode.com` が表示されますが、`https://api.fishxcode.com` も利用可能で、両者の動作は同一です。どちらか好きな方をお使いください。
</Callout>

### 2.2 チャージ

**コンソール → ウォレット**へ進むと、ページは**残高チャージ**と**サブスクリプションプラン**の 2 つのタブに分かれています：

![ウォレットの残高チャージ](/img/start/api-v2-08-wallet.png)

**残高チャージ**：プリセット金額（$1 / $5 / $10 / $100 / $500 / $1,000。大きな金額では 1%〜3% の割引あり）を選択するか、金額を自由に入力して、支払い方法を選んでください：

![支払い方法と引き換えコード](/img/start/api-09-payment.png)

| 方法 | 説明 |
| - | - |
| Alipay（支付宝） | 定番のチャージ方法。最低金額の制限なし |
| Waffo Pancake | 最低チャージ額は $100 |
| 引き換えコード | 「お持ちの引き換えコードはありますか？」エリアに入力して**クォータを引き換え**をクリック |

**サブスクリプションプラン**：Codex アカウントプールの月額パッケージ（$20 / $200 / $2,000 の 3 つの容量区分）を購入できます。購入後は `codex-sub-june` グループで API Key を作成して利用します。詳細は [サブスクリプションプラン](/ja/subscription-plans) をご覧ください：

![サブスクリプションプランタブ](/img/start/api-10-subscription.png)

<Callout type="idea" title="新規ユーザー特典">
  新規登録したアカウントには自動的に **$0.2** のトライアル残高が付与され、そのまま API 呼び出しのテストに使えます。
</Callout>

<Callout type="idea" title="倍率の説明">
  グループ名の倍率は消費係数を表し、数値が小さいほど同じリクエストの課金が少なくなります。たとえば `0.5x` グループでは、1 人民元の消費が公式定価で 2 人民元分の Token 量に相当します。詳細は [課金ルールとグループ](/ja/billing-groups) をご覧ください。
</Callout>

## 3. アカウントセキュリティ

**コンソール → セキュリティとアクセス**でアカウントのセキュリティ設定を管理できます：

![セキュリティとアクセスページ](/img/start/api-12-security.png)

| 機能 | 説明 |
| - | - |
| パスワード変更 | 定期的に変更を。8 文字以上で、英大文字・小文字と数字を含めること |
| アカウント連携 | GitHub / LinuxDO / Google を連携するとワンクリック認証ログインが可能 |
| ログインセッション | 現在ログイン中のデバイスを確認し、他のセッションをリモートでログアウトできます |
| アクセストークン | パネル API を呼び出す際に使用。権限を選んで作成します |
| Passkey ログイン | パスキーによるログインで、パスワード不要 |
| 2 段階認証 | アカウントに追加のセキュリティ層を設けます |

### API Key のセキュリティに関する推奨事項

- **定期的なローテーション**：30〜90 日ごとに Key を交換し、漏えいリスクを下げることを推奨します
- **平文での保存を避ける**：API Key をコードに直接書いたり Git リポジトリにコミットしたりしない。環境変数の使用を推奨します
- **最小権限の原則**：プロジェクトごとに独立した Key を作成すると、管理と追跡がしやすくなります
- **漏えい時の対応**：Key の漏えいが疑われる場合は、**API キー**ページですぐにその Key を削除し、新しい Key を作成してください

<Callout type="warn" title="注意">
  Key の削除は取り消せません。削除するとその Key は直ちに無効になり、その Key を使っていたツールは呼び出しを続けられなくなります。
</Callout>

## 4. よくある質問

### 登録時に確認コードが届かない場合は？

1. メールドメインが対応リストに含まれているか確認する（qq.com / 126.com / 163.com / gmail.com）
2. 迷惑メール/ゴミ箱フォルダを確認する
3. 1〜2 分待ってから再試行する。連続してリクエストしない
4. それでも届かない場合は、GitHub / LinuxDO / Google のサードパーティー認証ログインに切り替える

### API Key は作成後どこで確認できますか？

**コンソール → API キー**へ進むと、作成済みの Key が一覧に表示されます。コピーボタンをクリックすれば、`sk-xxx` 形式の API Key を取得できます。

### チャージが反映されない場合は？

1. 支払いが成功しているか確認する（Alipay などの取引履歴を確認）
2. 1〜5 分待つ。システムに一時的な遅延がある場合があります
3. コンソールのウォレットページを再読み込みする
4. 10 分経っても反映されない場合は、[お問い合わせ](https://fishxcode.com/contact) から支払い記録を添えてご連絡ください

### 消費明細はどこで確認できますか？

**コンソール → 使用ログ**へ進むと、API 呼び出しごとに以下を確認できます：

- 呼び出し時刻とモデル名
- Token 消費量と費用
- リクエスト元 IP と詳細な記録

その他のログタイプ（監査ログ、タスクログ）はサイドバーで切り替えて確認できます。
