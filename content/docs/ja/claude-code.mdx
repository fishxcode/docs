## プラットフォームの注意点

Claude Code は Anthropic 互換プロトコルで接続します。クライアントに Base URL / API Key のカスタム項目がある場合は上記の情報で入力してください。ベース URL は `https://api.fishxcode.com` です。完全なアドレスが必要な場合は `/v1/messages` などのパスを追加してください。
