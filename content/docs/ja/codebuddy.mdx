> 初めてご利用の方は、先に [アカウント登録とチャージ](/ja/account) を完了し、[FishXCode コンソール](https://fishxcode.com/console/token) で API Key を取得してください。

## 1. CodeBuddy Code をインストールして起動する

このチュートリアルで設定するのは、Tencent Cloud のコマンドラインツール **CodeBuddy Code** です。ローカルに Node.js 18.0 以降がインストールされていることを確認してから、インストールしてください。

```bash
npm install -g @tencent-ai/codebuddy-code
```

バージョンを確認します。

```bash
codebuddy --version
```

CodeBuddy Code を起動します。

```bash
codebuddy
```

初回起動時は、画面の案内に従ってログインを完了してください。その後、コマンドラインで `/model` と入力すると、カスタムモデルが正しく読み込まれたかを確認できます。

## 2. CodeBuddy の設定ファイルを開く

CodeBuddy Code では、ローカルの `models.json` でカスタムモデルを接続できます。設定ファイルの場所は次のとおりです。

- macOS / Linux：`~/.codebuddy/models.json`
- Windows：`C:\Users\<ユーザー名>\.codebuddy\models.json`

ディレクトリやファイルがない場合は、先に作成してください。

## 3. FishXCode のモデル設定を書き込む

CodeBuddy Code のサードパーティ LLM の設定では、OpenAI Chat Completions 互換のプロトコルを使います。ここでの `vendor: "OpenAI"` はプロトコルの互換性を表すもので、OpenAI のモデルしか指定できないという意味ではありません。Claude モデルも FishXCode の OpenAI 互換インターフェース経由で呼び出せます。

次の内容を `~/.codebuddy/models.json` に書き込みます。

```json
{
  "models": [
    {
      "id": "gpt-5.5",
      "name": "FishXCode GPT-5.5",
      "vendor": "OpenAI",
      "apiKey": "sk-あなたのFishXCode-Token",
      "url": "https://api.fishxcode.com/v1/chat/completions"
    },
    {
      "id": "claude-opus-4-7",
      "name": "FishXCode Claude Opus 4.7",
      "vendor": "OpenAI",
      "apiKey": "sk-あなたのFishXCode-Token",
      "url": "https://api.fishxcode.com/v1/chat/completions"
    }
  ],
  "availableModels": [
    "gpt-5.5",
    "claude-opus-4-7"
  ]
}
```

<Callout type="warn" title="重要">
  - `sk-あなたのFishXCode-Token` は、FishXCode コンソールで作成した実際の API Key に置き換えてください。
  - `availableModels` には、上記の `models[].id` にあるモデル ID を必ず含めてください。含まれていないと、`/model` に追加したモデルが表示されないことがあります。
  - サードパーティの中継サービスでは、Chat Completions の完全なアドレス `https://api.fishxcode.com/v1/chat/completions` が必要です。
</Callout>

## 4. Tencent の Coding Plan と FishXCode を併用する

Tencent 公式の Coding Plan も引き続き使いたい場合は、同じ `models.json` に FishXCode のモデルを追加できます。

```json
{
  "models": [
    {
      "id": "tc-code-latest",
      "name": "Auto",
      "vendor": "Tencent Cloud",
      "apiKey": "YOUR_TENCENT_CODING_PLAN_KEY",
      "url": "https://api.lkeap.cloud.tencent.com/coding/v3"
    },
    {
      "id": "gpt-5.5",
      "name": "FishXCode GPT-5.5",
      "vendor": "OpenAI",
      "apiKey": "sk-あなたのFishXCode-Token",
      "url": "https://api.fishxcode.com/v1/chat/completions"
    },
    {
      "id": "claude-opus-4-7",
      "name": "FishXCode Claude Opus 4.7",
      "vendor": "OpenAI",
      "apiKey": "sk-あなたのFishXCode-Token",
      "url": "https://api.fishxcode.com/v1/chat/completions"
    }
  ],
  "availableModels": [
    "tc-code-latest",
    "gpt-5.5",
    "claude-opus-4-7"
  ]
}
```

## 5. 再起動してモデルを選択する

1. `~/.codebuddy/models.json` を保存します
2. 実行中の CodeBuddy Code を完全に終了します
3. `codebuddy` を再実行します
4. `/model` と入力します
5. `gpt-5.5` または `claude-opus-4-7` を選択します
6. テスト用のプロンプトを送信します（例：`現在のプロジェクト構成を説明して`）

## よくある質問

### `/model` にモデルが表示されない

まず `availableModels` を確認してください。モデル ID は、`models[].id` と `availableModels` の両方に含まれている必要があります。

### モデルは表示されるが呼び出しに失敗する

まず `url` を確認してください。FishXCode のサードパーティモデルの設定では、完全なアドレス `https://api.fishxcode.com/v1/chat/completions` を使う必要があります。

### 認証に失敗する

コンソールから API Key をコピーし直し、余分なスペースや改行が含まれていないか確認してください。
