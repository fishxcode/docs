<Callout type="info" title="プロジェクト概要">
  Hermes Agent は Nous Research が提供する汎用 AI エージェントで、CLI での対話、ツール呼び出し、メモリー、スキル、ゲートウェイ、定期タスクに対応しています。公式にサポートされているクラウドサービスに接続できるほか、任意の OpenAI 互換エンドポイントにも接続できます。

  - 公式サイト：[https://hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com)
  - ドキュメント：[https://hermes-agent.nousresearch.com/docs](https://hermes-agent.nousresearch.com/docs)
  - GitHub：[https://github.com/NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)
  - Web3Hermes：[https://web3hermes.com](https://web3hermes.com)
</Callout>

## 前提条件

- FishXCode の API Key を取得済みであること（[コンソールで取得](https://fishxcode.com/keys)）
- ローカル環境で `git` が使えること
- ローカル環境で `python3` が使えること

## Hermes をインストールする

<Callout type="info" title="動作環境">
  - macOS / Linux / WSL2
  - Windows では PowerShell から直接インストールできますが、WSL2 を優先して使うことをおすすめします
  - インストーラーが Python、Node.js、ripgrep、ffmpeg などの依存関係を自動で処理するため、事前に手動でインストールする必要はありません
</Callout>

### おすすめ：Web3Hermes をインストールする

中国本土のユーザーにより適したデスクトップブラウザー向けの画面を使いたい場合は、[Web3Hermes](https://web3hermes.com) を優先してインストールすることをおすすめします。Hermes Agent をベースにした軽量な Web インターフェースで、公式の README は [Web3CZ/Web3Hermes](https://raw.githubusercontent.com/Web3CZ/Web3Hermes/refs/heads/main/README.md) で確認できます。

```bash
git clone https://github.com/Web3CZ/Web3Hermes.git
cd Web3Hermes
python3 bootstrap.py
```

プロジェクトディレクトリ内の起動スクリプトを使うこともできます。

```bash
./start.sh
```

サービスはデフォルトで `http://127.0.0.1:8787` で起動します。

### Hermes Agent CLI をインストールする

```bash tab="中国本土ミラー（推奨）"
curl -fsSL https://res1.hermesagent.org.cn/install.sh | bash
```

```bash tab="公式インストーラー"
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

```powershell tab="Windows PowerShell"
irm https://res1.hermesagent.org.cn/install.ps1 | iex
```

インストールが完了したら、ターミナルの設定を再読み込みします。

```bash
source ~/.zshrc
```

`bash` を使っている場合は、次に置き換えてください。

```bash
source ~/.bashrc
```

Windows PowerShell を使っている場合は、ターミナルを閉じて開き直すだけで構いません。

<Callout type="idea" title="ヒント">
  中国本土のネットワーク環境でインストールする場合は、`https://hermesagent.org.cn` が提供するミラーを優先して使うと、通常は成功率が高くなります。
</Callout>

## FishXCode を設定する

Hermes 公式は、`hermes model` による対話形式の設定を推奨しています。FishXCode は OpenAI 互換インターフェースを提供しているため、ここでは **Custom endpoint** を選択します。

インストール後に初期設定をまとめて済ませたい場合は、次のコマンドも使えます。

```bash
hermes setup
```

ツールの権限だけを追加で設定したい場合は、次を実行します。

```bash
hermes tools
```

### 方法 1：`hermes model` で対話形式に設定する（推奨）

次を実行します。

```bash
hermes model
```

画面の案内に従って、次の内容を入力します。

- Provider：`Custom endpoint (self-hosted / VLLM / etc.)`
- API base URL：`https://api.fishxcode.com/v1`
- API key：FishXCode のトークン
- Model name：`gpt-6.2-sol`
- Context length：`65536` 以上を推奨

設定が完了すると、Hermes はモデル、プロバイダー、アドレスを `~/.hermes/config.yaml` に書き込みます。

<Callout type="warn" title="重要">
  Hermes には、動作に必要なモデルのコンテキスト長に最低要件があります。カスタムエンドポイントでは、コンテキストウィンドウが `64K` 以上のモデルを優先して選んでください。そうしないと、複数ステップのツール呼び出しや長いコンテキストを扱うタスクが拒否されたり、正常に動作しなかったりすることがあります。
</Callout>

### 方法 2：設定ファイルを手動で編集する

Hermes のメイン設定ファイルは `~/.hermes/config.yaml` にあります。ディレクトリがない場合は、先に作成してください。

```bash
mkdir -p ~/.hermes
touch ~/.hermes/config.yaml
touch ~/.hermes/.env
```

次に、`~/.hermes/.env` にトークンを書き込みます。

```bash
OPENAI_API_KEY=sk-あなたのFishXCode-Token
```

さらに、次の内容を `~/.hermes/config.yaml` に書き込みます。

```yaml
model:
  default: gpt-6.2-sol
  provider: custom
  base_url: https://api.fishxcode.com/v1
```

<Callout type="idea" title="ヒント">
  カスタムエンドポイントの場合、Hermes は `config.yaml` の `provider`、`default`、`base_url` を優先して読み込みます。API Key は `config.yaml` に直接書くことも、上記のように `~/.hermes/.env` の `OPENAI_API_KEY` に設定することもできます。キーを平文で書かずに済むよう、`.env` の利用をおすすめします。
</Callout>

## モデルを切り替える

FishXCode が対応しているほかのモデルを使いたい場合は、`model.default` を変更するか、`hermes model` を再実行するだけです。

例：

```yaml
model:
  default: claude-fable-5-2
  provider: custom
  base_url: https://api.fishxcode.com/v1
```

<Callout type="warn" title="注意">
  これは、そのモデルに FishXCode の OpenAI 互換エンドポイントからアクセスでき、かつコンテキストウィンドウが Hermes の最低要件を満たしていることが前提です。正確なモデル ID がわからない場合は、先に [対応モデル](/ja/models) ページを確認してから `default` フィールドに入力してください。
</Callout>

## 起動して使う

そのまま対話を始めます。

```bash
hermes
```

テストメッセージを直接 1 件送ることもできます。

```bash
hermes chat -q "一文で返信してください：FishXCode に接続しました"
```

設定に成功していれば、セッション内で `/model` を使って、接続済みのモデルに切り替えることもできます。

## 設定を確認する

まず次の 3 つを確認してください。

```bash
hermes doctor
```

```bash
hermes config check
```

```bash
hermes chat -q "ok とだけ返信してください" -Q
```

最後のコマンドで正常に応答が返れば、FishXCode への接続は有効になっています。

## よくある質問

### なぜ `Custom endpoint` を選ぶのですか？

Hermes 公式は、任意の OpenAI 互換インターフェースを `provider: custom` に分類しているためです。FishXCode の接続方式はまさにこのパターンに当てはまるため、Hermes 専用のアダプターを別途書く必要はありません。

### `OPENAI_BASE_URL` や `LLM_MODEL` が反映されないのはなぜですか？

Hermes 公式は、この 2 つの古い環境変数を読み込む処理をすでに削除しています。現在は、モデル、プロバイダー、エンドポイントのアドレスは `~/.hermes/config.yaml` の内容が優先されるため、古い変数に頼らないでください。

### Key を設定したのに認証に失敗する場合は？

次の順に確認してください。

1. `base_url` が `https://api.fishxcode.com/v1` になっていること
2. トークンが [FishXCode コンソール](https://fishxcode.com/keys) で取得したものであること
3. `model.default` に有効なモデル ID（例：`gpt-6.2-sol`）が入力されていること
4. モデルのコンテキスト長が `65536` 以上であること
5. `hermes config check` と `hermes doctor` を実行して、具体的なエラーを確認すること

### Windows に直接インストールできますか？

PowerShell からインストールできますが、安定性と互換性の観点から、WSL2 を優先して使うことをおすすめします。ブラウザーの自動操作、依存関係の管理、Unix 系のワークフローでは、通常 WSL2 のほうが安定して動作します。
