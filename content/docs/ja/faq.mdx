## 全般

### FishXCode とは何ですか？

FishXCode はワンストップの AI モデル接続・アカウントサービスプラットフォームです。Claude、Codex、Kiro、Grok、中国産モデル、マルチモーダルモデルをカバーし、さまざまなツールやプラットフォームで利用できます。

### 対応しているツールは？

現在、以下のツールに対応しています：

- **Claude Code** — Anthropic 公式 CLI
- **OpenAI Codex** — OpenAI 公式コーディングアシスタント
- **RooCode** — VS Code 用 AI コーディングプラグイン
- **Qwen Code** — アリババ通義千問（Qwen）のコーディングツール
- **Droid CLI** — 軽量の AI コーディング CLI
- **OpenCode** — オープンソースの AI コーディングターミナルツール

### データのプライバシーはどう守られていますか？

FishXCode は API 中継サービスとしてのみ機能し、コードや会話内容を保存しません。すべてのリクエストは対応するモデルプロバイダーへ直接転送されます。

<Callout type="idea" title="推奨事項">
  機密性の高いプロジェクトでは、利用前に各モデルプロバイダーのプライバシーポリシーをお読みください。
</Callout>

## アカウントと API Key

### 登録するには？

[fishxcode.com/register](https://fishxcode.com/register?aff=9CTW) にアクセスし、ユーザー名、パスワード、メールアドレスを入力し、届いたメール確認コードを入力して登録を完了します。GitHub / LinuxDO / Google によるサードパーティー認証ログインも直接利用できます（初回の認証時にアカウントが自動作成されます）。

<Callout type="idea" title="対応しているメールドメイン">
  現在、メール登録は **qq.com、126.com、163.com、gmail.com** の 4 つのドメインに対応しています。
</Callout>

### API Key を取得するには？

登録後にコンソールへログインし、[API キーページ](https://fishxcode.com/keys) から新しい API Key を作成してください。

### 対応しているチャージ方法は？

**コンソール → ウォレット**からチャージできます。対応方法：

- **Alipay（支付宝）**：定番の方法。最低金額の制限なし
- **Waffo Pancake**：最低チャージ額は $100
- **引き換えコード**：ウォレットページの「クォータを引き換え」エリアに入力して引き換えます

### API Key の有効期間は？

手動で削除または再生成しない限り、API Key は有効であり続けます。セキュリティのため、定期的なローテーションを推奨します。

### 利用量クォータはどのくらいですか？

FishXCode はユーザーごとに利用量クォータを設けており、具体的な数値はプラットフォームのリソース状況に応じて動的に調整されます。コンソール内の利用量情報をご確認ください。

<Callout type="warn" title="注意">
  クォータを使い切るとリクエストは拒否されます。利用量は計画的にご利用ください。
</Callout>

## ツール設定

### 環境変数を設定したのに効かない場合は？

以下のよくある原因を確認してください：

1. **ターミナルを再起動していない** — `.bashrc` / `.zshrc` を変更した後は、`source ~/.bashrc` を実行するか、新しいターミナルを開く必要があります
2. **変数名のスペルミス** — 大文字・小文字は区別されます。`ANTHROPIC_BASE_URL` を `Anthropic_Base_Url` のようには書けません
3. **余分な引用符や空白** — `export KEY="value"` の value の前後に余分な空白を入れないでください

<Accordions type="single">
  <Accordion title="クイック診断コマンド">
    ```bash
    # 変数が設定されているか確認
    echo $ANTHROPIC_BASE_URL
    echo $ANTHROPIC_AUTH_TOKEN

    # 空の場合は、変数が効いていないことを意味します
    ```
  </Accordion>
</Accordions>

### 設定ファイルのパスはどこですか？

| ツール | 設定ファイルのパス |
| - | - |
| Claude Code | 環境変数で設定します |
| Codex | `~/.codex/config.toml` と `~/.codex/auth.json` |
| RooCode | VS Code の設定 JSON |
| Qwen Code | 環境変数で設定します |

### FishXCode のサービスに接続できない場合は？

1. `BASE_URL` が `https://api.fishxcode.com/` または `https://fishxcode.com/` に設定されていることを確認する（どちらも利用可能で、動作は同一です）
2. `fishxcode.com` にネットワーク経由でアクセスできるか確認する
3. 企業ネットワーク内の場合は、プロキシ設定が正しいか確認する

## モデル選択

### 適切なモデルを選ぶには？

利用シーンに応じて選択してください：

| シーン | 推奨モデル | 理由 |
| - | - | - |
| 日常のコーディング | `claude-fable-5-2` | 能力と速度のバランスが良い |
| 高速な補完 | `claude-haiku-5-5` | 応答速度が速い |
| 複雑なアーキテクチャ | `claude-fable-5-2` | 推論能力が強い |

### モデルごとの違いは何ですか？

- **Sonnet シリーズ**：能力がオールラウンドで、ほとんどのコーディングタスクに適しています
- **Haiku シリーズ**：軽量かつ高速で、単純な補完や整形タスクに適しています
- 具体的なモデル能力の違いは、各プロバイダーの公式ドキュメントを参照してください

### モデルを切り替えるには？

環境変数 `ANTHROPIC_MODEL` で指定します：

```bash
export ANTHROPIC_MODEL=claude-fable-5-2
```

## トラブルシューティング

### 認証エラー（Auth Error）と表示される

<Callout type="warn" title="よくある原因">
  - API Key の入力ミス（余分な空白や入力不足）
  - Key がすでに削除または再生成されている
  - `API_KEY` と `AUTH_TOKEN` が両方設定されていない
</Callout>

解決方法：[API キーページ](https://fishxcode.com/keys) で Key の状態を確認し、コピー＆ペーストし直してください。

### エラーログを確認・理解するには？

[コンソール → 使用ログ](https://fishxcode.com/usage-logs/common) に入り、ログタイプを**エラーログ**に切り替えると、時間、モデル、Key、グループ、リクエスト ID、エラーメッセージ、ステータスコードで絞り込めます。

<Callout type="idea" title="調査のヒント">
  - まず API レスポンスやログ内の `request_id` をコピーし、使用ログで同じリクエストを正確に検索する
  - 「エラーメッセージ」で `content` 内のキーワードを検索する。例：`Invalid token`、`Upstream request failed`
  - 「ステータスコード」で問題の種類を素早く集計する。例：`400`、`401`、`403`、`413`、`429`、`500`、`502`、`503`、`504`
  - 同じグループで同一エラーが集中している場合は、まずグループ単位で判断し、設定の問題か、利用量の問題か、上流の可用性の問題かを見極める
</Callout>

フィールドの詳細説明、ステータスコードの分類、よくあるエラー一覧は [エラーロガーの説明](/ja/error-logs) をご覧ください。

### グループ問題の影響範囲はどう判断しますか？

[使用ログ](https://fishxcode.com/usage-logs/common) で「グループ」で絞り込み、同じグループにエラーが集中しているかを観察します。個別のリクエストの失敗は偶発的なことが多く、同じグループで同じエラーが集中している場合はそのグループのリソースプールが影響を受けている可能性が高いです。しばらくしてから再試行するかグループを切り替え、`request_id` で具体的なリクエストを特定してください。

フィールドの説明、ステータスコード分類、よくあるエラーの一覧は [エラーログ解説](/ja/error-logs) をご覧ください。

### リクエストタイムアウト（Timeout）

考えられる原因：

1. ネットワーク遅延が大きい
2. リクエストのコンテキストが長すぎて、モデルの処理に時間がかかっている
3. 現在のサービス負荷が高い

対策：入力コンテキストを小さくするか、しばらく待ってから再試行してください。

### レート制限・クォータ制限の発生（Rate Limit）

`429` ステータスコードを受け取った場合は、通常リクエストが頻すぎることを意味します。上流アカウントの 1 日あたりのクォータを使い切った場合や、現在のモデルのクレデンシャルがクールダウン中の場合も含まれます。

<Callout type="idea" title="対処方法">
  - リクエスト頻度を下げ、数秒間隔をあけて再試行する
  - スクリプトで間隔なしのループ呼び出しを避ける
  - 同じ Key を他のプロセスが同時に使っていないか確認する
  - ログに `Max 10/min` や `Max 5/min` が含まれている場合は、表示に従って同時実行数と 1 分あたりのリクエスト数をしきい値未満に下げる
  - ログに `daily limit exceeded` が含まれている場合は、日次クォータのリセットを待つか、利用可能な他のモデル/グループへ切り替える
  - ログに `cooling down` が含まれている場合は、すぐに連続再試行せず、クールダウンの終了を待つか、一時的に別のモデルへ切り替える
</Callout>

### モデルが利用不可と返される（Model Not Available）

指定したモデル名が正しいか確認し、[クイックスタート](/ja/start) の推奨モデル一覧を参照してください。一部のモデルはまだ FishXCode で利用できない場合があります。
