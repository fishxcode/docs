> 初めてご利用の方は、先に [アカウント登録とチャージ](/ja/account) を完了し、コンソールで API Key を取得してください。

## 1. Cursor の設定を開く

Cursor を開き、右上の設定アイコンをクリックして設定画面を開きます。

## 2. Models を開く

左側のメニューで **Models** をクリックし、モデルと API の設定エリアを開きます。

## 3. モデルを追加して API Key / Base URL を入力する

まず **Add model** をクリックし、OpenAI API の設定エリアで次を入力します。

- **API Key**：FishXCode コンソールで発行したキー
- **Base URL**：`https://api.fishxcode.com/v1`

![Cursor の Models 設定例](/img/start/cursor.png)

図中の番号：

1. 設定の入口
2. Models メニュー
3. Add model
4. API Key の入力欄
5. Base URL の入力欄

## 4. 保存して動作を確認する

1. 新しいチャットを作成します
2. 有効にしたモデルを選択します
3. テスト用のプロンプトを送信します
4. 正常な応答が返ってくれば接続成功です
