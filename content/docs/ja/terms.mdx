## 1. 総則

本規約は、FishXCode API アグリゲーションプラットフォーム（以下「提供者」、「FishXCode」または「当社」といいます）のサービスを利用する法人または個人（以下「ユーザー」または「お客様」といいます）と FishXCode との間で締結されるものです。本規約は、規約本文、プライバシーポリシー、その他の関連するポリシーおよびお知らせで構成されます。**お客様は、本規約を締結するための完全な民事行為能力（満十八歳以上）を有することを確約するものとします。お客様が法人を代表する場合は、十分な権限を有することを保証しなければなりません。**

## 2. 定義

| 用語 | 意味 |
| - | - |
| **サービス** | FishXCode プラットフォームおよびそのすべての構成要素。API、コンソール、SDK、ドキュメント、AI モデルのアグリゲーション／ルーティング／推論サービスを含みます |
| **顧客データ** | お客様がサービスを利用する過程で送信するすべてのデータ、テキスト、指示、プロンプトなどのコンテンツ |
| **モデル出力** | お客様の顧客データに基づき、基盤となる AI モデルによって生成された応答内容 |
| **第三者モデルプロバイダー** | FishXCode と提携し、または FishXCode に統合されている基盤モデルの開発者 |

- サービスは前払い制を採用しており、事前にクレジットを購入する必要があります。
