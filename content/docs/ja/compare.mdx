## 主な特長

| ツール | 主な強み |

| **Claude Code** | 強力なコード理解・生成能力、ネイティブなターミナル体験、複数モデルの切り替えに対応 |

## 選び方

<Callout type="idea" title="ターミナル中心のワークフローを好む場合">
  ターミナルですべての作業を完結させたい場合は、**Claude Code** または **OpenAI Codex** をおすすめします。どちらもスムーズなコマンドライン体験を提供します。Claude Code は設定が最も簡単で、Codex は VSCode にも対応しています。
</Callout>

<Callout type="idea" title="VSCode の GUI 操作を好む場合">
  VSCode 上で操作したい場合は、**RooCode** または **OpenAI Codex** をおすすめします。RooCode は GUI だけで完結し、設定も簡単です。Codex はターミナルとエディターの両方のモードを備えています。
</Callout>

<Callout type="idea" title="とにかく簡単に設定したい場合">
  できるだけ早く使い始めたい場合は、**Claude Code**、**RooCode**、**Qwen Code** をおすすめします。いずれも数分で設定を終えて使い始められます。
</Callout>

<Callout type="idea" title="高度なカスタマイズが必要な場合">
  柔軟なモデル設定と超大規模なコンテキストが必要な場合は、**Droid CLI** をおすすめします。モデルのパラメーターをカスタマイズでき、最大 128 万トークンのコンテキストを設定できます。
</Callout>

<Callout type="idea" title="中国語での開発">
  中国語が中心のプロジェクトには、**Qwen Code** をおすすめします。中国語のコードコメントやドキュメントの理解・生成に優れています。
</Callout>
