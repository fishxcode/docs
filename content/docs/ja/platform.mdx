## 1. プラットフォーム概要

FishXCode は、開発者やチーム向けの AI 接続プラットフォームです。統合的な入り口だと考えてください。手前には公式サイト・料金・ドキュメントがあり、奥にはコンソール・Key・チャージ・請求書・利用記録があります。

プラットフォームは主要な AI モデルを対象に中継サービスを提供しています。具体的なチャネルとモデルは公式サイトの実際の提供状況が優先されるため、[料金ページ](https://fishxcode.com/pricing) でご確認ください。ユーザーは登録から始まり、Key の作成、ツールへの接続、消費の確認まで、一連の流れをすべて同じシステム内で完結できます。

## 3. コンソール機能のクイックリファレンス

ログイン後の操作はすべてコンソールに集約されており、利用シーンごとにすばやく見つけられます：

### 利用を開始する

1. アカウント登録 → コンソールへログイン
2. **API キー**：API Key を作成する（適切なグループを選択）
3. Base URL と API Key をお使いのツールに設定する

### 購入とチャージ

- **ウォレット → 残高チャージ**：Alipay、Waffo Pancake、引き換えコードに対応
- **残高確認**：ウォレットページと概要ページでリアルタイム表示

### 利用の管理

- **使用ログ**：呼び出しごとの記録を確認。モデル、消費、IP などの詳細を含みます
- **API キー**：Key の状態とグループ範囲を確認し、使わなくなった Key を削除または無効化
- **プロフィール**：チェックイン特典と基本統計を確認

### アフターサポート

- **招待リベート**：ウォレットページ下部で紹介プログラムの招待リンクと報酬収益を確認
- **サービスステータス**：呼び出しの異常を調査する際に、各グループが正常かどうかを確認
- **お問い合わせ**：利用上の問題の処理、購入の相談、アフターサポート
