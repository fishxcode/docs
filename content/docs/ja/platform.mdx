## 1. プラットフォームの概要

FishXCode は、開発者やチーム向けの AI 接続プラットフォームです。統一された入口と考えるとわかりやすいでしょう。手前には公式サイト、料金、ドキュメントがあり、その奥にコンソール、トークン、チャージ、請求書、利用記録があります。

プラットフォームは主要な AI モデルを対象に中継サービスを提供しています。具体的なチャネルとモデルは公式サイトの実際の内容が優先されますので、[料金ページ](https://fishxcode.com/pricing) でご確認ください。登録から、トークンの作成、プランの選択、ツールの接続、消費の確認まで、一連の流れはすべて同じシステム内で完結します。

## 3. コンソール機能のクイックリファレンス

ログイン後の操作はすべてコンソールに集約されています。利用シーン別に、目的の機能をすばやく見つけられます：

### 利用開始

1. アカウントを登録 → コンソールにログイン
2. **トークン管理**：API Key を作成（適切なグループを選択）
3. Base URL と API Key をお使いのツールに設定

### 購入とチャージ

- **プラン管理**：利用可能なプランを確認し、ニーズに合ったプランを購読
- **チャージページ**：Alipay、WeChat Pay、引き換えコードに対応
- **残高の確認**：ダッシュボードのトップページにリアルタイムで表示

### 利用管理

- **使用ログ**：各呼び出しの記録を確認（モデル、消費、IP などの詳細を含む）
- **トークン管理**：トークンの状態とグループの範囲を確認し、不要になったトークンを削除
- **個人設定**：デフォルトグループの変更、チェックイン報酬や基本統計の確認

### アフターサービスとサポート

- **請求書管理**：企業や経費精算が必要なユーザーが請求書の発行を申請
- **招待報酬**：招待リンクで新規ユーザーを招待し、報酬の収益を確認
- **サービス状況**：呼び出しの異常を調査する際に、各グループが正常かどうかを確認
- **お問い合わせ**：利用上の問題、購入に関する相談、アフターサポートに対応
