FishXCode プラットフォームは複数のプロバイダーの AI モデルに対応しており、さまざまな利用シーンやツールチェーンをカバーしています。必要に応じて、モデルを自由に選択・切り替えできます。

<ModelCatalog />

## モデルの切り替え

### Claude Code

環境変数でメインモデルを設定します：

```bash tab="Linux/macOS"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL = "claude-fable-5-2"
claude
```

### Codex

`~/.codex/config.toml` を編集し、`model` フィールドを変更します：

```toml
model = "gpt-6.2-sol"
```

### RooCode / Qwen Code

プロバイダー設定の **Model** フィールドを直接変更するだけです。上記の互換モデルであれば、どの ID でも入力できます。
