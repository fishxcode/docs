## プラットフォームの注意点

Command Code は OpenAI 互換プロトコルで接続します。クライアントに Base URL / API Key のカスタム項目がある場合は上記の情報で入力してください。OpenAI 互換エンドポイントのみ対応する場合は、URL に `/v1` が含まれていることを確認してください。
