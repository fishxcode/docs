## Ghi chú về nền tảng

Claude Code kết nối bằng giao thức tương thích Anthropic. Nếu ứng dụng có các trường Base URL / API Key tùy chỉnh, hãy điền theo thông tin ở trên; URL cơ sở là `https://api.fishxcode.com`. Nếu ứng dụng yêu cầu địa chỉ đầy đủ, hãy thêm các đường dẫn như `/v1/messages`.
