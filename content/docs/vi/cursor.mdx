> Lần đầu sử dụng? Hãy hoàn tất [đăng ký tài khoản và nạp tiền](/vi/account) trước, rồi lấy API Key trong bảng điều khiển.

## 1. Mở phần cài đặt của Cursor

Mở Cursor, nhấn biểu tượng cài đặt ở góc trên bên phải để vào trang cài đặt.

## 2. Vào Models

Ở menu bên trái, nhấn **Models** để vào khu vực cấu hình mô hình và API.

## 3. Thêm mô hình và điền API Key / Base URL

Trước tiên nhấn **Add model**, sau đó điền vào khu vực cấu hình OpenAI API:

- **API Key**: key được tạo trong bảng điều khiển FishXCode
- **Base URL**: `https://api.fishxcode.com/v1`

![Ví dụ cấu hình Models trong Cursor](/img/start/cursor.png)

Chú thích trong ảnh:

1. Lối vào cài đặt
2. Menu Models
3. Nút Add model
4. Ô nhập API Key
5. Ô nhập Base URL

## 4. Lưu và kiểm tra hoạt động

1. Tạo cuộc hội thoại mới
2. Chọn mô hình vừa bật
3. Gửi một prompt thử nghiệm
4. Nhận được phản hồi bình thường là kết nối thành công
