## 1. Đăng ký và đăng nhập

### 1. Đăng ký tài khoản

Truy cập [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW), bạn sẽ vào trang đăng ký:

![Trang đăng ký FishXCode](/img/start/api-v2-01-home.png)

Điền vào biểu mẫu đăng ký: đặt tên người dùng và mật khẩu (8–128 ký tự, nên gồm chữ hoa, chữ thường, số và ký tự đặc biệt), đồng thời điền địa chỉ email dùng để nhận mã xác minh:

![Điền thông tin đăng ký](/img/start/api-v2-03-register-form.png)

<Callout type="idea" title="Các tên miền email được hỗ trợ">
  Đăng ký bằng email hiện chỉ hỗ trợ bốn tên miền: **qq.com, 126.com, 163.com, gmail.com**; các tên miền khác có thể không nhận được mã xác minh.
</Callout>

Nhấn **Gửi mã xác minh** (发送验证码), sau khi hoàn tất xác minh Cloudflare, mã xác minh sẽ được gửi vào email của bạn. Tìm mã trong hộp thư (6 ký tự gồm chữ và số) rồi điền vào biểu mẫu:

![Nhập mã xác minh email](/img/start/api-v2-02-register-verify.png)

Nhấn **Tạo tài khoản** (创建账户) để hoàn tất đăng ký; trang sẽ chuyển hướng đến trang đăng nhập kèm thông báo 「Tài khoản đã được tạo! Vui lòng đăng nhập」.

<Callout type="warn" title="Không nhận được mã xác minh?">
  1. Xác nhận tên miền email nằm trong danh sách được hỗ trợ (qq.com / 126.com / 163.com / gmail.com)
  2. Kiểm tra thư mục thư rác
  3. Chờ 1–2 phút rồi thử lại, tránh gửi yêu cầu quá dày
  4. Nếu vẫn không nhận được, hãy dùng đăng nhập ủy quyền qua bên thứ ba
</Callout>

### 2. Đăng nhập

Sau khi đăng ký, đăng nhập bằng tên người dùng và mật khẩu; bạn cũng có thể đăng nhập ủy quyền một chạm bằng tài khoản bên thứ ba:

![Trang đăng nhập](/img/start/api-v2-04-login.png)

| Cách đăng nhập | Mô tả |
| - | - |
| Tài khoản đăng ký bằng email | Đăng nhập bằng tên người dùng/email + mật khẩu |
| GitHub | Đăng nhập ủy quyền, khuyến nghị cho lập trình viên |
| LinuxDO | Đăng nhập ủy quyền cho thành viên cộng đồng |
| Google | Đăng nhập ủy quyền bằng tài khoản Google |

<Callout type="info" title="Ủy quyền bên thứ ba đồng nghĩa với đăng ký">
  Khi lần đầu đăng nhập ủy quyền bằng GitHub / LinuxDO / Google, tài khoản sẽ được tạo tự động, không cần đăng ký riêng.
</Callout>

Sau khi đăng nhập, bạn vào bảng điều khiển (trang tổng quan):

![Tổng quan bảng điều khiển](/img/start/api-v2-05-console.png)

## 2. Lấy API Key

### 1. Tạo API Key

Vào **Bảng điều khiển → API Keys** (API 密钥), nhấn **Tạo API Key** (创建 API 密钥) ở góc trên bên phải:

![Hộp thoại tạo API Key](/img/start/api-v2-06-token-create.png)

Ý nghĩa các trường trong biểu mẫu:

| Trường | Mô tả |
| - | - |
| Tên | Tên khóa tùy ý, dễ nhận biết mục đích sử dụng |
| Nhóm | Quyết định mô hình khả dụng và hệ số tiêu hao, xem giải thích bên dưới |
| Thời hạn | Vĩnh viễn / 1 tháng / 1 ngày / 1 giờ |
| Số lượng | Có thể tạo nhiều khóa cùng lúc (tên tự thêm hậu tố ngẫu nhiên) |
| Hạn mức vô hạn | Bật mặc định; tắt đi thì có thể giới hạn mức tiêu hao tối đa của khóa này |
| Cài đặt nâng cao | Danh sách trắng IP (hỗ trợ CIDR), cho phép tra cứu hạn mức người dùng |

- Với **nhóm**, khuyến nghị chọn <LiveRatio name="claude" /> — đây là pool tài khoản chính thức Claude Max 20 mua theo giá gốc, hiệu năng đầy đủ. Khi dùng gói tháng Codex bắt buộc chọn `codex-sub-june`. Toàn bộ nhóm và hệ số xem tại [Quy tắc tính phí và nhóm](/vi/billing-groups).
- **Danh sách trắng IP** phù hợp với máy chủ có IP đầu ra cố định; khi phát triển cục bộ hãy dùng thận trọng, vì sau khi IP thay đổi sẽ không gọi được nữa.

Nhấn **Lưu thay đổi** (保存更改) để hoàn tất việc tạo. Nhấn nút **Sao chép** (复制) trong danh sách khóa để lấy API Key (định dạng `sk-xxx`):

![Sao chép API Key](/img/start/api-v2-07-token-copy.png)

<Callout type="idea" title="Địa chỉ API">
  Nhấn **API 地址** ở góc trên bên phải trang để xem địa chỉ kết nối. Bảng điều khiển hiển thị mặc định `https://fishxcode.com`; `https://api.fishxcode.com` cũng dùng được, cả hai hoạt động như nhau, chọn địa chỉ nào cũng được.
</Callout>

### 2. Nạp tiền

Vào **Bảng điều khiển → Ví** (钱包), trang có hai tab: **Nạp số dư** và **Gói đăng ký**:

![Nạp số dư trong ví](/img/start/api-v2-08-wallet.png)

**Nạp số dư**: chọn mức tiền có sẵn ($1 / $5 / $10 / $100 / $500 / $1,000, mức lớn có ưu đãi 1%–3%) hoặc nhập số tiền tùy chọn, sau đó chọn phương thức thanh toán:

![Phương thức thanh toán và mã đổi thưởng](/img/start/api-09-payment.png)

| Phương thức | Mô tả |
| - | - |
| Alipay | Phương thức nạp chính, không giới hạn mức tối thiểu |
| Waffo Pancake | Nạp tối thiểu $100 |
| Mã đổi thưởng | Nhập mã trong mục 「有兑换码吗？」 rồi nhấn **Đổi hạn mức** (兑换额度) |

**Gói đăng ký**: mua gói tháng pool tài khoản Codex (ba mức hạn mức $20 / $200 / $2,000); sau khi mua, dùng nhóm `codex-sub-june` để tạo khóa sử dụng, chi tiết tại [Gói đăng ký](/vi/subscription-plans):

![Tab gói đăng ký](/img/start/api-10-subscription.png)

<Callout type="idea" title="Ưu đãi cho người dùng mới">
  Tài khoản mới đăng ký sẽ tự động nhận **$0.2** số dư dùng thử, dùng được ngay để thử nghiệm gọi API.
</Callout>

<Callout type="idea" title="Giải thích hệ số">
  Hệ số trong tên nhóm là hệ số tiêu hao: giá trị càng nhỏ thì cùng một yêu cầu bị trừ càng ít. Ví dụ nhóm `0.5x` tiêu hao 1 yuan tương ứng lượng token như 2 yuan theo giá gốc chính thức. Chi tiết tại [Quy tắc tính phí và nhóm](/vi/billing-groups).
</Callout>

## 3. Bảo mật tài khoản

Vào **Bảng điều khiển → Bảo mật và truy cập** (安全与访问) để quản lý cài đặt bảo mật tài khoản:

![Trang Bảo mật và truy cập](/img/start/api-12-security.png)

| Tính năng | Mô tả |
| - | - |
| Đổi mật khẩu | Đổi định kỳ, từ 8 ký tự trở lên, gồm chữ hoa, chữ thường và số |
| Liên kết tài khoản | Liên kết GitHub / LinuxDO / Google để đăng nhập ủy quyền một chạm |
| Phiên đăng nhập | Xem thiết bị đang đăng nhập, có thể đăng xuất các phiên khác từ xa |
| Token truy cập | Dùng khi gọi API của bảng điều khiển, tạo theo quyền đã chọn |
| Đăng nhập Passkey | Đăng nhập bằng khóa truy cập, không cần mật khẩu |
| Xác minh hai bước | Thêm một lớp bảo vệ cho tài khoản |

### Khuyến nghị bảo mật khóa

- **Xoay vòng định kỳ**: nên đổi khóa mỗi 30–90 ngày để giảm rủi ro rò rỉ
- **Không lưu dạng văn bản rõ**: tránh ghi API Key trực tiếp vào mã nguồn hay commit lên Git; nên dùng biến môi trường
- **Quyền tối thiểu**: tạo khóa riêng cho từng dự án để dễ quản lý và truy vết
- **Xử lý khi rò rỉ**: nếu nghi ngờ khóa bị rò rỉ, lập tức xóa khóa đó trong trang **API Keys** và tạo khóa mới

<Callout type="warn" title="Lưu ý">
  Việc xóa khóa không thể hoàn tác; sau khi xóa, khóa sẽ vô hiệu ngay lập tức và các công cụ đang dùng nó sẽ không thể tiếp tục gọi.
</Callout>

## 4. Câu hỏi thường gặp

### Không nhận được mã xác minh khi đăng ký?

1. Xác nhận tên miền email nằm trong danh sách được hỗ trợ (qq.com / 126.com / 163.com / gmail.com)
2. Kiểm tra thư mục thư rác
3. Chờ 1–2 phút rồi thử lại, tránh gửi yêu cầu quá dày
4. Nếu vẫn không nhận được, hãy dùng đăng nhập ủy quyền GitHub / LinuxDO / Google

### Sau khi tạo API Key, xem ở đâu?

Vào **Bảng điều khiển → API Keys**, các khóa đã tạo sẽ hiển thị trong danh sách. Nhấn nút sao chép để lấy API Key định dạng `sk-xxx`.

### Nạp tiền chưa về tài khoản thì làm sao?

1. Xác nhận thanh toán đã thành công (xem lịch sử giao dịch trên Alipay và các kênh khác)
2. Chờ 1–5 phút, hệ thống có thể có độ trễ ngắn
3. Làm mới trang ví trong bảng điều khiển
4. Nếu quá 10 phút vẫn chưa về, hãy nhờ hỗ trợ qua [Liên hệ với chúng tôi](https://fishxcode.com/contact) kèm hồ sơ thanh toán

### Xem chi tiết tiêu hao ở đâu?

Vào **Bảng điều khiển → Nhật ký sử dụng** để xem của mỗi lần gọi API:

- Thời gian gọi và tên mô hình
- Lượng token tiêu hao và chi phí
- IP yêu cầu và bản ghi chi tiết

Các loại nhật ký khác (nhật ký kiểm toán, nhật ký tác vụ) có thể chuyển xem trong thanh bên.
