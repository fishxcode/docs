## Ghi chú về nền tảng

Gemini CLI kết nối bằng giao thức tương thích OpenAI. Nếu ứng dụng có các trường Base URL / API Key tùy chỉnh, hãy điền theo thông tin ở trên; nếu ứng dụng chỉ hỗ trợ endpoint tương thích OpenAI, hãy đảm bảo URL chứa `/v1`.
