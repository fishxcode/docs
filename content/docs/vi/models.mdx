Nền tảng FishXCode hỗ trợ các mô hình AI từ nhiều nhà cung cấp, bao quát nhiều tình huống sử dụng và chuỗi công cụ khác nhau. Bạn có thể tự do chọn và chuyển đổi mô hình theo nhu cầu thực tế.

<ModelCatalog />

## Chuyển đổi mô hình

### Claude Code

Thiết lập mô hình chính qua biến môi trường:

```bash tab="Linux/macOS"
export ANTHROPIC_MODEL=claude-sonnet-4-5-20250929
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL = "claude-sonnet-4-5-20250929"
claude
```

### Codex

Chỉnh sửa `~/.codex/config.toml`, sửa trường `model`:

```toml
model = "gpt-5"
```

### RooCode / Qwen Code

Sửa trực tiếp trường **Model** trong cấu hình nhà cung cấp. Có thể điền ID của bất kỳ mô hình tương thích nào ở trên.
