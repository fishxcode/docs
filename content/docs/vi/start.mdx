## 1. Chuẩn bị môi trường

### Cài đặt Node.js

Claude  Code được cài qua npm, nên trước tiên hãy xác nhận Node.js đã sẵn sàng.

```bash tab="macOS — kiểm tra"
node -v
npm -v
```

```bash tab="macOS — cài bằng Homebrew"
brew install node
```

```bash tab="Windows — kiểm tra (CMD/PowerShell)"
node -v
npm -v
```

Nếu chưa cài, hãy tải gói cài cho nền tảng của bạn tại [nodejs.org/zh-cn/download](https://nodejs.cn/download/current/); sau khi cài xong **Windows cần khởi động lại**.

### Riêng Windows: cài Git Bash

Claude  Code phụ thuộc môi trường chạy bash, nên người dùng Windows cần cài Git Bash:

1. Tải tại: [git-scm.com/install/windows](https://git-scm.com/install), chọn phiên bản phù hợp để cài.
2. Kiểm tra: nhấp chuột phải trên desktop, nếu xuất hiện tùy chọn **Open Git Bash here** là cài thành công.

## 3. Cấu hình FishXCode

1. Nhập `npx zcf` trong terminal rồi nhấn Enter để chạy.
   Khi hiện `Ok to proceed? (y)`, nhập `y` và nhấn Enter.

2. Chọn ngôn ngữ hiển thị của ZCF:
   chọn **简体中文**.

3. Sau khi cài xong, chọn:
   `1. 完整初始化 - 安装 Claude Code + 导入工作流 + 配置 API 或 CCR 代理 + 配置 MCP 服务`

4. Có sửa cấu hình ngôn ngữ mẫu không:
   chọn `No`

5. Ngôn ngữ xuất của AI:
   chọn `简体中文`

6. Có cài Claude không:
   chọn `Yes`

7. Chế độ cấu hình API:
   chọn `自定义 API 配置`

8. Nhà cung cấp API:
   chọn `自定义配置`

9. Tên cấu hình:
   đặt tên tiếng Anh tùy ý

10. Loại xác thực:
    chọn `API Key`

11. URL cơ sở của API:
    ```
    https://api.fishxcode.com
    ```
    <Callout type="idea" title="Địa chỉ kết nối">
      Cả `https://api.fishxcode.com` và `https://fishxcode.com` đều dùng làm địa chỉ kết nối được, hai địa chỉ hoạt động như nhau, chọn địa chỉ nào cũng được.
    </Callout>

12. API Key:
    điền API Key đã tạo trong bảng điều khiển FishXCode (Bảng điều khiển → API Keys / API 密钥)

13. Cấu hình liên quan đến mô hình:
    chỉ cần nhấn Enter để bỏ qua với mặc định

14. Loại quy trình làm việc:
    chọn `通用工具`

15. Phong cách xuất nội dung:
    chọn theo sở thích cá nhân

16. Có cấu hình MCP không:
    chọn `Yes`

17. Dịch vụ MCP:
    dùng phím cách để chọn dịch vụ cần dùng, nhấn Enter để chạy

18. Cấu hình CCometixLine:
    nhấn Enter luôn

19. Quay lại menu chính, nhập:
    ```
    q
    ```

20. Nhập trong terminal:
    ```
    claude
    ```
    - chọn `Yes, I trust this folder`
    - ở bước chọn API, bắt buộc chọn **YES (tùy chọn đầu tiên)**

## 5. Chuyển đổi mô hình

Nhập `/model` trong giao diện hội thoại của Claude  Code là có thể chuyển mô hình:

| Tùy chọn | Mô hình thực tế | Mô tả |
| - | - | - |
| **Default** | `claude-fable-5-2` + `claude-haiku-5-5` | Tự chọn theo tác vụ, khuyến nghị dùng hằng ngày |
| **Opus** | `claude-opus-5-5` | Khả năng suy luận mạnh nhất, tiêu hao cao hơn |
| **Haiku** | `claude-haiku-5-5` | Nhẹ và nhanh |

Cũng có thể cố định mô hình bằng biến môi trường:

```bash tab="macOS/Linux"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL="claude-fable-5-2"
claude
```

<Callout type="idea" title="Nâng cấp Claude Code">
  Nếu thấy phiên bản mô hình chưa phải mới nhất, hãy chạy lệnh nâng cấp rồi khởi động lại các công cụ liên quan:

  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
</Callout>

## 6. Tích hợp IDE

### IntelliJ IDEA

Đường dẫn thao tác: File → Settings → Plugins → Marketplace → tìm `claude code`, tìm thấy **Claude  Code Terminal** rồi cài:

![Cài Claude  Code Terminal](/img/start/idea-01-install.png)

Sau khi cài xong, khởi động lại IDEA và xác nhận plugin đã được nạp:

![Xác nhận plugin đã nạp](/img/start/idea-02-verify.png)

<Callout type="info">
  Nếu không tìm thấy trong chợ plugin, nghĩa là phiên bản IDEA hiện tại đã quá cũ, cần nâng cấp lên phiên bản mới nhất.
</Callout>

### VSCode

Nhấn `Ctrl + Shift + X` để mở bảng tiện ích mở rộng, tìm `claude code`, tìm thấy **Claude  Code for VSCode** rồi cài.

![Tìm và cài tiện ích Claude  Code](/img/start/vscode-01-install.png)

Sau khi cài xong, tiện ích cung cấp ba cách kết nối:

![Ba cách kết nối của tiện ích Claude  Code](/img/start/vscode-02-login.png)

Khuyến nghị cấu hình kết nối FishXCode qua `settings.json`. Nhấn **biểu tượng bánh răng** ở góc dưới bên phải tiện ích → **Edit in settings.json** (在 settings.json 中编辑):

![Mở settings.json để chỉnh sửa](/img/start/vscode-03-settings.png)

Thêm vào `settings.json` của VSCode:

```json
{
  "claudeCode.preferredLocation": "panel",
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "替换为您的 API Key" },
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.fishxcode.com/" }
  ]
}
```

<Callout type="idea" title="Địa chỉ kết nối">
  Trong `ANTHROPIC_BASE_URL` cũng có thể điền `https://fishxcode.com/`, hai địa chỉ hoạt động như nhau, chọn địa chỉ nào cũng được.
</Callout>

![Ví dụ cấu hình settings.json](/img/start/vscode-04-config.png)

Sau khi lưu, **thoát và mở lại VSCode**, tiện ích sẽ kết nối FishXCode bình thường.

![Dùng Claude  Code trong VSCode](/img/start/vscode-05-demo.gif)

## 7. Câu hỏi thường gặp

### Xuất hiện lỗi 403

Số dư token không đủ; hãy nạp tiền trong bảng điều khiển rồi thử lại.

### Windows xuất hiện lỗi kết nối bất thường hoặc 400/401

Chạy lại lệnh `setx` trong PowerShell để ghi biến hệ thống, rồi mở lại terminal:

```powershell
setx ANTHROPIC_AUTH_TOKEN "sk-xxx"
setx ANTHROPIC_BASE_URL "https://api.fishxcode.com/"
```

### Hiện thông báo "Unable to connect to Anthropic services"

Nội dung lỗi đầy đủ như sau:

```
Unable to connect to Anthropic services
Failed to connect to api.anthropic.com: ERR_BAD_REQUEST
Please check your internet connection and network settings.
```

Lý do là Claude  Code chưa hoàn tất onboarding nên vẫn đang cố kết nối tới `api.anthropic.com` chính thức. **Không cần VPN**: thêm `"hasCompletedOnboarding": true` vào cuối tệp `~/.claude.json` (chú ý là `.claude.json` trong thư mục home, không phải `.claude/settings.json`) là có thể bỏ qua bước này:

```json
{
  "installMethod": "unknown",
  "autoUpdates": true,
  "projects": { ... },
  "hasCompletedOnboarding": true
}
```

<Callout type="idea">
  Trước khi thêm, nhớ bổ sung dấu phẩy ở cuối trường đứng trước (yêu cầu của cú pháp JSON). Sau khi sửa, chạy lại `claude` là kết nối được bình thường.
</Callout>
