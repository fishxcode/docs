## Cài RooCode trong VSCode

1. Tìm [RooCode](https://marketplace.visualstudio.com/items?itemName=RooVeterinaryInc.roo-cline) trong VSCode và cài đặt
2. Truy cập [https://fishxcode.com/console/token](https://fishxcode.com/console/token) để lấy API Key của bạn

## Thêm nhà cung cấp

Sau khi cài RooCode, mở RooCode, chọn cấu hình nhà cung cấp và thêm một nhà cung cấp kiểu OpenAI Compatible:

| Mục cấu hình | Giá trị |
| - | - |
| **OpenAI Base URL** | `https://api.fishxcode.com/v1` |
| **API Key** | Key bạn đã tạo trong FishXCode |
| **Mô hình** | `gpt-5` |

<Callout type="idea" title="Mẹo">
  Bạn cũng có thể đổi sang các mô hình khác như `glm-4.5`, `glm-4.6` hoặc `deepseek-v3.1`.
</Callout>

Cấu hình xong, chỉ cần lưu lại là có thể sử dụng.
