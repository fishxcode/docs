## Установка Codex

```bash tab="pnpm"
pnpm install -g @openai/codex
```

```bash tab="npm"
npm install -g @openai/codex
```

```bash tab="yarn"
yarn global add @openai/codex
```

```bash tab="bunx"
bunx --global @openai/codex
```

## Настройка переменных окружения

1. Получите API Key на странице [https://fishxcode.com/console/token](https://fishxcode.com/console/token)

2. Создайте файл `~/.codex/config.toml` и добавьте в него конфигурацию:

   ```toml
   model_provider = "fishxcode"
   model = "gpt-6.2-sol"
   review_model = "gpt-6.2-sol"
   model_reasoning_effort = "medium"
   model_reasoning_summary = "detailed"
   disable_response_storage = true
   preferred_auth_method = "apikey"
   model_verbosity = "high"

   [model_providers.fishxcode]
   name = "OpenAI using Chat Completions"
   base_url = "https://api.fishxcode.com/v1"
   wire_api = "responses"
   requires_openai_auth = true

   [features]
   skills = true
   image_generation = false

   ```

3. Создайте файл `~/.codex/auth.json` и укажите в `OPENAI_API_KEY` ваш API Key FishXCode:

   ```json
   {
     "OPENAI_API_KEY": "your_api_key_here"
   }
   ```

## Запуск

```bash
cd my-project
codex
```

## Использование в VSCode

1. Установите расширение Codex

2. Откройте настройки и переключитесь в режим редактирования JSON

3. Добавьте параметры:

   ```json
   {
     "chatgpt.apiBase": "https://api.fishxcode.com/v1",
     "chatgpt.config": {
       "preferred_auth_method": "api_key",
       "model_provider": "fishxcode"
     }
   }
   ```

4. Нажмите значок Codex, чтобы начать работу
