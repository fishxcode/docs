Месячный пакет пула Codex Pro работает на официальном пуле аккаунтов Codex Pro: вы покупаете фиксированную квоту на месяц. Он подходит для интенсивного программирования с Codex и разработки агентов. Сейчас в продаже только эта серия тарифов, в ней три уровня:

| Тариф | Цена | Квота тарифа | Фактический коэффициент стоимости | Срок действия | Сброс квоты | Когда подходит |
| - | - | - | - | - | - | - |
| Месячный пакет с квотой 2000 долларов | $260 | $2,000 | 0.13x | 1 календарный месяц | Не сбрасывается | Интенсивная разработка и корпоративные команды |
| Месячный пакет с квотой 200 долларов | $30 | $200 | 0.15x | 1 календарный месяц | Не сбрасывается | Средняя квота, оптимальный выбор для повседневной разработки |
| Месячный пакет с квотой 20 долларов | $3.60 | $20 | 0.18x | 1 календарный месяц | Не сбрасывается | Для первого знакомства, гибкое использование |

Актуальные цены и доступность для покупки смотрите на [странице цен](https://fishxcode.com/pricing).

## Как пользоваться после покупки

1. Купите месячный пакет Codex с нужной квотой.
2. В консоли выберите группу `codex-sub-june`.
3. Создайте в этой группе новый API-токен.
4. Укажите токен в поддерживаемом клиенте, например [Codex](/ru/codex) или [Codex Desktop](/ru/codex-desktop), и можно начинать работу.

## Правила тарификации

- У группы `codex-sub-june` фиксированный **коэффициент 1x**.
- Фактический коэффициент стоимости = цена тарифа ÷ квота тарифа.
- Квота тарифа списывается по фактическому расходу токенов в запросах.
- Срок действия тарифа — 1 календарный месяц.
- Квота тарифа не сбрасывается, а неиспользованная квота автоматически не продлевается.

<Callout type="idea" title="Пример">
  Квота $2,000 покупается за $260: фактический коэффициент стоимости составляет **0.13x**, но у группы по-прежнему отображается коэффициент 1x.
</Callout>

## Важные замечания

<Callout type="warn" title="Квоту месячного пакета можно использовать только в группе codex-sub-june">
  Для месячного пакета Codex токен нужно создавать в группе `codex-sub-june`: в других группах квота этого тарифа не действует.
</Callout>

- Квота месячного пакета не безлимитна: после её исчерпания или окончания срока действия тарифа пользоваться им будет нельзя.
- Если не хотите покупать месячный пакет, можно вызывать группы серии Codex с оплатой по факту с баланса, см. [Правила тарификации и группы](/ru/billing-groups).
