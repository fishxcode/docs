[ZCF](https://github.com/UfoMiao/zcf) — инструмент, который расширяет возможности Claude Code / Codex без ручной настройки: одна команда `zcf init` выполняет всю инициализацию — настраивает API, импортирует рабочие процессы, подключает сервисы MCP и т. д.

> Нет аккаунта? Сначала [зарегистрируйтесь](/ru/account) и получите API Key.

---

## Основные параметры

### Настройка API

| Параметр | Описание |
| - | - |
| `-p custom` | Использовать собственного провайдера (именно так подключается FishXCode) |
| `-t api_key` | Равнозначная запись, действует так же, как `-p custom` |
| `-k "sk-xxx"` | API Key |
| `-u "https://api.fishxcode.com/"` | Base URL FishXCode |
| `-M "claude-sonnet-4-5-20250929"` | Основная модель |
| `-H "claude-haiku-4-5-20251001"` | Быстрая модель |

Пример с указанием моделей:

```bash
npx zcf i -s -t api_key -k "sk-xxx" -u "https://api.fishxcode.com/" \
  -M "claude-sonnet-4-5-20250929" \
  -H "claude-haiku-4-5-20251001"
```

### Рабочие процессы

| Параметр | Описание |
| - | - |
| `-w all` | Установить все рабочие процессы |
| `-w sixStepsWorkflow,gitWorkflow` | Установить выбранные рабочие процессы |
| `-w skip` | Пропустить |

Доступные рабочие процессы: `commonTools` / `sixStepsWorkflow` / `featPlanUx` / `gitWorkflow` / `bmadWorkflow`

### Сервисы MCP

| Параметр | Описание |
| - | - |
| `-m all` | Установить все сервисы MCP |
| `-m context7,open-websearch` | Установить выбранные сервисы |
| `-m skip` | Пропустить |

Доступные сервисы: `context7` / `open-websearch` / `spec-workflow` / `mcp-deepwiki` / `Playwright` / `exa` / `serena`

### Прочее

| Параметр | Описание |
| - | - |
| `-g en` | Задать английский язык для интерфейса, шаблонов и ответов ИИ |
| `-s` | Неинтерактивный режим, все вопросы пропускаются |
| `-r backup` | Стратегия обработки конфигурации (`backup` / `merge` / `docs-only` / `skip`) |
| `-x false` | Не устанавливать строку состояния CCometixLine |

## Команды рабочих процессов

После установки в Claude Code доступны следующие слеш-команды:

| Команда | Описание |
| - | - |
| `/zcf:workflow` | Шестиэтапный процесс разработки (исследование → идеи → план → выполнение → оптимизация → ревью) |
| `/zcf:feat` | Разработка новой функции с планированием и проектированием UI/UX |
| `/zcf:git-commit` | Автоматическая генерация сообщений коммитов Git |
| `/zcf:git-rollback` | Интерактивный откат к предыдущим версиям |
| `/zcf:git-worktree` | Управление Git Worktree |
| `/zcf:bmad-init` | Процесс agile-разработки корпоративного уровня |

## Сервисы MCP

MCP (Model Context Protocol) позволяет Claude Code обращаться к внешним инструментам и сервисам. В ZCF встроены следующие сервисы:

| Сервис | Описание | Нужен ли ключ |
| - | - | - |
| `context7` | Актуальная документация и примеры кода для библиотек | Нет |
| `open-websearch` | Веб-поиск через DuckDuckGo/Bing/Brave | Нет |
| `spec-workflow` | Структурированный процесс «требования → проектирование → реализация» | Нет |
| `mcp-deepwiki` | Поиск по документации репозиториев GitHub | Нет |
| `Playwright` | Автоматизация действий в браузере | Нет |
| `exa` | Семантический поиск Exa AI | Да (`EXA_API_KEY`) |
| `serena` | IDE-ассистент, семантический поиск по коду | Нет |

### Подробнее о сервисах

**context7** — находит актуальную документацию и примеры кода для любой библиотеки, чтобы ИИ не использовал устаревшие API:

```
Найди актуальную документацию и примеры для хука React useState
```

**open-websearch** — поиск сразу в нескольких системах (DuckDuckGo, Bing, Brave), API Key не нужен:

```
Найди в интернете новые возможности TypeScript 5.0
```

**spec-workflow** — структурированный процесс от требований до реализации: анализ требований, техническое проектирование и разбиение на задачи:

```bash
npx -y @pimzino/spec-workflow-mcp@latest --dashboard  # запуск визуальной панели
```

**mcp-deepwiki** — поиск по документации репозиториев GitHub:

```
Найди документацию по Composition API в репозитории vuejs/core
```

**Playwright** — управление браузером: скриншоты, заполнение форм, имитация действий пользователя. При первом запуске нужно скачать браузер.

**exa** — семантический веб-поиск Exa AI, требуется API Key:

```bash
export EXA_API_KEY="your-api-key"  # получите ключ на dashboard.exa.ai
```

**serena** — семантический поиск по коду и умные подсказки для правок, возможности уровня IDE.

### Где находится файл конфигурации

После установки ZCF конфигурация MCP записывается в `~/.claude/settings.json`:

```json
{
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": ["-y", "@context-labs/context7"]
    },
    "open-websearch": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-open-websearch"]
    }
  }
}
```

<Callout type="idea" title="Пользователям Windows">
  ZCF автоматически исправляет формат путей Windows. Если возникли проблемы с подключением MCP, запустите `npx zcf` и выберите `4. Configure MCP` — всё исправится автоматически.
</Callout>

## Обновление

```bash
npx zcf update
# или
npx zcf u -s -g en
```

Обновление синхронизирует только шаблоны рабочих процессов и промпты — **настройки API не меняются**.

## Частые вопросы

### Перезапишется ли существующий settings.json?

Перед изменениями ZCF автоматически создаёт резервную копию в `~/.claude/backup/YYYY-MM-DD_HH-mm-ss/` и предлагает четыре стратегии обработки:

```bash
npx zcf i -s -r backup    # резервная копия и перезапись (по умолчанию)
npx zcf i -s -r merge     # умное слияние
npx zcf i -s -r docs-only # обновить только документы рабочих процессов
npx zcf i -s -r skip      # пропустить, ничего не менять
```

### Как вернуться к ручной настройке?

`settings.json`, созданный ZCF, имеет стандартный формат — его можно редактировать напрямую. Подробнее см. [Настройка Claude Code](/ru/start).

### Требования к версии Node.js

Для ZCF нужен Node.js >= 18:

```bash
node --version
```
