<Callout type="info" title="О проекте">
  OpenClaw — платформа персонального ИИ-ассистента с открытым исходным кодом для самостоятельного размещения: она связывает мессенджеры с ИИ-агентами, работающими на вашем собственном оборудовании. Платформа создана для разработчиков и опытных пользователей, которым нужны автономные ИИ-ассистенты без потери контроля над данными.

  - Официальный сайт: [https://openclaw.ai](https://openclaw.ai)
  - Документация: [https://docs.openclaw.ai](https://docs.openclaw.ai)
  - GitHub: [https://github.com/openclaw/openclaw](https://github.com/openclaw/openclaw)
</Callout>

## Предварительные условия

- Установлен OpenClaw (см. раздел об установке ниже)
- Получен API Key FishXCode ([получить в консоли](https://fishxcode.com/console/token))

## Основные возможности

### Интеграция с несколькими каналами

- **Все платформы**: поддерживаются Feishu (Lark), Discord, Slack, Microsoft Teams и другие
- **Единый шлюз**: все каналы управляются одним процессом Gateway
- **Поддержка голоса**: голосовое взаимодействие на macOS/iOS/Android
- **Интерфейс Canvas**: отрисовка интерактивного интерфейса Canvas

### Самостоятельное размещение и безопасность данных

- **Полностью self-hosted**: работает на вашем компьютере или сервере
- **Открытый исходный код**: лицензия MIT, код полностью прозрачен
- **Локальное хранение данных**: контекст и навыки хранятся локально и не загружаются в облако

### Возможности умного агента

- **Постоянная работа**: работа в фоне и постоянная память
- **Задания по расписанию**: поддержка заданий cron
- **Изоляция сеансов**: сеансы изолируются по агенту, рабочему пространству и отправителю
- **Маршрутизация между агентами**: поддержка совместной работы нескольких агентов
- **Вызов инструментов**: встроенная поддержка вызова инструментов и выполнения кода

## Установка

<Callout type="info" title="Требования к окружению">
  - API Key FishXCode
  - Для установки через npm/git нужен Node.js 22+; при установке одной командой через curl зависимости устанавливаются автоматически
</Callout>

```bash tab="curl (рекомендуется)"
curl -fsSL https://openclaw.ai/install.sh | bash
```

```bash tab="npm"
npm install -g openclaw@latest
```

```bash tab="curl (режим git)"
curl -fsSL https://openclaw.ai/install.sh | bash -s -- --install-method git
```

```bash tab="Ручное клонирование"
git clone https://github.com/openclaw/openclaw.git
cd openclaw && pnpm install && pnpm run build
pnpm run openclaw onboard
```

После установки запустите мастер начальной настройки (для ручного клонирования он уже включён в команды выше):

```bash
openclaw onboard
```

## Настройка

### Расположение файла конфигурации

Файл конфигурации OpenClaw находится в `~/.openclaw/openclaw.json`:

- **macOS**: `/Users/имя_пользователя/.openclaw/openclaw.json`
- **Linux**: `/home/имя_пользователя/.openclaw/openclaw.json`
- **Windows**: `C:\Users\имя_пользователя\.openclaw\openclaw.json`

Если файла нет, сначала создайте его:

```bash tab="macOS / Linux"
mkdir -p ~/.openclaw
touch ~/.openclaw/openclaw.json
```

```powershell tab="Windows (PowerShell)"
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.openclaw"
New-Item -ItemType File -Force -Path "$env:USERPROFILE\.openclaw\openclaw.json"
```

<Callout type="idea" title="Совет">
  Если вы уже запускали `openclaw onboard`, файл конфигурации создан автоматически — достаточно изменить его содержимое.
</Callout>

### Структура файла конфигурации

`openclaw.json` состоит из двух основных частей:

```json
{
  "models": {
    "mode": "merge",
    "providers": {
      // настройка провайдеров моделей ИИ
    }
  },
  "agents": {
    "defaults": {
      // модель по умолчанию, рабочий каталог и т. д.
    }
  }
}
```

- `models.providers` — описание провайдеров: адрес, ключ, список моделей
- `models.mode` — при значении `"merge"` ваша конфигурация объединяется со встроенной конфигурацией по умолчанию; **настоятельно рекомендуем всегда его указывать**
- `agents.defaults.model.primary` — модель по умолчанию в формате `имя_провайдера/ID_модели`
- `api` — тип протокола API: для моделей Anthropic — `"anthropic-messages"`, для OpenAI-совместимых моделей — `"openai-responses"`

### Способы настройки

#### Настройка моделей Anthropic (Claude)

Запишите в `openclaw.json` следующее:

```json
{
  "models": {
    "mode": "merge",
    "providers": {
      "fishxcode-anthropic": {
        "baseUrl": "https://api.fishxcode.com",
        "apiKey": "sk-your-fishxcode-token",
        "api": "anthropic-messages",
        "models": [
          {
            "id": "claude-opus-4-6",
            "name": "Claude Opus 4.6",
            "input": ["text", "image"],
            "contextWindow": 200000,
            "maxTokens": 8192,
            "reasoning": false
          }
        ]
      }
    }
  },
  "agents": {
    "defaults": {
      "model": {
        "primary": "fishxcode-anthropic/claude-opus-4-6"
      }
    }
  }
}
```

<Callout type="warn" title="Важно">
  - Замените `sk-your-fishxcode-token` на реальный токен, полученный в [консоли FishXCode](https://fishxcode.com/console/token)
  - **Для протокола Anthropic не добавляйте `/v1` в `baseUrl`** — SDK сам допишет путь
</Callout>

#### Настройка моделей OpenAI (GPT)

При вызове моделей OpenAI через FishXCode поле `api` должно иметь значение `openai-responses`:

```json
{
  "models": {
    "mode": "merge",
    "providers": {
      "fishxcode-openai": {
        "baseUrl": "https://api.fishxcode.com/v1",
        "apiKey": "sk-your-fishxcode-token",
        "api": "openai-responses",
        "models": [
          {
            "id": "gpt-5",
            "name": "GPT-5",
            "input": ["text", "image"],
            "contextWindow": 200000,
            "maxTokens": 16384,
            "reasoning": true
          }
        ]
      }
    }
  },
  "agents": {
    "defaults": {
      "model": {
        "primary": "fishxcode-openai/gpt-5"
      }
    }
  }
}
```

<Callout type="idea" title="Совет">
  **Для протокола OpenAI `/v1` нужен**, то есть `https://api.fishxcode.com/v1`. Дело в том, что два SDK по-разному собирают путь запроса.
</Callout>

#### Одновременная настройка Anthropic и OpenAI (рекомендуется)

Добавьте в `models.providers` двух провайдеров рядом, чтобы пользоваться моделями обоих семейств:

```json
{
  "models": {
    "mode": "merge",
    "providers": {
      "fishxcode-anthropic": {
        "baseUrl": "https://api.fishxcode.com",
        "apiKey": "sk-your-fishxcode-token",
        "api": "anthropic-messages",
        "models": [
          {
            "id": "claude-opus-4-6",
            "name": "Claude Opus 4.6",
            "input": ["text", "image"],
            "contextWindow": 200000,
            "maxTokens": 8192,
            "reasoning": false
          },
          {
            "id": "claude-sonnet-4-5-20250929",
            "name": "Claude Sonnet 4.5",
            "input": ["text", "image"],
            "contextWindow": 200000,
            "maxTokens": 8192,
            "reasoning": false
          }
        ]
      },
      "fishxcode-openai": {
        "baseUrl": "https://api.fishxcode.com/v1",
        "apiKey": "sk-your-fishxcode-token",
        "api": "openai-responses",
        "models": [
          {
            "id": "gpt-5",
            "name": "GPT-5",
            "input": ["text", "image"],
            "contextWindow": 200000,
            "maxTokens": 16384,
            "reasoning": true
          },
          {
            "id": "gpt-5-codex",
            "name": "GPT-5 Codex",
            "input": ["text", "image"],
            "contextWindow": 200000,
            "maxTokens": 16384,
            "reasoning": true
          }
        ]
      }
    }
  },
  "agents": {
    "defaults": {
      "model": {
        "primary": "fishxcode-anthropic/claude-opus-4-6",
        "fallbacks": [
          "fishxcode-anthropic/claude-sonnet-4-5-20250929",
          "fishxcode-openai/gpt-5"
        ]
      }
    }
  }
}
```

Чтобы сменить модель по умолчанию, достаточно изменить значение `model.primary`:

- `"fishxcode-anthropic/claude-opus-4-6"` → Claude Opus 4.6
- `"fishxcode-anthropic/claude-sonnet-4-5-20250929"` → Claude Sonnet 4.5
- `"fishxcode-openai/gpt-5"` → GPT-5
- `"fishxcode-openai/gpt-5-codex"` → GPT-5 Codex

### Ключевые поля

| Поле | Назначение | Anthropic (Claude) | OpenAI (GPT) |
| - | - | - | - |
| `baseUrl` | Адрес API-прокси | `https://api.fishxcode.com` | `https://api.fishxcode.com/v1` |
| `apiKey` | Ваш API Key | `sk-your-fishxcode-token` | `sk-your-fishxcode-token` |
| `api` | Тип протокола API | `anthropic-messages` | `openai-responses` |
| `mode` | Режим слияния конфигурации | `merge` (рекомендуется) | `merge` (рекомендуется) |
| `models[].id` | ID модели | `claude-opus-4-6` | `gpt-5` |
| `model.primary` | Модель по умолчанию | `fishxcode-anthropic/claude-opus-4-6` | `fishxcode-openai/gpt-5` |
| `reasoning` | Включён ли режим рассуждений | `false` (зависит от модели) | `true` (поддерживается в GPT-5.x) |

## Проверка конфигурации

Чтобы убедиться, что конфигурация применилась, выполните:

```bash
openclaw
```

Если всё настроено правильно, OpenClaw запустится в обычном режиме и будет отправлять запросы через прокси FishXCode.

Список моделей можно проверить командой:

```bash
openclaw models list
```

Текущая модель и состояние аутентификации:

```bash
openclaw models status
```

Комплексная диагностика:

```bash
openclaw doctor
```

## Запуск сервиса

После настройки запустите OpenClaw:

```bash
openclaw start
```

После запуска с ИИ-ассистентом можно общаться через настроенные каналы.

Перезапуск Gateway:

```bash
openclaw gateway restart
```

## Частые вопросы

### Блокировка с ошибкой 403

**Симптом**: провайдер настроен, прямой запрос к API через curl возвращает 200, но запросы из OpenClaw получают 403 Your request was blocked.

**Причина**: OpenClaw внутри использует `@anthropic-ai/sdk` и отправляет запросы с User-Agent официального SDK (например, `Anthropic/JS 0.73.0`), а некоторые CDN и WAF блокируют такой UA.

**Решение**: добавьте в конфигурацию провайдера поле `headers`, чтобы переопределить UA:

```json
{
  "fishxcode-anthropic": {
    "baseUrl": "https://api.fishxcode.com",
    "apiKey": "your-api-key",
    "api": "anthropic-messages",
    "headers": {
      "User-Agent": "Mozilla/5.0"
    },
    "models": [...]
  }
}
```

### Не добавляйте /v1 в baseUrl (протокол Anthropic)

**Симптом**: запрос сразу возвращает 404, а в логах видно, что путь запроса превратился в `/v1/v1/messages`.

**Причина**: Anthropic SDK автоматически дописывает `/v1/messages` после baseURL. Если в baseUrl уже есть `/v1`, путь в запросе удваивается.

**Решение**: для протокола Anthropic указывайте в baseUrl только домен, без `/v1`:

```json
{
  "baseUrl": "https://api.fishxcode.com"
}
```

<Callout type="idea" title="Совет">
  Для протокола OpenAI `/v1` нужен, то есть `https://api.fishxcode.com/v1`. Дело в том, что два SDK по-разному собирают путь запроса.
</Callout>

### Поле api принимает только три значения

**Симптом**: при запуске появляется ошибка Config invalid или настроенный провайдер не виден в списке моделей.

**Причина**: OpenClaw строго проверяет поле `api` и принимает только три значения:

| Значение | Формат |
| - | - |
| `anthropic-messages` | Anthropic Messages API |
| `openai-completions` | OpenAI Chat Completions |
| `openai-responses` | OpenAI Responses API |

Значения вроде `openai-chat`, `openai`, `anthropic` вызовут ошибку.

**Решение**: при работе через FishXCode указывайте `anthropic-messages` для моделей Claude и `openai-responses` для моделей GPT.

### openai-completions возвращает пустые ответы (не используйте для моделей GPT)

**Симптом**: в `api` указано `openai-completions`, запрос выполняется успешно (в логе `isError=false`), но в интерфейсе отображается пустое сообщение.

**Причина**: OpenClaw внутри обрабатывает поток сообщений в формате Anthropic, и ответ в формате OpenAI от `openai-completions` в некоторых случаях не удаётся правильно сопоставить.

**Решение**: при вызове моделей GPT через FishXCode используйте `openai-responses`, а не `openai-completions`.

### Конфигурация изменена, но не применилась

**Симптом**: вы изменили `openclaw.json`, но OpenClaw по-прежнему использует старую конфигурацию.

**Причина**: в OpenClaw конфигурация провайдеров хранится в двух местах, которые нужно синхронизировать:

```
~/.openclaw/openclaw.json              → models.providers
~/.openclaw/agents/main/agent/models.json → providers
```

Если изменить только одно из них, настройки могут не примениться.

**Решение**: после изменения проверьте результат командой:

```bash
openclaw models status
```

Или перезапустите OpenClaw Gateway:

```bash
openclaw gateway restart
```

### Ошибки формата JSON

Типичные ошибки в JSON:

- **Лишняя запятая**: после последнего элемента запятой быть не должно
- **Пропущенная запятая**: соседние пары «ключ — значение» должны разделяться запятой
- **Неправильные кавычки**: JSON принимает только прямые двойные кавычки `"`, китайские и одинарные кавычки не подходят
- **Непарные скобки**: у каждой `{` должна быть парная `}`, у каждой `[` — парная `]`

Проверить формат можно командой:

```bash
python3 -m json.tool ~/.openclaw/openclaw.json
```

### Что такое поле reasoning?

`reasoning` определяет, включён ли у модели режим рассуждений (размышлений). При значении `true` модель сначала рассуждает про себя и только потом отвечает, но расходует больше токенов.

Серия GPT-5.x Codex обычно поддерживает `reasoning`, у моделей Claude это зависит от версии. Если не уверены, укажите `false`.

### Чем отличаются openai-completions и openai-responses?

- **openai-responses** — соответствует OpenAI Responses API (`/v1/responses`). **Используйте его для моделей GPT через FishXCode.**
- **openai-completions** — соответствует OpenAI Chat Completions API (`/v1/chat/completions`), это универсальный совместимый формат, но с моделями GPT в FishXCode он может приводить к пустым ответам, поэтому **не рекомендуется**.

### Шпаргалка по диагностике

| Команда | Назначение |
| - | - |
| `openclaw models status` | Текущая модель и состояние аутентификации |
| `openclaw models list` | Список настроенных моделей |
| `openclaw doctor` | Комплексная диагностика |
| `openclaw gateway restart` | Перезапуск Gateway |

<Callout type="idea" title="Главный принцип диагностики">
  Сначала проверьте через curl, что сам API FishXCode работает, а затем выясните, чем отличаются запросы, которые отправляет OpenClaw (UA, путь, формат).
</Callout>
