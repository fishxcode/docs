## Особенности платформы

Gemini CLI подключается через протокол, совместимый с OpenAI. Если клиент поддерживает собственные поля Base URL / API Key, заполните их данными выше; если он работает только с эндпоинтами, совместимыми с OpenAI, убедитесь, что адрес содержит `/v1`.

## Необязательно: импорт в один клик через CC Switch

Если вы используете несколько каналов Gemini, для быстрого переключения подойдёт [CC Switch](https://github.com/farion1231/cc-switch); если FishXCode — ваш единственный канал, обычно достаточно настройки через переменные окружения выше.

На странице **API-ключи** консоли FishXCode найдите строку нужного ключа и нажмите **Открыть меню → CC Switch**:

![Выбрать «Заполнить в CC Switch» в консоли FishXCode](/img/start/gemini-cli/cc-switch-import-channel.png)

В консоли откроется форма «Заполнить в CC Switch». Выберите `Gemini` в поле **Приложение**, оставьте **Имя** `FishXCode` (легко узнать в списке каналов), выберите `gemini-3.6-flash` как **Основную модель** и нажмите **Открыть CC Switch**:

| Поле | Рекомендуемое значение FishXCode |
| - | - |
| Приложение | `Gemini` |
| Имя | `FishXCode` |
| Основная модель | `gemini-3.6-flash` |

CC Switch покажет диалог «Подтвердите импорт поставщика». Проверьте, что endpoint API — `https://fishxcode.com`, а модель — `gemini-3.6-flash`, затем нажмите **Импортировать**:

![Подтвердить импорт FishXCode в CC Switch](/img/start/gemini-cli/cc-switch-select-model.png)

После импорта FishXCode появится в списке поставщиков:

![FishXCode импортирован и виден в списке поставщиков](/img/start/gemini-cli/cc-switch-import-success.png)

<Callout type="warn" title="Внимание">
  Если включено «Сразу переключиться на этого поставщика после импорта», CC Switch перезаписывает локальную конфигурацию Gemini CLI (`~/.gemini/.env`). При возврате на официальный канал снова выберите его в CC Switch, чтобы не отправлять запросы на неожиданный адрес.
</Callout>
