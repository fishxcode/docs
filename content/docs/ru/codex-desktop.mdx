## Область применения

Это руководство описывает подключение настольного приложения OpenAI Codex к FishXCode. Установка и настройка Codex для командной строки описаны в статье [Использование FishXCode в Codex](/ru/codex); настольному приложению тоже рекомендуем использовать ту же конфигурацию `~/.codex`, чтобы не поддерживать две копии настроек.

<Callout type="idea" title="Рекомендуемый порядок">
  Сначала подготовьте локальную конфигурацию Codex, а уже потом откройте Codex Desktop и войдите. Тогда настольное приложение и CLI будут использовать один и тот же адрес API FishXCode, модель и токен.
</Callout>

## 1. Установка Codex Desktop

Пользователи Windows могут найти `Codex` в Microsoft Store и установить официальное приложение:

![Установка Codex Desktop из Microsoft Store](/img/start/codex-desktop/microsoft-store-codex.png)

После установки не спешите входить — сначала выполните локальную настройку из следующего раздела. Если Microsoft Store недоступен, скачайте установщик через официальные каналы распространения OpenAI или из другого надёжного источника.

## 2. Подключение к FishXCode через общую конфигурацию Codex

Codex Desktop и Codex CLI рекомендуется настраивать через одну и ту же пользовательскую конфигурацию. Она совпадает с описанной в [руководстве по Codex CLI](/ru/codex).

### 1. Создайте каталог конфигурации

```bash tab="macOS/Linux"
mkdir -p ~/.codex
```

```powershell tab="Windows PowerShell"
New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex"
```

### 2. Запишите `config.toml`

Добавьте в `~/.codex/config.toml`:

```toml
model_provider = "fishxcode"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "medium"
model_reasoning_summary = "detailed"
disable_response_storage = true
preferred_auth_method = "apikey"
model_verbosity = "high"

[model_providers.fishxcode]
name = "OpenAI using Chat Completions"
base_url = "https://api.fishxcode.com/v1"
wire_api = "responses"
requires_openai_auth = true

[features]
skills = true
image_generation = false

```

<Callout type="info">
  `model` и `review_model` можно заменить на другие модели, доступные в вашем тарифе и группе. Если сомневаетесь, начните с `gpt-5.4`.
</Callout>

### 3. Запишите `auth.json`

Укажите токен FishXCode в `~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "your_api_key_here"
}
```

<Callout type="warn" title="Внимание">
  `auth.json` содержит секретный ключ: не коммитьте его в Git и никому не передавайте.
</Callout>

## 3. Вход в Codex Desktop

Если после запуска Codex Desktop появится экран входа, выберите **Войти другим способом**:

![Выбор другого способа входа](/img/start/codex-desktop/codex-login-options.png)

Затем вставьте токен, скопированный в консоли FishXCode. Если вы уже записали `~/.codex/auth.json`, но запрос на вход всё равно появляется, вставьте здесь тот же токен.

Чтобы скопировать токен, найдите его на странице токенов консоли FishXCode и нажмите кнопку копирования рядом с ключом. Меню копирования на скриншотах не показано, чтобы иллюстрации к инструкции не раскрывали лишних сведений о ключе.

После входа выберите каталог проекта — папку, с которой должен работать Codex, — и можно начинать.

## 4. Дополнительно: управление несколькими каналами через CC Switch

Если вы используете несколько каналов Codex, переключаться между ними удобно через CC Switch; если вы работаете только с FishXCode, обычно достаточно одного `~/.codex/config.toml`.

На странице токенов консоли FishXCode найдите нужный токен и нажмите **Импорт** в строке группы `codex_sub_june`:

![Импорт группы Codex в консоли FishXCode](/img/start/codex-desktop/cc-switch-import-channel.png)

В окне импорта CC Switch выберите приложение `Codex`; основные поля рекомендуем оставить такими:

| Поле | Рекомендуемое значение для FishXCode |
| - | - |
| Адрес API | `https://api.fishxcode.com/v1` |
| Ключ API | Токен FishXCode |
| Основная модель | `gpt-5.4` или другая модель, доступная в вашем тарифе |

Переключите основную модель на `gpt-5.4` и нажмите **Тест**; импортируйте только после сообщения «Тест пройден / проверка связи с моделью выполнена успешно»:

![Проверка gpt-5.4 в окне импорта CC Switch](/img/start/codex-desktop/cc-switch-select-model.png)

Когда браузер откроет CC Switch, сверьте адрес API, модель и примечание и, если всё верно, нажмите **Импорт**:

![Подтверждение импорта конфигурации Codex для FishXCode](/img/start/codex-desktop/cc-switch-import-success.png)

После настройки убедитесь, что сейчас выбран канал FishXCode, и перезапустите Codex Desktop.

## 5. Основные функции

### Модель, глубина рассуждений и права доступа

Рядом с полем ввода Codex Desktop обычно показывает модель, глубину рассуждений, режим прав доступа и рабочий каталог:

![Параметры диалога в Codex Desktop](/img/start/codex-desktop/codex-dialog-options.png)

Для повседневной работы рекомендуем:

- Модель: выберите модель, доступную в FishXCode, например `gpt-5.4`
- Глубина рассуждений: для обычных задач — средняя, для сложных — выше
- Режим прав доступа: если код приходится часто менять, можно включить полный доступ; в незнакомом проекте сначала оставьте ручное подтверждение
- Рабочий каталог: выберите проект, который нужно проанализировать или изменить

### `/` и `@`

В поле ввода есть два удобных быстрых вызова:

| Символ | Назначение |
| - | - |
| `/` | Открыть список команд или Skill |
| `@` | Сослаться на файл или каталог текущего проекта |

Если меню не открывается, проверьте, что перед `/` или `@` стоит пробел, а фокус находится в поле ввода Codex Desktop.

### Режим планирования

Для сложных задач рекомендуем начинать с Plan Mode. Codex сначала разобьёт задачу на шаги, задаст уточняющие вопросы и приступит к выполнению только после вашего подтверждения.

![Переход в режим планирования](/img/start/codex-desktop/codex-plan-mode.png)

Когда Codex задаёт уточняющие вопросы, выбирайте вариант, который соответствует вашей задаче:

![Ответы на уточняющие вопросы](/img/start/codex-desktop/codex-clarify-question.png)

Утвердив план, поручите Codex его выполнение и по ходу работы следите за объёмом изменений:

![Выполнение плана и отслеживание прогресса](/img/start/codex-desktop/codex-execute-plan.png)

## 6. Частые вопросы

### После входа запросы всё равно идут не через FishXCode?

Проверьте по порядку:

1. Существует ли `~/.codex/config.toml`
2. Равен ли `model_provider` значению `fishxcode`
3. Равен ли `base_url` значению `https://api.fishxcode.com/v1`
4. Записан ли токен FishXCode в `~/.codex/auth.json`
5. Полностью ли вы закрыли и снова открыли Codex Desktop после изменения конфигурации

### Ошибка 401 или 403?

Прежде всего проверьте, что токен скопирован полностью и включён, на балансе достаточно средств, а текущая модель доступна в вашем тарифе или группе.

### Отображается не та модель?

Сначала проверьте `model` в `config.toml`, затем — выбор модели внутри Codex Desktop. Если вы используете CC Switch, убедитесь также, что в нём выбран канал FishXCode.

### Появляется сообщение, что CC Switch не настроен?

Если вы пользуетесь CC Switch и видите похожее сообщение, значит, канал переключён неправильно:

![Сообщение о ненастроенном CC Switch](/img/start/codex-desktop/cc-switch-not-configured.png)

Что сделать:

1. Полностью закройте Codex Desktop, включая процесс в трее
2. Откройте CC Switch и убедитесь, что выбран канал FishXCode
3. Снова откройте Codex Desktop

Если вы не пользуетесь CC Switch, вернитесь к разделу 2 и проверьте `~/.codex/config.toml` и `~/.codex/auth.json` напрямую.
