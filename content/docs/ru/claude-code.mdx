## Особенности платформы

Claude Code подключается через протокол, совместимый с Anthropic. Если клиент поддерживает собственные поля Base URL / API Key, заполните их данными выше; базовый адрес — `https://api.fishxcode.com`. Если клиенту нужен полный адрес, добавьте пути вроде `/v1/messages`.
