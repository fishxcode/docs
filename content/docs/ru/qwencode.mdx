## Установка Qwen Code

```bash tab="pnpm"
pnpm install -g @qwen-code/qwen-code
```

```bash tab="npm"
npm install -g @qwen-code/qwen-code
```

```bash tab="yarn"
yarn global add @qwen-code/qwen-code
```

```bash tab="bunx"
bunx --global @qwen-code/qwen-code
```

## Настройка переменных окружения

```bash tab="Linux/macOS"
export OPENAI_API_KEY="sk-xxx"
export OPENAI_BASE_URL="https://api.fishxcode.com/v1"
export OPENAI_MODEL="gpt-5"
```

```powershell tab="Windows PowerShell"
$env:OPENAI_API_KEY="sk-xxx"
$env:OPENAI_BASE_URL="https://api.fishxcode.com/v1"
$env:OPENAI_MODEL="gpt-5"
```

```cmd tab="Windows CMD"
set OPENAI_API_KEY="sk-xxx"
set OPENAI_BASE_URL="https://api.fishxcode.com/v1"
set OPENAI_MODEL="gpt-5"
```

<Callout type="warn" title="Важно">
  Замените `sk-xxx` на реальный токен, полученный в [консоли FishXCode](https://fishxcode.com/console/token).
</Callout>

## Быстрый запуск

```bash
cd my-project
qwen
```

## Постоянная настройка

Чтобы не задавать переменные окружения каждый раз вручную, добавьте их в файл конфигурации оболочки:

- **Linux/macOS**: добавьте в `~/.bashrc` или `~/.zshrc`
- **Windows PowerShell**: добавьте в `$PROFILE`
