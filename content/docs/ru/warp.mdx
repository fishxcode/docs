## Особенности платформы

Warp подключается через протокол, совместимый с OpenAI. Если клиент поддерживает собственные поля Base URL / API Key, заполните их данными выше; если он работает только с эндпоинтами, совместимыми с OpenAI, убедитесь, что адрес содержит `/v1`.
