## Область применения

Это руководство описывает новый режим Claude Desktop — **подключение стороннего инференса для Cowork / Code**, который в официальной документации Anthropic называется `third-party inference`.

Если вам нужно:

- работать в **Cowork** в настольном приложении Claude
- работать в **Code** в настольном приложении Claude
- направлять запросы в FishXCode через собственный API или шлюз

то вам подходит именно этот способ настройки.

<Callout type="warn" title="Внимание">
  Это не прежний сценарий «войти в аккаунт Claude и сразу общаться». После подключения стороннего инференса вы в основном будете работать во вкладках **Cowork** и **Code**.
</Callout>

## Подготовка

Перед началом:

1. Установите последнюю версию Claude Desktop
2. Подготовьте токен FishXCode
3. Убедитесь, что у токена есть доступ к моделям Claude

Получить токен можно здесь:

- [https://fishxcode.com/console/token](https://fishxcode.com/console/token)

Для начала рекомендуем подготовить эти модели:

- `claude-sonnet-4-5-20250929`
- `claude-opus-4-5-20251101`
- `claude-haiku-4-5-20251001`

## Способ 1. Настройка прямо в Claude Desktop (рекомендуется)

Anthropic официально рекомендует выполнять настройку через встроенный в приложение мастер подключения стороннего инференса.

### 1. Включите Developer mode

В верхнем меню Claude Desktop последовательно выберите:

```text
Help → Troubleshooting → Enable Developer mode
```

После этого в меню приложения появятся пункты `Developer`.

### 2. Откройте настройку стороннего инференса

Затем перейдите в:

```text
Developer → Configure third-party inference
```

Откроется официальный мастер Anthropic для настройки стороннего инференса.

### 3. Выберите режим Gateway

В качестве типа провайдера выберите:

```text
Gateway
```

Собственным API и шлюзам вроде FishXCode соответствует именно режим `gateway`.

### 4. Укажите параметры FishXCode

Основные параметры заполните так:

- Gateway URL: `https://api.fishxcode.com`
- Authentication: `x-api-key`
- API Key: ваш токен FishXCode

Если интерфейс просит указать список моделей, для начала введите:

```text
claude-sonnet-4-5-20250929
claude-opus-4-5-20251101
claude-haiku-4-5-20251001
```

Если в интерфейсе можно включить `Code`, оставьте эту опцию включённой.

### 5. Примените настройки локально

Завершив настройку, выберите:

```text
Apply locally
```

Конфигурация стороннего инференса будет записана в локальные настройки Claude Desktop текущего пользователя.

После успешной настройки перезапустите Claude Desktop — обычно после этого появляется рабочее пространство **Cowork / Code**.

## Способ 2. Управление через локальный файл конфигурации (для опытных)

Если нужно сделать резервную копию, перенести настройки или разобраться с проблемой, посмотрите, куда Claude Desktop записывает локальную конфигурацию.

Типичные пути:

### macOS

```text
~/Library/Application Support/Claude-3p/claude_desktop_config.json
```

### Windows

```text
%APPDATA%\Claude-3p\claude_desktop_config.json
```

### Linux

```text
~/.config/Claude-3p/claude_desktop_config.json
```

<Callout type="idea" title="Совет">
  В локальном файле настройки стороннего инференса хранятся в разделе `enterpriseConfig`. Надёжнее не писать JSON вручную, а сначала выполнить настройку в приложении и уже потом включать полученный файл в резервное копирование или синхронизацию.
</Callout>

## Рекомендуемые параметры для FishXCode

Если вы сверяете поля вручную, обратите внимание на следующие:

| Поле | Рекомендуемое значение |
| - | - |
| `inferenceProvider` | `gateway` |
| `inferenceGatewayBaseUrl` | `https://api.fishxcode.com` |
| `inferenceGatewayAuthScheme` | `x-api-key` |
| `inferenceGatewayApiKey` | ваш токен FishXCode |
| `inferenceModels` | список моделей Claude |
| `isClaudeCodeForDesktopEnabled` | `true` |

Пример рекомендуемого списка моделей:

```text
claude-sonnet-4-5-20250929
claude-opus-4-5-20251101
claude-haiku-4-5-20251001
```

## Использование

После настройки в Claude Desktop можно:

- открыть **Cowork** для общих вопросов, анализа документов и совместной работы с файлами
- открыть **Code** для редактирования кода, работы в терминале и инженерных задач

Если доступен выбор модели, рекомендуем:

- для повседневной работы: `claude-sonnet-4-5-20250929`
- для сложных рассуждений: `claude-opus-4-5-20251101`
- для лёгких и быстрых задач: `claude-haiku-4-5-20251001`

## Частые вопросы

### Почему я не вижу `Enable Developer mode`?

Сначала проверьте две вещи:

1. У вас достаточно свежая версия Claude Desktop
2. Вы смотрите в системную строку меню, а не на кнопки внутри окна

Если пункт не появился и после обновления, полностью закройте Claude Desktop и откройте его снова.

### Что делать, если Windows сообщает `Virtual Machine Platform not available`?

Если Claude Desktop показывает:

```text
Claude's workspace requires the Virtual Machine Platform on Windows. Enable this feature, then restart.
```

Это значит, что в Windows не включён компонент **Virtual Machine Platform**. Откройте PowerShell от имени администратора и выполните:

```powershell
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
```

После выполнения перезагрузите Windows и снова откройте Claude Desktop.

### Почему после настройки не появляются Cowork / Code?

Проверьте по порядку:

1. Developer mode включён
2. Шаг `Configure third-party inference` выполнен
3. Выбран режим `Gateway`
4. В `gatewayUrl` указано `https://api.fishxcode.com`
5. Токен действителен и имеет доступ к моделям Claude
6. После настройки Claude Desktop был полностью закрыт и открыт заново

### Почему Gateway URL — не `https://api.fishxcode.com/v1`?

Потому что режим шлюза стороннего инференса в Claude Desktop использует настройку шлюза в стиле Anthropic, а не OpenAI-совместимый путь `/v1/chat/completions`. Здесь нужно указать корневой адрес шлюза:

```text
https://api.fishxcode.com
```

### Настройка выполнена, но запросы возвращают ошибку аутентификации?

Прежде всего проверьте:

1. Выбран ли способ аутентификации `x-api-key`
2. Вставлен ли в поле API Key именно токен FishXCode
3. Не истёк ли токен, не удалён ли он и хватает ли ему прав

### Можно ли вручную редактировать локальный JSON?

Можно, но первую настройку не стоит строить на ручном редактировании JSON. Причина простая: поля стороннего инференса в Claude Desktop меняются от версии к версии, поэтому настройка в самом приложении надёжнее, а при проблемах её проще откатить.
