## 1. Получение API Key

### 1. Регистрация

Откройте [fishxcode.com](https://fishxcode.com/register?aff=9CTW) и нажмите **Регистрация**:

![Главная страница FishXCode](/img/start/api-01-home.png)

Выберите способ регистрации (GitHub, LinuxDO или имя пользователя):

![Выбор способа регистрации](/img/start/api-02-register.png)

Укажите имя пользователя, пароль и подтверждение пароля, чтобы завершить регистрацию:

![Форма регистрации](/img/start/api-03-register-form.png)

### 2. Вход

После регистрации войдите с именем пользователя и паролем:

![Страница входа](/img/start/api-04-login.png)

После входа откроется консоль:

![Главная страница консоли](/img/start/api-05-console.png)

### 3. Создание токена

Откройте **Консоль → Управление токенами → Добавить токен** и заполните форму:

![Добавление токена](/img/start/api-06-token-create.png)

- В поле **Группа токена** рекомендуем выбрать **Официальный канал**. В эту группу входит вся линейка моделей Claude, а модель подбирается автоматически по сложности задачи, так что переключать её вручную не нужно. Доступные каналы и модели могут меняться — актуальную информацию смотрите на [странице цен](https://fishxcode.com/pricing).

После создания нажмите кнопку **Копировать** в списке токенов, чтобы получить API Key (формат `sk-xxx`):

![Копирование токена](/img/start/api-07-token-copy.png)

### 4. Пополнение баланса

Откройте **Консоль → Управление кошельком**. Поддерживаются Alipay, WeChat Pay и коды пополнения:

![Страница пополнения баланса](/img/start/api-08-wallet.png)

| Способ | Порядок действий |
| - | - |
| Alipay | Введите или выберите сумму → Alipay |
| WeChat Pay | Введите или выберите сумму → WeChat |
| Код пополнения | Введите код в разделе кодов пополнения → нажмите «Активировать» |

<Callout type="idea" title="Что такое коэффициент">
  `0.5x` в названии группы — это коэффициент списания: чем он меньше, тем больше токенов вы получаете. Например, при `0.5x` за 1 юань можно использовать 10 млн токенов по официальным расценкам (по официальной цене — 5 млн).
</Callout>

## 2. Управление токенами

### Группы токенов

При создании токена нужно выбрать группу. От неё зависят доступные модели и коэффициент списания:

| Тип группы | Описание | Когда подходит |
| - | - | - |
| **Официальный канал** | Вся линейка моделей Claude, автоматическая маршрутизация | Рекомендуется большинству пользователей |
| **Группы с низким коэффициентом** | Более низкий коэффициент списания, выгоднее по цене | Частые вызовы, задачи, где важна стоимость |

<Callout type="idea" title="Рекомендация">
  Если не знаете, какую группу выбрать, просто выберите **Официальный канал**. Система сама подберёт самую подходящую модель по сложности задачи.
</Callout>

### Безопасность токенов

- **Регулярная смена**: меняйте токен раз в 30–90 дней, чтобы снизить риск утечки
- **Не храните ключи в открытом виде**: не вписывайте API Key прямо в код и не коммитьте его в Git-репозиторий — используйте переменные окружения
- **Минимум прав**: создавайте отдельный токен для каждого проекта, чтобы проще было управлять ими и отслеживать расход
- **Действия при утечке**: если подозреваете утечку токена, сразу удалите его в консоли и создайте новый

### Изменение и удаление токенов

На странице **Консоль → Управление токенами**:

- **Подробности**: нажмите на название токена, чтобы увидеть группу, доступные модели и время создания
- **Копирование токена**: нажмите кнопку копирования в списке
- **Удаление токена**: нажмите кнопку удаления. Удалённый токен сразу перестаёт действовать, и инструменты, которые его используют, больше не смогут выполнять вызовы

<Callout type="warn" title="Внимание">
  Удаление нельзя отменить. Удаляйте токен, только если уверены, что он больше не нужен.
</Callout>

## 3. Безопасность аккаунта

### Пароль и безопасность входа

- Используйте **надёжный пароль** (не короче 8 символов, с заглавными и строчными буквами и цифрами)
- Не используйте один и тот же пароль на разных платформах
- Если забыли пароль, сбросьте его через восстановление пароля на странице входа

### Вход через сторонние сервисы

FishXCode поддерживает вход через следующие сервисы:

| Способ | Описание |
| - | - |
| **GitHub** | Рекомендуется разработчикам, вход в один клик |
| **LinuxDO** | Участники сообщества могут входить напрямую |

После привязки стороннего аккаунта можно входить через авторизацию на соответствующей платформе, не вводя пароль.

### Подозрительная активность

Если вы заметили что-то из перечисленного ниже, примите меры немедленно:

1. **Необычный рост расходов** → проверьте, не утёк ли токен; при необходимости удалите все токены и создайте новые
2. **Не удаётся войти** → попробуйте восстановить пароль; если не помогло, обратитесь в официальную поддержку
3. **Непонятные списания с баланса** → найдите конкретные вызовы в журнале использования и убедитесь, что это обычный расход

<Callout type="idea" title="Связаться с поддержкой">
  Если с аккаунтом возникли проблемы, обратитесь за помощью через страницу [«Связаться с нами»](https://fishxcode.com/contact).
</Callout>

## 4. Частые вопросы

### Не приходит код подтверждения при регистрации?

1. Проверьте, правильно ли указан адрес почты (нет ли опечаток в имени и домене)
2. Загляните в папку «Спам» или «Нежелательная почта»
3. Подождите 1–2 минуты и повторите попытку — не запрашивайте код слишком часто
4. Если код так и не пришёл, попробуйте другой адрес почты или вход через сторонний сервис

### Где посмотреть созданный токен?

Откройте **Консоль → Управление токенами** — созданные токены отображаются в списке. Нажмите кнопку копирования, чтобы получить API Key в формате `sk-xxx`.

### Пополнение не зачислено — что делать?

1. Убедитесь, что оплата прошла успешно (проверьте историю операций в Alipay или WeChat)
2. Подождите 1–5 минут: зачисление может ненадолго задерживаться
3. Обновите страницу кошелька в консоли
4. Если через 10 минут средства так и не поступили, обратитесь в официальную поддержку и приложите скриншот оплаты

### Как посмотреть детализацию расходов?

Откройте **Консоль → Журнал использования**. Для каждого вызова API там видно:

- Время вызова и название модели
- Расход токенов и стоимость
- IP-адрес запроса и подробную запись
