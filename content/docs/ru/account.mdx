## 1. Регистрация и вход

### 1. Регистрация аккаунта

Откройте [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW), вы попадёте на страницу регистрации:

![Страница регистрации FishXCode](/img/start/api-v2-01-home.png)

Заполните форму: задайте имя пользователя и пароль (8–128 символов, желательно со строчными и заглавными буквами, цифрами и символами), укажите адрес электронной почты для получения кода подтверждения:

![Заполнение формы регистрации](/img/start/api-v2-03-register-form.png)

<Callout type="idea" title="Поддерживаемые домены почты">
  Для регистрации по e-mail сейчас поддерживаются четыре домена: **qq.com, 126.com, 163.com, gmail.com**; с других доменов код подтверждения может не приходить.
</Callout>

Нажмите **Отправить код** (发送验证码), пройдите проверку Cloudflare — код подтверждения придёт на вашу почту. Найдите в письме код (6 знаков, буквы и цифры) и введите его в форму:

![Ввод кода из письма](/img/start/api-v2-02-register-verify.png)

Нажмите **Создать аккаунт** (创建账户), чтобы завершить регистрацию. Страница перенаправит на форму входа с сообщением «Аккаунт создан! Войдите».

<Callout type="warn" title="Код не приходит?">
  1. Убедитесь, что домен почты входит в список поддерживаемых (qq.com / 126.com / 163.com / gmail.com)
  2. Проверьте папку «Спам»
  3. Подождите 1–2 минуты и повторите попытку, не отправляйте запросы слишком часто
  4. Если код так и не пришёл, войдите через сторонний сервис авторизации
</Callout>

### 2. Вход

После регистрации войдите с именем пользователя и паролем. Также доступен вход в один клик через сторонние аккаунты:

![Страница входа](/img/start/api-v2-04-login.png)

| Способ входа | Описание |
| - | - |
| Аккаунт, зарегистрированный по e-mail | Вход по имени пользователя/почте + пароль |
| GitHub | Авторизация, рекомендуется разработчикам |
| LinuxDO | Авторизация для пользователей сообщества |
| Google | Авторизация через аккаунт Google |

<Callout type="info" title="Сторонняя авторизация = регистрация">
  При первом входе через GitHub / LinuxDO / Google аккаунт создаётся автоматически, отдельно регистрироваться не нужно.
</Callout>

После входа вы попадёте в консоль (страницу «Обзор»):

![Обзор консоли](/img/start/api-v2-05-console.png)

## 2. Получение API Key

### 1. Создание API Key

Откройте **Консоль → API Keys** (API 密钥) и нажмите **Создать API Key** (创建 API 密钥) в правом верхнем углу:

![Окно создания API Key](/img/start/api-v2-06-token-create.png)

Поля формы:

| Поле | Описание |
| - | - |
| Название | Произвольное имя ключа, чтобы легче было распознать его назначение |
| Группа | Определяет доступные модели и коэффициент расхода, см. пояснение ниже |
| Срок действия | Никогда / 1 месяц / 1 день / 1 час |
| Количество | Можно создать сразу несколько ключей (к названию добавится случайный суффикс) |
| Безлимитная квота | Включена по умолчанию; если выключить, можно ограничить максимальный расход по этому ключу |
| Расширенные настройки | Белый список IP (поддержка CIDR), разрешение на просмотр квоты пользователя |

- Для **группы** рекомендуется <LiveRatio name="claude" /> — это пул официальных аккаунтов Claude Max 20, оплаченных по полной цене, с полной производительностью. При использовании месячного пакета Codex обязательно выбирайте `codex-sub-june`. Все группы и коэффициенты перечислены в разделе [Правила тарификации и группы](/ru/billing-groups).
- **Белый список IP** подходит для серверов с фиксированным исходящим IP; для локальной разработки используйте осторожно — после смены IP вызовы перестанут работать.

Нажмите **Сохранить изменения** (保存更改), чтобы завершить создание. Нажмите кнопку **Копировать** (复制) в списке ключей, чтобы получить API Key (формат `sk-xxx`):

![Копирование API Key](/img/start/api-v2-07-token-copy.png)

<Callout type="idea" title="API-адрес">
  Нажмите **API 地址** в правом верхнем углу страницы, чтобы посмотреть адрес подключения. В консоли по умолчанию показан `https://fishxcode.com`; `https://api.fishxcode.com` тоже доступен — оба адреса работают одинаково, выбирайте любой.
</Callout>

### 2. Пополнение

Откройте **Консоль → Кошелёк** (钱包). Страница разделена на две вкладки: **Пополнение баланса** и **Тарифные планы**:

![Пополнение баланса в кошельке](/img/start/api-v2-08-wallet.png)

**Пополнение баланса**: выберите предустановленную сумму ($1 / $5 / $10 / $100 / $500 / $1,000, для крупных сумм действует скидка 1%–3%) или введите свою сумму, затем выберите способ оплаты:

![Способы оплаты и коды обмена](/img/start/api-09-payment.png)

| Способ | Описание |
| - | - |
| Alipay | Основной способ пополнения, без минимальной суммы |
| Waffo Pancake | Минимальное пополнение $100 |
| Код обмена | Введите его в области «有兑换码吗？」и нажмите **Обменять лимит** (兑换额度) |

**Тарифные планы**: покупка месячного пакета пула Codex (три уровня квоты: $20 / $200 / $2,000). После покупки создавайте API Key с группой `codex-sub-june`, подробности в разделе [Тарифные планы](/ru/subscription-plans):

![Вкладка тарифных планов](/img/start/api-10-subscription.png)

<Callout type="idea" title="Бонус для новых пользователей">
  Только что зарегистрированным аккаунтам автоматически начисляется **$0.2** пробного баланса — можно сразу тестировать вызовы API.
</Callout>

<Callout type="idea" title="О коэффициентах">
  Коэффициент в названии группы — это множитель расхода: чем меньше значение, тем меньше спишется за тот же запрос. Например, в группе `0.5x` расход на 1 юань соответствует объёму токенов на 2 юаня по официальному прайсу. Подробнее в разделе [Правила тарификации и группы](/ru/billing-groups).
</Callout>

## 3. Безопасность аккаунта

Откройте **Консоль → Безопасность и доступ** (安全与访问), чтобы управлять настройками безопасности аккаунта:

![Безопасность и доступ](/img/start/api-12-security.png)

| Функция | Описание |
| - | - |
| Смена пароля | Меняйте пароль регулярно: от 8 символов, с заглавными и строчными буквами и цифрами |
| Привязка аккаунтов | Привяжите GitHub / LinuxDO / Google, чтобы входить в один клик |
| Сеансы входа | Просмотр текущих устройств входа; другие сеансы можно завершить удалённо |
| Токены доступа | Используются для вызова API панели; создавайте с нужными разрешениями |
| Вход по Passkey | Вход с помощью Passkey, без пароля |
| Двухэтапная проверка | Дополнительный уровень защиты аккаунта |

### Рекомендации по безопасности API Key

- **Регулярная ротация**: меняйте ключ каждые 30–90 дней, чтобы снизить риск утечки
- **Не храните в открытом виде**: не вписывайте API Key прямо в код и не коммитьте его в Git-репозиторий — используйте переменные окружения
- **Минимальные привилегии**: создавайте отдельные ключи под разные проекты — так проще управлять и отслеживать
- **При утечке**: если есть подозрение на утечку, немедленно удалите ключ на странице **API Keys** и создайте новый

<Callout type="warn" title="Внимание">
  Удаление ключа необратимо: после удаления он немедленно перестаёт действовать, и инструменты, которые его использовали, больше не смогут выполнять вызовы.
</Callout>

## 4. Частые вопросы

### Код подтверждения при регистрации не приходит?

1. Убедитесь, что домен почты входит в список поддерживаемых (qq.com / 126.com / 163.com / gmail.com)
2. Проверьте папки «Спам» и «Корзина»
3. Подождите 1–2 минуты и повторите попытку, не отправляйте запросы слишком часто
4. Если код так и не пришёл, войдите через GitHub / LinuxDO / Google

### Где посмотреть созданный API Key?

Откройте **Консоль → API Keys** — созданные ключи отображаются в списке. Нажмите кнопку копирования, чтобы получить API Key формата `sk-xxx`.

### Пополнение не зачислилось — что делать?

1. Убедитесь, что платёж прошёл успешно (проверьте историю операций в Alipay и других каналах)
2. Подождите 1–5 минут — возможна короткая задержка на стороне системы
3. Обновите страницу кошелька в консоли
4. Если прошло больше 10 минут и средства не зачислились, обратитесь за помощью через страницу [Свяжитесь с нами](https://fishxcode.com/contact), приложив платёжные документы

### Как посмотреть детали расхода?

Откройте **Консоль → Журналы использования**, чтобы увидеть по каждому вызову API:

- время вызова и название модели
- объём потраченных токенов и стоимость
- IP запроса и подробные записи

Другие типы журналов (журнал аудита, журнал задач) можно переключить в боковой панели.
