## 1. Обзор платформы

FishXCode — платформа доступа к AI для разработчиков и команд. Её удобно представлять как единую точку входа: на витрине — официальный сайт, цены и документация, а за ней — консоль, токены, пополнение баланса, счета и история использования.

Платформа работает как шлюз к популярным AI-моделям. Актуальные каналы и модели указаны на официальном сайте, смотрите [страницу цен](https://fishxcode.com/pricing). Весь путь пользователя — от регистрации до создания токена, выбора тарифа, подключения инструментов и просмотра расхода — проходит в одной системе.

## 3. Краткий справочник по консоли

После входа все действия выполняются в консоли. Нужный раздел легко найти по сценарию использования:

### Начало работы

1. Зарегистрируйте аккаунт → войдите в консоль
2. **Управление токенами**: создайте API Key (выберите подходящую группу)
3. Укажите Base URL и API Key в настройках своего инструмента

### Покупка и пополнение баланса

- **Управление тарифами**: просмотрите доступные тарифы и оформите подписку на подходящий
- **Страница пополнения баланса**: поддерживаются Alipay, WeChat и коды активации
- **Проверка баланса**: баланс отображается в реальном времени на главной странице Dashboard

### Управление использованием

- **Журнал использования**: записи о каждом вызове с моделью, расходом, IP и другими подробностями
- **Управление токенами**: статус токенов и их группы, удаление токенов, которые больше не нужны
- **Личные настройки**: смена группы по умолчанию, бонусы за ежедневную отметку и базовая статистика

### Поддержка и обслуживание

- **Управление счетами**: заявки на выставление счетов для компаний и пользователей, которым нужны документы для возмещения расходов
- **Реферальная программа**: приглашайте новых пользователей по реферальной ссылке и следите за вознаграждениями
- **Статус сервиса**: при сбоях вызовов проверьте, работают ли группы в штатном режиме
- **Контакты**: вопросы по использованию, закупкам и поддержке после покупки
