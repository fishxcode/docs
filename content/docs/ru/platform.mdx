## 1. Обзор платформы

FishXCode — платформа доступа к AI для разработчиков и команд. Её можно понимать как единый вход: снаружи — официальный сайт, цены и документация, внутри — консоль, API Keys, пополнение, счета и история использования.

Платформа предоставляет посреднический сервис вокруг популярных AI-моделей; конкретные каналы и модели — по факту на официальном сайте, смотрите [страницу цен](https://fishxcode.com/pricing). Весь путь пользователя — от регистрации до создания ключей, выбора плана, подключения инструментов и просмотра расхода — проходит в одной системе.

## 3. Быстрая справка по консоли

После входа все операции сосредоточены в консоли — ориентируйтесь по сценариям:

### Начало работы

1. Зарегистрируйте аккаунт → войдите в консоль
2. **API Keys**: создайте API Key (выберите подходящую группу)
3. Настройте Base URL и API Key в вашем инструменте

### Покупка и пополнение

- **Кошелёк → Тарифные планы**: просмотр и покупка месячных пакетов Codex и других подписок
- **Кошелёк → Пополнение баланса**: Alipay, Waffo Pancake и коды обмена
- **Просмотр баланса**: в реальном времени на страницах кошелька и обзора

### Управление использованием

- **Журналы использования**: записи о каждом вызове — модель, расход, IP и другие детали
- **API Keys**: статус ключей, охват групп; удаляйте или отключайте неиспользуемые ключи
- **Профиль**: награды за ежедневный вход и базовая статистика

### Поддержка

- **Реферальная программа**: ссылка для приглашения и вознаграждения — внизу страницы кошелька
- **Статус сервисов**: проверка доступности групп при сбоях вызовов
- **Свяжитесь с нами**: вопросы использования, закупки и послепродажная поддержка
