> Впервые здесь? Сначала [зарегистрируйтесь и пополните баланс](/ru/account), затем получите API Key в консоли.

## 1. Откройте настройки Cursor

Запустите Cursor и нажмите значок настроек в правом верхнем углу, чтобы открыть страницу настроек.

## 2. Перейдите в раздел Models

В меню слева выберите **Models** — откроется раздел настройки моделей и API.

## 3. Добавьте модель и укажите API Key / Base URL

Сначала нажмите **Add model**, затем в разделе настроек OpenAI API заполните:

- **API Key**: ключ, созданный в консоли FishXCode
- **Base URL**: `https://api.fishxcode.com/v1`

![Пример настройки Models в Cursor](/img/start/cursor.png)

Обозначения на скриншоте:

1. Вход в настройки
2. Меню Models
3. Добавление модели
4. Поле ввода API Key
5. Поле ввода Base URL

## 4. Сохраните и проверьте подключение

1. Создайте новый чат
2. Выберите только что включённую модель
3. Отправьте тестовый запрос
4. Если пришёл нормальный ответ, подключение работает
