## 1. Подготовка окружения

### Установка Node.js

Claude Code устанавливается через npm, поэтому сначала убедитесь, что Node.js уже установлен.

```bash tab="macOS — проверка"
node -v
npm -v
```

```bash tab="macOS — установка через Homebrew"
brew install node
```

```bash tab="Windows — проверка (CMD/PowerShell)"
node -v
npm -v
```

Если Node.js не установлен, скачайте установщик для своей платформы на [nodejs.org/en/download](https://nodejs.org/en/download/current/). **После установки в Windows нужна перезагрузка.**

### Только для Windows: установка Git Bash

Для работы Claude Code нужна среда bash, поэтому пользователям Windows необходимо установить Git Bash:

1. Скачайте установщик на [git-scm.com/install/windows](https://git-scm.com/install) и установите подходящую версию.
2. Проверка: щёлкните правой кнопкой мыши по рабочему столу — если в меню есть пункт **Open Git Bash here**, установка прошла успешно.

## 3. Настройка FishXCode

1. Введите в терминале `npx zcf` и нажмите Enter.
   Когда появится `Ok to proceed? (y)`, введите `y` и нажмите Enter.

2. Язык интерфейса ZCF:
   выберите **English**.

3. После завершения установки выберите:
   `1. Full Init - Install Claude Code + Import Workflows + Configure API or CCR Proxy + Configure MCP Services`

4. Изменение языка шаблонов:
   выберите `No`

5. Язык ответов ИИ:
   выберите `English`

6. Установка Claude:
   выберите `Yes`

7. Режим настройки API:
   выберите `Custom API Configuration`

8. Провайдер API:
   выберите `Custom Configuration`

9. Название конфигурации:
   введите любое название на английском

10. Тип аутентификации:
    выберите `API Key`

11. Базовый URL API:
    ```
    https://api.fishxcode.com
    ```

12. Ключ API:
    вставьте токен, созданный в консоли FishXCode

13. Настройки моделей:
    просто нажмите Enter, чтобы оставить значения по умолчанию

14. Тип рабочего процесса:
    выберите `General Tools`

15. Стиль вывода:
    выберите на свой вкус

16. Настройка MCP:
    выберите `Yes`

17. Сервисы MCP:
    отметьте нужные сервисы пробелом и нажмите Enter

18. Настройка CCometixLine:
    просто нажмите Enter

19. Вернувшись в главное меню, введите:
    ```
    q
    ```

20. Введите в терминале:
    ```
    claude
    ```
    - Выберите `Yes, I trust this folder`
    - При выборе API обязательно выберите **YES (первый вариант)**

## 5. Смена модели

Чтобы сменить модель, введите `/model` в диалоге Claude Code:

| Вариант | Фактическая модель | Описание |
| - | - | - |
| **Default** | `claude-fable-5-2` + `claude-haiku-5-5` | Выбирается автоматически под задачу, рекомендуется для повседневной работы |
| **Opus** | `claude-opus-5-5` | Самые сильные рассуждения, но и расход выше |
| **Haiku** | `claude-haiku-5-5` | Лёгкая и быстрая |

Модель можно также зафиксировать через переменную окружения:

```bash tab="macOS/Linux"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL="claude-fable-5-2"
claude
```

<Callout type="idea" title="Обновление Claude Code">
  Если версия модели оказалась не самой новой, выполните команду обновления и перезапустите связанные инструменты:

  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
</Callout>

## 6. Интеграция с IDE

### IntelliJ IDEA

Путь: File → Settings → Plugins → Marketplace → найдите `claude code`, затем выберите и установите **Claude Code Terminal**:

![Установка Claude Code Terminal](/img/start/idea-01-install.png)

После установки перезапустите IDEA и убедитесь, что плагин загрузился:

![Проверка загрузки плагина](/img/start/idea-02-verify.png)

<Callout type="info">
  Если плагин не находится в Marketplace, ваша версия IDEA слишком старая — обновите её до последней.
</Callout>

### VSCode

Нажмите `Ctrl + Shift + X`, чтобы открыть панель расширений, найдите `claude code` и установите **Claude Code for VSCode**.

![Поиск и установка расширения Claude Code](/img/start/vscode-01-install.png)

После установки расширение предлагает три способа подключения:

![Способы подключения в расширении Claude Code](/img/start/vscode-02-login.png)

Для подключения к FishXCode рекомендуем настройку через `settings.json`. Нажмите **значок шестерёнки** в правом нижнем углу расширения → **Изменить в settings.json**:

![Открытие settings.json для редактирования](/img/start/vscode-03-settings.png)

Добавьте в `settings.json` VSCode:

```json
{
  "claudeCode.preferredLocation": "panel",
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "замените на ваш API Key" },
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.fishxcode.com/" }
  ]
}
```

![Пример настройки settings.json](/img/start/vscode-04-config.png)

После сохранения **закройте и снова откройте VSCode** — расширение подключится к FishXCode.

![Работа с Claude Code в VSCode](/img/start/vscode-05-demo.gif)

## 7. Частые вопросы

### Ошибка 403

На балансе токена недостаточно средств. Пополните баланс в консоли и повторите попытку.

### Windows: ошибка подключения или 400/401

Повторно выполните в PowerShell команды `setx`, чтобы записать системные переменные, затем откройте терминал заново:

```powershell
setx ANTHROPIC_AUTH_TOKEN "sk-xxx"
setx ANTHROPIC_BASE_URL "https://api.fishxcode.com/"
```

### Сообщение «Unable to connect to Anthropic services»

Полный текст ошибки:

```
Unable to connect to Anthropic services
Failed to connect to api.anthropic.com: ERR_BAD_REQUEST
Please check your internet connection and network settings.
```

Это происходит потому, что Claude Code ещё не прошёл onboarding и по-прежнему пытается подключиться к официальному `api.anthropic.com`. **VPN не нужен**: добавьте `"hasCompletedOnboarding": true` в конец файла `~/.claude.json` (именно `.claude.json` в домашнем каталоге, а не `.claude/settings.json`), и этот шаг будет пропущен:

```json
{
  "installMethod": "unknown",
  "autoUpdates": true,
  "projects": { ... },
  "hasCompletedOnboarding": true
}
```

<Callout type="idea">
  Перед добавлением не забудьте поставить запятую в конце предыдущего поля — этого требует синтаксис JSON. После изменения снова запустите `claude`, и подключение заработает.
</Callout>
