## 1. Подготовка окружения

### Установка Node.js

Claude  Code устанавливается через npm, поэтому сначала убедитесь, что Node.js готов к работе.

```bash tab="macOS — проверка"
node -v
npm -v
```

```bash tab="macOS — установка через Homebrew"
brew install node
```

```bash tab="Windows — проверка (CMD/PowerShell)"
node -v
npm -v
```

Если Node.js не установлен, скачайте установщик для своей платформы на [nodejs.org/zh-cn/download](https://nodejs.cn/download/current/). После установки **Windows требует перезагрузки**.

### Только для Windows: установка Git Bash

Claude  Code зависит от среды bash, поэтому пользователям Windows нужно установить Git Bash:

1. Ссылка для скачивания: [git-scm.com/install/windows](https://git-scm.com/install) — выберите подходящую версию и установите.
2. Проверка: щёлкните правой кнопкой мыши по рабочему столу — если появился пункт **Open Git Bash here**, установка прошла успешно.

## 3. Настройка FishXCode

1. Введите в терминале `npx zcf` и нажмите Enter.
   Когда появится `Ok to proceed? (y)`, введите `y` и нажмите Enter.

2. Выбор языка интерфейса ZCF:
   выберите **简体中文**.

3. После завершения установки выберите:
   `1. 完整初始化 - 安装 Claude Code + 导入工作流 + 配置 API 或 CCR 代理 + 配置 MCP 服务`

4. Изменить настройки языка шаблона:
   выберите `No`

5. Язык вывода AI:
   выберите `简体中文`

6. Установить Claude:
   выберите `Yes`

7. Режим настройки API:
   выберите `自定义 API 配置`

8. Поставщик API:
   выберите `自定义配置`

9. Название конфигурации:
   произвольное имя на английском

10. Тип аутентификации:
    выберите `API Key`

11. Базовый URL API:
    ```
    https://api.fishxcode.com
    ```
    <Callout type="idea" title="Адрес подключения">
      В качестве адреса подключения подойдут и `https://api.fishxcode.com`, и `https://fishxcode.com` — оба работают одинаково, выбирайте любой.
    </Callout>

12. API Key:
    введите API Key, созданный в консоли FishXCode (Консоль → API Keys / API 密钥)

13. Настройки, связанные с моделью:
    просто нажмите Enter, чтобы пропустить с настройками по умолчанию

14. Тип рабочего процесса:
    выберите `通用工具`

15. Стиль вывода:
    выберите по личным предпочтениям

16. Настроить MCP:
    выберите `Yes`

17. Сервисы MCP:
    отметьте нужные сервисы клавишей пробела и нажмите Enter

18. Настройка CCometixLine:
    просто нажмите Enter

19. Вернувшись в главное меню, введите:
    ```
    q
    ```

20. Введите в терминале:
    ```
    claude
    ```
    - выберите `Yes, I trust this folder`
    - на шаге выбора API обязательно выберите **YES (первый вариант)**

## 5. Переключение моделей

Введите `/model` в диалоговом интерфейсе Claude  Code, чтобы переключить модель:

| Вариант | Фактическая модель | Описание |
| - | - | - |
| **Default** | `claude-fable-5-2` + `claude-haiku-5-5` | Выбирается автоматически под задачу, рекомендуется для повседневной работы |
| **Opus** | `claude-opus-5-5` | Самые сильные рассуждения, расход выше |
| **Haiku** | `claude-haiku-5-5` | Лёгкая и быстрая |

Модель можно закрепить и через переменную окружения:

```bash tab="macOS/Linux"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL="claude-fable-5-2"
claude
```

<Callout type="idea" title="Обновление Claude Code">
  Если версия модели оказалась не самой свежей, выполните команду обновления и перезапустите инструменты:

  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
</Callout>

## 6. Интеграция с IDE

### IntelliJ IDEA

Путь: File → Settings → Plugins → Marketplace → найдите `claude code`, выберите **Claude  Code Terminal** и установите:

![Установка Claude  Code Terminal](/img/start/idea-01-install.png)

После установки перезапустите IDEA и убедитесь, что плагин загрузился:

![Проверка загрузки плагина](/img/start/idea-02-verify.png)

<Callout type="info">
  Если плагин не находится в Marketplace, значит версия IDEA слишком старая — обновите её до последней.
</Callout>

### VSCode

Нажмите `Ctrl + Shift + X`, чтобы открыть панель расширений, найдите `claude code` и установите **Claude  Code for VSCode**.

![Поиск и установка расширения Claude  Code](/img/start/vscode-01-install.png)

После установки расширение предлагает три способа подключения:

![Способы подключения расширения Claude  Code](/img/start/vscode-02-login.png)

Рекомендуется подключить FishXCode через `settings.json`. Нажмите **значок шестерёнки** в правом нижнем углу расширения → **Edit in settings.json** (在 settings.json 中编辑):

![Открытие settings.json для правки](/img/start/vscode-03-settings.png)

Добавьте в `settings.json` VSCode:

```json
{
  "claudeCode.preferredLocation": "panel",
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "替换为您的 API Key" },
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.fishxcode.com/" }
  ]
}
```

<Callout type="idea" title="Адрес подключения">
  В `ANTHROPIC_BASE_URL` можно указать и `https://fishxcode.com/` — оба адреса работают одинаково, выбирайте любой.
</Callout>

![Пример настройки settings.json](/img/start/vscode-04-config.png)

После сохранения **закройте и заново откройте VSCode** — расширение подключится к FishXCode как положено.

![Использование Claude  Code в VSCode](/img/start/vscode-05-demo.gif)

## 7. Частые вопросы

### Ошибка 403

Недостаточно токенов на балансе. Пополните баланс в консоли и повторите попытку.

### Ошибка подключения или 400/401 на Windows

Выполните команды `setx` заново в PowerShell, чтобы записать системные переменные, затем снова откройте терминал:

```powershell
setx ANTHROPIC_AUTH_TOKEN "sk-xxx"
setx ANTHROPIC_BASE_URL "https://api.fishxcode.com/"
```

### Ошибка «Unable to connect to Anthropic services»

Полный текст ошибки:

```
Unable to connect to Anthropic services
Failed to connect to api.anthropic.com: ERR_BAD_REQUEST
Please check your internet connection and network settings.
```

Причина в том, что onboarding в Claude  Code ещё не завершён, и клиент пытается подключиться к официальному `api.anthropic.com`. **VPN не нужен**: добавьте `"hasCompletedOnboarding": true` в конец файла `~/.claude.json` (это `.claude.json` в домашнем каталоге, не `.claude/settings.json`), и этот шаг будет пропущен:

```json
{
  "installMethod": "unknown",
  "autoUpdates": true,
  "projects": { ... },
  "hasCompletedOnboarding": true
}
```

<Callout type="idea">
  Перед добавлением поставьте запятую в конце предыдущего поля (этого требует синтаксис JSON). После правки снова запустите `claude` — подключение заработает.
</Callout>
