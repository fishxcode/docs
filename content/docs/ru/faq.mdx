## Общее

### Что такое FishXCode?

FishXCode — универсальная платформа доступа к AI-моделям и сервисам аккаунтов: Claude, Codex, Kiro, Grok, китайские и мультимодальные модели. Работает с множеством инструментов и платформ.

### Какие инструменты поддерживаются?

Сейчас поддерживаются следующие инструменты:

- **Claude Code** — официальный CLI от Anthropic
- **OpenAI Codex** — официальный ассистент для программирования от OpenAI
- **RooCode** — плагин для AI-программирования в VS Code
- **Qwen Code** — инструмент для программирования от Alibaba (Tongyi Qianwen)
- **Droid CLI** — лёгкий CLI для AI-программирования
- **OpenCode** — open-source терминальный инструмент для AI-программирования

### Как обеспечивается приватность данных?

FishXCode — только посредник для вызовов API: мы не храним ваш код и содержимое диалогов. Все запросы передаются напрямую соответствующему провайдеру модели.

<Callout type="idea" title="Рекомендация">
  Для чувствительных проектов перед использованием прочитайте политику конфиденциальности соответствующего провайдера модели.
</Callout>

## Аккаунт и API Key

### Как зарегистрироваться?

Откройте [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW), укажите имя пользователя, пароль и почту, введите код подтверждения из письма — и регистрация завершена. Также можно сразу войти через GitHub / LinuxDO / Google (при первой авторизации аккаунт создаётся автоматически).

<Callout type="idea" title="Поддерживаемые домены почты">
  Для регистрации по e-mail сейчас поддерживаются четыре домена: **qq.com, 126.com, 163.com, gmail.com**.
</Callout>

### Как получить API Key?

После регистрации войдите в консоль и откройте [страницу API Keys](https://fishxcode.com/keys), чтобы создать новый API Key.

### Какие способы пополнения поддерживаются?

Откройте **Консоль → Кошелёк** и пополните баланс. Поддерживаются:

- **Alipay**: основной способ, без минимальной суммы
- **Waffo Pancake**: минимальное пополнение $100
- **Код обмена**: введите его в области обмена лимитами на странице кошелька

Активные пользователи Codex могут сразу купить месячный пакет пула аккаунтов (вкладка «Тарифные планы»), см. [Тарифные планы](/ru/subscription-plans).

### Как долго действует API Key?

Ключ действует, пока вы не удалите или не перевыпустите его вручную. Для безопасности рекомендуется ротировать его регулярно.

### Какова квота использования?

FishXCode предоставляет каждому пользователю квоту использования; конкретное значение динамически меняется вместе с ресурсами платформы. Следите за информацией о квоте в консоли.

<Callout type="warn" title="Внимание">
  Когда квота исчерпана, запросы отклоняются — планируйте расход разумно.
</Callout>

## Настройка инструментов

### Переменные окружения не действуют — что делать?

Проверьте типичные причины:

1. **Терминал не перезапущен** — после правки `.bashrc` / `.zshrc` выполните `source ~/.bashrc` или откройте новый терминал
2. **Опечатка в имени переменной** — учитывайте регистр: `ANTHROPIC_BASE_URL` нельзя писать как `Anthropic_Base_Url`
3. **Лишние кавычки или пробелы** — в `export KEY="value"` не должно быть лишних пробелов вокруг value

<Accordions type="single">
  <Accordion title="Команды быстрой проверки">
    ```bash
    # Проверить, заданы ли переменные
    echo $ANTHROPIC_BASE_URL
    echo $ANTHROPIC_AUTH_TOKEN

    # Если пусто — переменные не действуют
    ```
  </Accordion>
</Accordions>

### Где находятся файлы конфигурации?

| Инструмент | Путь к файлу конфигурации |
| - | - |
| Claude Code | настройка через переменные окружения |
| Codex | `~/.codex/config.toml` и `~/.codex/auth.json` |
| RooCode | JSON настроек VS Code |
| Qwen Code | настройка через переменные окружения |

### Не удаётся подключиться к FishXCode — что делать?

1. Убедитесь, что `BASE_URL` установлен в `https://api.fishxcode.com/` или `https://fishxcode.com/` (работают оба, поведение одинаковое)
2. Проверьте, доступен ли `fishxcode.com` из вашей сети
3. Если вы в корпоративной сети, проверьте настройки прокси

## Выбор модели

### Как выбрать подходящую модель?

Отталкивайтесь от сценария использования:

| Сценарий | Рекомендуемая модель | Почему |
| - | - | - |
| Повседневное программирование | `claude-fable-5-2` | Баланс возможностей и скорости |
| Быстрые дополнения | `claude-haiku-5-5` | Быстрый отклик |
| Сложная архитектура | `claude-fable-5-2` | Сильные рассуждения |

### Чем модели различаются между собой?

- **Серия Sonnet**: универсальные возможности, подходит для большинства задач программирования
- **Серия Haiku**: лёгкая и быстрая, подходит для простых дополнений и задач форматирования
- За точными различиями возможностей моделей обращайтесь к официальной документации каждого провайдера

### Как переключить модель?

Укажите её через переменную окружения `ANTHROPIC_MODEL`:

```bash
export ANTHROPIC_MODEL=claude-fable-5-2
```

## Поиск неисправностей

### Ошибка аутентификации (Auth Error)

<Callout type="warn" title="Типичные причины">
  - API Key введён неверно (лишние пробелы или не полностью)
  - Ключ был удалён или перевыпущен
  - `API_KEY` и `AUTH_TOKEN` заданы не одновременно
</Callout>

Решение: откройте [страницу API Keys](https://fishxcode.com/keys), проверьте состояние ключа и скопируйте его заново.

### Как читать журнал ошибок?

Откройте [Консоль → Журналы использования](https://fishxcode.com/usage-logs/common), переключите тип журнала на **Журнал ошибок** — фильтруйте по времени, модели, ключу, группе, ID запроса, сообщению об ошибке и коду состояния.

<Callout type="idea" title="Советы по диагностике">
  - Сначала скопируйте `request_id` из ответа API или журнала и точно найдите тот же запрос в журналах использования
  - Ищите ключевые слова в `content` по полю «错误消息» (сообщение об ошибке), например `Invalid token`, `Upstream request failed`
  - Быстро сгруппируйте типы проблем по «状态码» (коду состояния): `400`, `401`, `403`, `413`, `429`, `500`, `502`, `503`, `504`
  - Если в одной группе повторяются одинаковые ошибки, сначала по группе определите: это проблема конфигурации, лимитов или доступности upstream
</Callout>

Полное описание полей, классификация кодов состояния и таблица типичных ошибок — в разделе [Описание журнала ошибок](/ru/error-logs).

### Как читать состояние здоровья группы?

Состояние здоровья группы помогает понять: проблема в отдельных запросах или же она сконцентрирована в конкретном плане, модели или upstream-группе. Смотрите сначала `success_rate`, `error_count` и `error_reasons`, а по `request_id` в конкретной записи журнала находите сам запрос.

Полная страница состояния, описание полей и порядок диагностики — в разделе [Состояние здоровья групп](/ru/group-health).

### Таймаут запроса (Timeout)

Возможные причины:

1. Слишком высокая задержка в сети
2. Слишком длинный контекст запроса — модель обрабатывает его долго
3. Высокая нагрузка на сервис

Рекомендация: уменьшите входной контекст или повторите попытку позже.

### Срабатывание лимита частоты или квоты (Rate Limit)

Код `429` обычно означает, что запросы идут слишком часто. Он также может означать, что дневная квота upstream-аккаунта исчерпана или ключ модели сейчас «остывает».

<Callout type="idea" title="Что делать">
  - Снизьте частоту запросов и повторите попытку через несколько секунд
  - Не вызывайте API в скриптах в непрерывном цикле без пауз
  - Проверьте, не использует ли тот же API Key другой процесс прямо сейчас
  - Если в журнале есть `Max 10/min` или `Max 5/min`, снизьте параллелизм и число запросов в минуту ниже указанного порога
  - Если в журнале есть `daily limit exceeded`, дождитесь сброса дневной квоты или переключитесь на другую доступную модель/группу
  - Если в журнале есть `cooling down`, не повторяйте запросы сразу подряд — дождитесь окончания охлаждения или временно смените модель
</Callout>

### Ошибка «Модель недоступна» (Model Not Available)

Проверьте, правильно ли указано имя модели; список рекомендуемых моделей есть в разделе [Быстрый старт](/ru/start). Часть моделей может быть ещё не запущена на FishXCode.
