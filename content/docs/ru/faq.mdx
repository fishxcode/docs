## Общие вопросы

### Что такое FishXCode?

FishXCode — шлюз для AI Coding, позволяющий использовать модели Claude и Codex на разных платформах.

### Какие инструменты поддерживаются?

Сейчас поддерживаются следующие инструменты:

- **Claude Code** — официальный CLI от Anthropic
- **OpenAI Codex** — официальный помощник по программированию от OpenAI
- **RooCode** — AI-плагин для программирования в VS Code
- **Qwen Code** — инструмент для программирования на базе Alibaba Tongyi Qianwen
- **Droid CLI** — лёгкий CLI для программирования с AI
- **OpenCode** — терминальный AI-инструмент для программирования с открытым исходным кодом

### Как обеспечивается конфиденциальность данных?

FishXCode работает только как API-шлюз и не хранит ваш код и содержимое диалогов. Все запросы передаются напрямую соответствующим поставщикам моделей.

<Callout type="idea" title="Рекомендация">
  Для проектов с конфиденциальными данными рекомендуем перед началом работы ознакомиться с политиками конфиденциальности поставщиков моделей.
</Callout>

## Аккаунт и токены

### Как зарегистрироваться?

Перейдите на [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW) и завершите регистрацию, следуя подсказкам.

### Как получить API-токен?

После регистрации войдите в консоль, откройте [страницу управления токенами](https://fishxcode.com/console/token) и создайте новый токен.

### Сколько действует токен?

Токен действует, пока вы не удалите его вручную или не сгенерируете заново. Для безопасности рекомендуем регулярно менять токены.

### Какая квота использования?

FishXCode предоставляет каждому пользователю квоту использования; её размер динамически меняется в зависимости от ресурсов платформы. Следите за данными об использовании в консоли.

<Callout type="warn" title="Важно">
  Когда квота исчерпана, запросы отклоняются, поэтому планируйте использование разумно.
</Callout>

## Настройка инструментов

### Что делать, если переменные окружения не применяются?

Проверьте частые причины:

1. **Терминал не перезапущен** — после изменения `.bashrc` / `.zshrc` выполните `source ~/.bashrc` или откройте новый терминал
2. **Опечатка в имени переменной** — регистр важен: например, `ANTHROPIC_BASE_URL` нельзя писать как `Anthropic_Base_Url`
3. **Лишние кавычки или пробелы** — в `export KEY="value"` не должно быть лишних пробелов вокруг value

<Accordions type="single">
  <Accordion title="Команды для быстрой проверки">
    ```bash
    # Проверьте, заданы ли переменные
    echo $ANTHROPIC_BASE_URL
    echo $ANTHROPIC_AUTH_TOKEN

    # Пустой вывод означает, что переменная не применилась
    ```
  </Accordion>
</Accordions>

### Где находятся файлы конфигурации?

| Инструмент | Путь к файлу конфигурации |
| - | - |
| Claude Code | Настраивается через переменные окружения |
| Codex | `~/.codex/config.toml` и `~/.codex/auth.json` |
| RooCode | JSON-настройки VS Code |
| Qwen Code | Настраивается через переменные окружения |

### Что делать, если не удаётся подключиться к FishXCode?

1. Убедитесь, что `BASE_URL` равен `https://api.fishxcode.com/` (обратите внимание на `/` в конце)
2. Проверьте, доступен ли `fishxcode.com` из вашей сети
3. Если вы в корпоративной сети, проверьте настройки прокси

## Выбор модели

### Как выбрать подходящую модель?

Выбирайте в зависимости от сценария:

| Сценарий | Рекомендуемая модель | Почему |
| - | - | - |
| Повседневное программирование | `claude-sonnet-4-5-20250929` | Баланс возможностей и скорости |
| Быстрое автодополнение | `claude-3-5-haiku-20241022` | Быстрый отклик |
| Сложная архитектура | `claude-sonnet-4-5-20250514` | Сильные навыки рассуждения |

### Чем различаются модели?

- **Серия Sonnet**: универсальные возможности, подходит для большинства задач программирования
- **Серия Haiku**: лёгкие и быстрые модели для простого автодополнения и форматирования
- Подробные различия в возможностях моделей смотрите в официальной документации поставщиков

### Как переключить модель?

Укажите модель в переменной окружения `ANTHROPIC_MODEL`:

```bash
export ANTHROPIC_MODEL=claude-sonnet-4-5-20250929
```

## Устранение неполадок

### Ошибка аутентификации (Auth Error)

<Callout type="warn" title="Частые причины">
  - Токен введён с ошибкой (лишние пробелы или неполный)
  - Токен удалён или сгенерирован заново
  - `API_KEY` и `AUTH_TOKEN` не заданы одновременно
</Callout>

Решение: откройте [консоль](https://fishxcode.com/console/token), проверьте статус токена, заново скопируйте и вставьте его.

### Как просматривать и понимать журнал ошибок?

Откройте [Консоль → Журнал использования](https://fishxcode.com/console/log) и переключите тип журнала на **Журнал ошибок** — записи можно фильтровать по времени, модели, токену, группе, ID запроса, сообщению об ошибке и коду состояния.

<Callout type="idea" title="Советы по диагностике">
  - Прежде всего скопируйте `request_id` из ответа API или журнала и найдите именно этот запрос в журнале использования
  - В фильтре «Сообщение об ошибке» ищите ключевые слова из `content`, например `Invalid token`, `Upstream request failed`
  - Фильтр «Код состояния» помогает быстро сгруппировать проблемы по типу, например `400`, `401`, `403`, `413`, `429`, `500`, `502`, `503`, `504`
  - Если одинаковые ошибки массово возникают в одной группе, сначала на уровне группы определите, в чём дело: в настройках, в объёме использования или в доступности upstream-провайдера
</Callout>

Полное описание полей, классификацию кодов состояния и таблицу частых ошибок смотрите на странице [Журнал ошибок](/ru/error-logs).

### Как читать состояние групп?

Состояние групп помогает понять, сбоят ли отдельные запросы или проблема массово затронула определённый тариф, модель или группу upstream-провайдера. Сначала смотрите `success_rate`, `error_count` и `error_reasons`, а затем находите конкретный запрос по `request_id` из записи журнала.

Полную страницу статуса, описание полей и порядок диагностики смотрите на странице [Состояние групп](/ru/group-health).

### Тайм-аут запроса (Timeout)

Возможные причины:

1. Высокая сетевая задержка
2. Слишком длинный контекст запроса, поэтому модели нужно больше времени на обработку
3. Высокая текущая нагрузка на сервис

Что делать: сократите входной контекст или повторите попытку позже.

### Превышен лимит частоты или квоты (Rate Limit)

Код состояния `429` обычно означает слишком частые запросы, но может также указывать на исчерпанную дневную квоту аккаунта upstream-провайдера или на охлаждение учётных данных текущей модели.

<Callout type="idea" title="Что делать">
  - Снизьте частоту запросов и повторяйте попытки с интервалом в несколько секунд
  - Не вызывайте API в скриптах в цикле без пауз
  - Проверьте, не использует ли тот же токен одновременно другой процесс
  - Если в журнале есть `Max 10/min` или `Max 5/min`, снизьте параллелизм и число запросов в минуту ниже указанного порога
  - Если в журнале есть `daily limit exceeded`, дождитесь сброса дневной квоты или переключитесь на другую доступную модель или группу
  - Если в журнале есть `cooling down`, не повторяйте запросы сразу подряд: дождитесь окончания охлаждения или временно смените модель
</Callout>

### Модель недоступна (Model Not Available)

Проверьте правильность названия модели и сверьтесь со списком рекомендуемых моделей в разделе [Быстрый старт](/ru/start). Некоторые модели могут быть ещё недоступны в FishXCode.
