Платформа FishXCode поддерживает AI-модели от нескольких поставщиков для разных сценариев и наборов инструментов. Вы можете свободно выбирать модели и переключаться между ними под свои задачи.

<ModelCatalog />

## Переключение моделей

### Claude Code

Основная модель задаётся через переменную окружения:

```bash tab="Linux/macOS"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL = "claude-fable-5-2"
claude
```

### Codex

Откройте `~/.codex/config.toml` и измените поле `model`:

```toml
model = "gpt-6.2-sol"
```

### RooCode / Qwen Code

Достаточно изменить поле **Model** в настройках провайдера. Можно указать ID любой из перечисленных выше совместимых моделей.
