## 一、平台概述

FishXCode 是一个面向开发者和团队使用的 AI 接入平台。你可以把它理解成一个统一入口：前面是官网、定价和文档，后面是控制台、令牌、充值、发票和使用记录。

平台围绕主流 AI 模型提供中转服务，具体渠道和模型以官网实际为准，请前往 [定价页](https://fishxcode.com/pricing) 查看。用户从注册开始，到创建令牌、接入工具、查看消耗，整套流程都在同一个系统里完成。

## 三、控制台功能速查

登录后所有操作集中在控制台，可按使用场景快速定位：

### 开通使用

1. 注册账号 → 登录控制台
2. **API 密钥**：创建 API Key（选择合适的分组）
3. 将 Base URL 和 API Key 配置到你的工具中

### 购买与充值

- **钱包 → 余额充值**：支持支付宝、Waffo Pancake 和兑换码
- **余额查看**：钱包页与概览页实时显示

### 使用管理

- **使用日志**：查看每次调用记录，包含模型、消耗、IP 等详情
- **API 密钥**：查看密钥状态、分组范围，删除或禁用不再使用的密钥
- **个人资料**：查看签到奖励和基础统计

### 售后与支持

- **邀请返利**：钱包页底部查看推荐计划的邀请链接与奖励收益
- **服务状态**：排查调用异常时查看各分组是否正常
- **联系我们**：处理使用问题、采购沟通和售后支持
