## 1. Registration and Login

### 1. Create an account

Visit [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW) to open the registration page:

![FishXCode registration page](/img/start/api-v2-01-home.png)

Fill in the registration form: set a username and a password (8–128 characters; we recommend uppercase and lowercase letters, digits, and symbols), and enter the email address that will receive the verification code:

![Fill in registration details](/img/start/api-v2-03-register-form.png)

<Callout type="idea" title="Supported email domains">
  Email registration currently supports four domains: **qq.com, 126.com, 163.com, gmail.com**. Other domains may not receive the verification code.
</Callout>

Click **Send verification code**. After completing the Cloudflare human verification, the code is sent to your inbox. Find the code (a 6-character alphanumeric combination) in your inbox and enter it in the form:

![Enter the email verification code](/img/start/api-v2-02-register-verify.png)

Click **Create account** to finish registration. The page redirects to the login page with the message “Account created! Please log in”.

<Callout type="warn" title="Not receiving the verification code?">
  1. Make sure the email domain is on the supported list (qq.com / 126.com / 163.com / gmail.com)
  2. Check your spam folder
  3. Wait 1–2 minutes and retry; avoid frequent requests
  4. If it still does not arrive, switch to third-party authorized login
</Callout>

### 2. Log in

After registering, log in with your username and password, or use one-click third-party authorized login:

![Login page](/img/start/api-v2-04-login.png)

| Login method | Description |
| - | - |
| Email-registered account | Log in with username/email + password |
| GitHub | Authorized login; recommended for developers |
| LinuxDO | Authorized login for community users |
| Google | Authorized login with a Google account |

<Callout type="info" title="Third-party login creates the account automatically">
  The first time you log in with GitHub / LinuxDO / Google, an account is created automatically — no separate registration needed.
</Callout>

After logging in you land on the console (Overview page):

## 2. Get an API Key

### 1. Create an API Key

Go to **Console → API Keys** and click **Create API Key** in the top-right corner:

![Create API Key dialog](/img/start/api-v2-06-token-create.png)

Form fields:

| Field | Description |
| - | - |
| Name | A custom key name so you can recognize its purpose |
| Group | Determines the available models and the billing multiplier; see below |
| Expiry | Never / 1 month / 1 day / 1 hour |
| Quantity | You can batch-create several keys at once (a random suffix is added to each name) |
| Unlimited quota | Enabled by default; disable it to cap the maximum usage of this key |
| Advanced settings | IP allowlist (CIDR supported), allow querying user quota |

- For **Group**, we recommend **claude** (1.5x): this group is the official full-price Claude Max 20 account pool with full performance. When using a Codex monthly package you must select `codex-sub-june`. For all groups and multipliers see [Billing Rules & Groups](/en/billing-groups).
- The **IP allowlist** suits servers with a fixed outbound IP; be careful using it for local development, since an IP change will break your calls.

Click **Save changes** to finish. In the key list, click **Copy** to get the API Key (format `sk-xxx`):

![Copy the API Key](/img/start/api-v2-07-token-copy.png)

<Callout type="idea" title="API endpoint">
  Click **API Endpoint** in the top-right corner of the page to see the access addresses. The console shows `https://fishxcode.com` by default; `https://api.fishxcode.com` works as well. Both behave identically — pick either one.
</Callout>

### 2. Top up

Go to **Console → Wallet**. The page has two tabs: **Balance top-up** and **Subscription plans**:

![Wallet balance top-up](/img/start/api-v2-08-wallet.png)

**Balance top-up**: choose a preset amount ($1 / $5 / $10 / $100 / $500 / $1,000; large amounts get a 1%–3% discount) or enter a custom amount, then choose a payment method:

![Payment methods and redeem codes](/img/start/api-09-payment.png)

| Method | Description |
| - | - |
| Alipay | The mainstream top-up method, no minimum |
| Waffo Pancake | Minimum top-up $100 |
| Redeem code | Enter it in the “Got a redeem code?” area and click **Redeem credits** |

**Subscription plans**: buy a Codex account-pool monthly package ($20 / $200 / $2,000 tiers), then create keys with the `codex-sub-june` group to use it. See [Subscription Plans](/en/subscription-plans):

![Subscription plans tab](/img/start/api-10-subscription.png)

<Callout type="idea" title="New-user bonus">
  Newly registered accounts automatically get a **$0.2** trial balance you can use to test API calls right away.
</Callout>

<Callout type="idea" title="How multipliers work">
  The multiplier in a group name is the billing factor: the smaller the value, the less the same request costs. For example, consuming 1 unit on a `0.5x` group corresponds to the token volume that would cost 2 units at the official price. See [Billing Rules & Groups](/en/billing-groups).
</Callout>

## 3. Account security

Go to **Console → Security & Access** to manage account security settings:

![Security & Access page](/img/start/api-12-security.png)

| Feature | Description |
| - | - |
| Change password | Rotate regularly: at least 8 characters with upper- and lowercase letters and digits |
| Account linking | After linking GitHub / LinuxDO / Google you can log in with one-click authorization |
| Login sessions | See current logged-in devices and remotely sign out other sessions |
| Access API Key | Used when calling the dashboard API; create it with the permissions you need |
| Passkey login | Passwordless sign-in with a passkey |
| Two-factor authentication | Add an extra layer of security to your account |

### API Key security tips

- **Rotate regularly**: replace keys every 30–90 days to reduce the risk of leaks
- **Never store keys in plain text**: avoid hard-coding API Keys in source code or committing them to Git; use environment variables instead
- **Least privilege**: create separate keys per project for easier management and tracking
- **If a key leaks**: if you suspect a key has leaked, delete it immediately on the **API Keys** page and create a new one

<Callout type="warn" title="Note">
  Deleting a key is irreversible. Once deleted, the key stops working immediately and tools using it can no longer make calls.
</Callout>

## 4. FAQ

### Not receiving the verification code when registering?

1. Make sure the email domain is on the supported list (qq.com / 126.com / 163.com / gmail.com)
2. Check your spam/junk folder
3. Wait 1–2 minutes and retry; avoid frequent requests
4. If it still does not arrive, use third-party authorized login with GitHub / LinuxDO / Google

### Where do I find my API Key after creating it?

Go to **Console → API Keys**; created keys appear in the list. Click the copy button to get the API Key in `sk-xxx` format.

### What if my top-up has not arrived?

1. Confirm the payment succeeded (check the transaction record in Alipay or your payment channel)
2. Wait 1–5 minutes; the system may have a short delay
3. Refresh the console Wallet page
4. If it still has not arrived after 10 minutes, contact us via [Contact](https://fishxcode.com/contact) with your payment record

### How do I view usage details?

Go to **Console → Usage Logs** to see, for every API call:

- Time of the call and the model name
- Token consumption and cost
- Request IP and detailed records

More log types (audit logs, task logs) can be switched in the sidebar.
