## 1. Prepare your environment

### Install Node.js

Claude Code is installed via npm, so make sure Node.js is ready first.

```bash tab="macOS - Verify"
node -v
npm -v
```

```bash tab="macOS - Install with Homebrew"
brew install node
```

```bash tab="Windows - Verify (CMD/PowerShell)"
node -v
npm -v
```

If it is not installed, download the installer for your platform from [nodejs.org/zh-cn/download](https://nodejs.cn/download/current/). After installing, **Windows requires a restart**.

### Windows extra: install Git Bash

Claude Code relies on a bash environment, so Windows users need Git Bash:

1. Download from [git-scm.com/install/windows](https://git-scm.com/install) and install the matching version.
2. Verify: right-click the desktop — if **Open Git Bash here** appears, the installation succeeded.

## 3. Configure FishXCode

1. Type `npx zcf` in the terminal and press Enter.
   When `Ok to proceed? (y)` appears, type `y` and press Enter.

2. Select the ZCF display language:
   Choose **Simplified Chinese**.

3. After installation completes, select:
   `1. Full Init - Install Claude Code + Import Workflows + Configure API or CCR Proxy + Configure MCP Services`

4. Modify template language configuration:
   Select `No`

5. AI output language:
   Select `Simplified Chinese`

6. Install Claude:
   Select `Yes`

7. API configuration mode:
   Select `Custom API Configuration`

8. API provider:
   Select `Custom Configuration`

9. Configuration name:
   Enter a custom name in English

10. Authentication type:
    Select `API Key`

11. API Base URL:
    ```
    https://api.fishxcode.com
    ```
    <Callout type="idea" title="Access endpoints">
      Both `https://api.fishxcode.com` and `https://fishxcode.com` work as access endpoints. They behave identically — pick either one.
    </Callout>

12. API Key:
    Enter the API Key created in the FishXCode console (Console → API Keys)

13. Model-related configuration:
    Press Enter to skip with defaults

14. Workflow type:
    Select `General Tools`

15. Output style:
    Choose according to personal preference

16. Configure MCP:
    Select `Yes`

17. MCP services:
    Use Space to select the services you need, then press Enter to proceed

18. Configure CCometixLine:
    Press Enter directly

19. Back at the main menu, enter:
    ```
    q
    ```

20. In the terminal, type:
    ```
    claude
    ```
    - Select `Yes, I trust this folder`
    - For the API choice, make sure to select **YES (the first option)**

## 5. Switch models

Type `/model` in the Claude Code chat interface to switch models:

| Option | Actual model | Description |
| - | - | - |
| **Default** | `claude-fable-5-2` + `claude-haiku-5-5` | Picks automatically based on the task; recommended for daily use |
| **Opus** | `claude-opus-5-5` | Strongest reasoning, higher consumption |
| **Haiku** | `claude-haiku-5-5` | Lightweight and fast |

You can also pin a model with an environment variable:

```bash tab="macOS/Linux"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL="claude-fable-5-2"
claude
```

<Callout type="idea" title="Upgrading Claude Code">
  If the model version is not the latest, run the upgrade command and restart the relevant tools:

  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
</Callout>

Path: File → Settings → Plugins → Marketplace → search `claude code`, find **Claude Code Terminal** and install:

![Verify the plugin has loaded](/img/start/idea-02-verify.png)

<Callout type="info">
  If you cannot find it in the plugin marketplace, your IDEA version is too old — upgrade to the latest version.
</Callout>

### VSCode

Press `Ctrl + Shift + X` to open the Extensions panel, search `claude code`, and install **Claude Code for VSCode**.

![Search and install the Claude Code plugin](/img/start/vscode-01-install.png)

Once installed, the plugin offers three ways to connect:

![Claude Code plugin connection options](/img/start/vscode-02-login.png)

We recommend connecting to FishXCode via `settings.json`. Click the **gear icon** at the bottom right of the plugin → **Edit in settings.json**:

![Open settings.json for editing](/img/start/vscode-03-settings.png)

Add the following to VSCode's `settings.json`:

```json
{
  "claudeCode.preferredLocation": "panel",
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "replace with your API Key" },
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.fishxcode.com/" }
  ]
}
```

<Callout type="idea" title="Access endpoints">
  `ANTHROPIC_BASE_URL` can also be set to `https://fishxcode.com/` — both addresses behave identically, pick either one.
</Callout>

![settings.json configuration example](/img/start/vscode-04-config.png)

After saving, **quit and reopen VSCode**; the plugin can then connect to FishXCode normally.

![Using Claude Code in VSCode](/img/start/vscode-05-demo.gif)

## 7. FAQ

### 403 error

Your balance is insufficient — top up in the console and retry.

### Connection issues or 400/401 errors on Windows

Re-run the `setx` commands in PowerShell to write the system variables, then reopen the terminal:

```powershell
setx ANTHROPIC_AUTH_TOKEN "sk-xxx"
setx ANTHROPIC_BASE_URL "https://api.fishxcode.com/"
```

### "Unable to connect to Anthropic services"

The full error looks like this:

```
Unable to connect to Anthropic services
Failed to connect to api.anthropic.com: ERR_BAD_REQUEST
Please check your internet connection and network settings.
```

This happens because Claude Code has not completed onboarding and still tries to reach the official `api.anthropic.com`. **No VPN is needed** — add `"hasCompletedOnboarding": true` at the end of `~/.claude.json` (note: this is `.claude.json` in your home directory, not `.claude/settings.json`) to skip it:

```json
{
  "installMethod": "unknown",
  "autoUpdates": true,
  "projects": { ... },
  "hasCompletedOnboarding": true
}
```

<Callout type="idea">
  Remember to add a comma at the end of the previous field before appending (JSON syntax requires it). After the change, run `claude` again and it connects normally.
</Callout>
