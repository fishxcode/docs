## Install OpenCode

```bash tab="npm"
npm install -g opencode-ai@latest
```

```bash tab="brew"
brew install anomalyco/tap/opencode
```

```bash tab="scoop"
scoop install opencode
```

## Configure FishXCode

1. Get your API Key from [https://fishxcode.com/keys](https://fishxcode.com/keys)
2. Set the environment variable:

```bash tab="Linux/macOS"
export FISHXCODE_TOKEN=sk-xxx
```

```powershell tab="Windows PowerShell"
$env:FISHXCODE_TOKEN="sk-xxx"
```

3. Create `opencode.json` in your project root or `~/.config/opencode/`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "fishxcode-anthropic": {
      "npm": "@ai-sdk/anthropic",
      "name": "fishxcode-anthropic",
      "options": {
        "baseURL": "https://api.fishxcode.com/v1",
        "apiKey": "{env:FISHXCODE_TOKEN}"
      },
      "models": {
        "claude-sonnet-4-6": {
          "name": "claude-sonnet-4-6"
        }
      }
    },
    "fishxcode-openai": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "fishxcode-openai",
      "options": {
        "baseURL": "https://api.fishxcode.com/v1",
        "apiKey": "{env:FISHXCODE_TOKEN}"
      },
      "models": {
        "gpt-6.2-sol": {
          "name": "gpt-6.2-sol"
        }
      }
    }
  }
}
```

<Callout type="warn" title="Important">
  Replace `sk-xxx` with your actual Token from the [FishXCode console](https://fishxcode.com/keys).
</Callout>

## Launch

```bash
cd my-project
opencode
```

Once launched, select a model under the FishXCode provider to start coding.
