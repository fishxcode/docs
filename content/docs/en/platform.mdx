## 1. Platform overview

FishXCode is an AI access platform for developers and teams. Think of it as a single entry point: in front are the main site, pricing, and documentation; behind are the console, API Keys, top-ups, invoices, and usage records.

The platform provides relay services around mainstream AI models. Exact channels and models are subject to the main site — see the [pricing page](https://fishxcode.com/pricing). From signing up to creating keys, connecting tools, and checking consumption, the entire workflow happens in one system.

## 3. Console features quick reference

After logging in, everything happens in the console. Locate features by scenario:

### Getting started

1. Register an account → log in to the console
2. **API Keys**: create an API Key (pick a suitable group)
3. Configure the Base URL and API Key in your tool

### Purchase and top-up

- **Wallet → Balance top-up**: Alipay, Waffo Pancake, and redeem codes supported
- **Balance visibility**: shown in real time on the Wallet and Overview pages

### Usage management

- **Usage Logs**: every call with model, consumption, IP, and more
- **API Keys**: check key status and group scope; delete or disable unused keys
- **Profile**: check-in rewards and basic statistics

### After-sales and support

- **Referral rewards**: find your referral-program invite link and reward earnings at the bottom of the Wallet page
- **Service Status**: check group health when calls misbehave
- **Contact**: usage issues, procurement discussions, and after-sales support
