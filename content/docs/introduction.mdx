FishXcode 是面向开发者的 AI API 中转聚合平台：一个 API Key 统一调用 Claude、GPT、Gemini 等全球主流大模型，兼容 OpenAI 协议，无需海外账号。

## 快速开始

前往 [控制台](https://fishxcode.com) 注册并创建 API Key，即可开始调用。
