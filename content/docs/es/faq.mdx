## General

### ¿Qué es FishXCode?

FishXCode es una plataforma integral de acceso a modelos de IA y servicios de cuentas que cubre Claude, Codex, Kiro, Grok, modelos nacionales y multimodales, utilizable en multitud de herramientas y plataformas.

### ¿Qué herramientas admite?

Actualmente se admiten estas herramientas:

- **Claude Code** — la CLI oficial de Anthropic
- **OpenAI Codex** — el asistente de programación oficial de OpenAI
- **RooCode** — extensión de programación con IA para VS Code
- **Qwen Code** — herramienta de programación de Alibaba Tongyi Qianwen
- **Droid CLI** — CLI ligera de programación con IA
- **OpenCode** — herramienta de terminal de programación con IA de código abierto

### ¿Cómo se protege la privacidad de los datos?

FishXCode actúa solo como intermediario de la API y no almacena tu código ni el contenido de las conversaciones. Todas las solicitudes se reenvían directamente al proveedor del modelo correspondiente.

<Callout type="idea" title="Recomendación">
  Para proyectos sensibles, lee la política de privacidad de cada proveedor de modelos antes de usarlos.
</Callout>

## Cuentas y API Keys

### ¿Cómo me registro?

Visita [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW), rellena nombre de usuario, contraseña y correo, e introduce el código de verificación enviado a tu correo para completar el registro. También puedes iniciar sesión directamente con la autorización de GitHub / LinuxDO / Google (la primera autorización crea la cuenta automáticamente).

<Callout type="idea" title="Dominios de correo admitidos">
  El registro por correo admite actualmente cuatro dominios: **qq.com, 126.com, 163.com, gmail.com**.
</Callout>

### ¿Cómo obtengo una API Key?

Tras registrarte, inicia sesión en la consola y ve a la [página de Claves API](https://fishxcode.com/keys) para crear una nueva API Key.

### ¿Qué métodos de recarga hay?

Ve a **Consola → Monedero** para recargar. Se admiten:

- **Alipay**: el método habitual, sin importe mínimo
- **Waffo Pancake**: recarga mínima de $100
- **Código de canje**: introdúcelo en la zona de canje de la página del monedero

Los usuarios intensivos de Codex también pueden comprar directamente un paquete mensual del pool de cuentas (pestaña Planes de suscripción); ver [Planes de suscripción](/es/subscription-plans).

### ¿Cuánto dura una API Key?

Una API Key sigue siendo válida hasta que la elimines o la regeneres. Rótala periódicamente por seguridad.

### ¿Cuál es mi cuota de uso?

FishXCode otorga a cada usuario una cuota de uso, ajustada dinámicamente según los recursos de la plataforma. Presta atención a la información de uso en la consola.

<Callout type="warn" title="Atención">
  Las solicitudes se rechazan una vez agotada la cuota; planifica tu uso en consecuencia.
</Callout>

## Configuración de herramientas

### Las variables de entorno no surten efecto

Comprueba estas causas habituales:

1. **Terminal no reiniciada** — tras editar `.bashrc` / `.zshrc`, ejecuta `source ~/.bashrc` o abre una terminal nueva
2. **Nombre de variable mal escrito** — se distinguen mayúsculas y minúsculas; `ANTHROPIC_BASE_URL` no puede escribirse como `Anthropic_Base_Url`
3. **Comillas o espacios de más** — en `export KEY="value"` no dejes espacios sobrantes alrededor del valor

<Accordions type="single">
  <Accordion title="Comandos de comprobación rápida">
    ```bash
    # Comprobar si las variables están establecidas
    echo $ANTHROPIC_BASE_URL
    echo $ANTHROPIC_AUTH_TOKEN

    # Si la salida está vacía, las variables no están en vigor
    ```
  </Accordion>
</Accordions>

### ¿Dónde están los archivos de configuración?

| Herramienta | Ruta del archivo de configuración |
| - | - |
| Claude Code | Configuración por variables de entorno |
| Codex | `~/.codex/config.toml` y `~/.codex/auth.json` |
| RooCode | JSON de ajustes de VS Code |
| Qwen Code | Configuración por variables de entorno |

### ¿No puedo conectar con FishXCode?

1. Confirma que `BASE_URL` es `https://api.fishxcode.com/` o `https://fishxcode.com/` (ambas valen y se comportan igual)
2. Comprueba que tu red alcanza `fishxcode.com`
3. En una red corporativa, revisa que la configuración del proxy es correcta

## Selección de modelos

### ¿Cómo elegir el modelo adecuado?

Elige según el caso de uso:

| Caso de uso | Modelo recomendado | Por qué |
| - | - | - |
| Programación diaria | `claude-fable-5-2` | Equilibrio entre capacidad y velocidad |
| Autocompletado rápido | `claude-haiku-5-5` | Respuesta rápida |
| Arquitectura compleja | `claude-fable-5-2` | Mayor capacidad de razonamiento |

### ¿Qué diferencias hay entre los modelos?

- **Serie Sonnet**: capacidades completas, adecuada para la mayoría de tareas de programación
- **Serie Haiku**: ligera y rápida, adecuada para autocompletados simples y formateo
- Para las diferencias detalladas de cada modelo, consulta la documentación oficial de cada proveedor

### ¿Cómo cambio de modelo?

Especifícalo con la variable de entorno `ANTHROPIC_MODEL`:

```bash
export ANTHROPIC_MODEL=claude-fable-5-2
```

## Resolución de problemas

### Error de autenticación (Auth Error)

<Callout type="warn" title="Causas habituales">
  - La clave se introdujo mal (espacios de más o incompleta)
  - La clave fue eliminada o regenerada
  - `API_KEY` y `AUTH_TOKEN` no están establecidas a la vez
</Callout>

Solución: ve a la [página de Claves API](https://fishxcode.com/keys), comprueba el estado de la clave y cópiala y pégala de nuevo.

### ¿Cómo ver y entender los registros de errores?

Ve a [Consola → Registros de uso](https://fishxcode.com/usage-logs/common) y cambia el tipo de registro a **Registros de errores**. Puedes filtrar por hora, modelo, clave, grupo, ID de solicitud, mensaje de error y código de estado.

<Callout type="idea" title="Consejos de diagnóstico">
  - Copia primero el `request_id` de la respuesta de la API o del registro y búscalo con precisión en Registros de uso para encontrar la misma solicitud
  - Busca palabras clave de `content` con «Mensaje de error», por ejemplo `Invalid token`, `Upstream request failed`
  - Agrega rápidamente los tipos de problema por «Código de estado», por ejemplo `400`, `401`, `403`, `413`, `429`, `500`, `502`, `503`, `504`
  - Si el mismo error se concentra en un grupo, valora primero por el grupo si se trata de un problema de configuración, de uso o de disponibilidad del upstream
</Callout>

Para la descripción completa de campos, la clasificación de códigos de estado y la tabla de errores habituales, consulta [Guía de registros de errores](/es/error-logs).

### ¿Cómo interpretar el estado de salud de los grupos?

El estado de salud de los grupos sirve para saber si un problema es una anomalía puntual de alguna solicitud o un fallo concentrado de un plan, modelo o grupo del upstream. Mira primero `success_rate`, `error_count` y `error_reasons`, y usa después el `request_id` de los registros individuales para localizar solicitudes concretas.

Para la página completa de estados, la descripción de campos y el flujo de diagnóstico, consulta [Estado de salud de los grupos](/es/group-health).

### Tiempo de espera agotado (Timeout)

Causas posibles:

1. Latencia de red elevada
2. Contexto de la solicitud muy largo, y el modelo tarda más en procesarlo
3. Carga del servicio elevada en este momento

Sugerencias: reduce el contexto de entrada o reintenta más tarde.

### Límite de frecuencia o de cuota alcanzado (Rate Limit)

Un código de estado `429` suele indicar solicitudes demasiado frecuentes. También puede indicar que la cuota diaria de una cuenta del upstream se agotó, o que la credencial del modelo actual está enfriándose.

<Callout type="idea" title="Cómo actuar">
  - Reduce la frecuencia de solicitudes y reintenta tras unos segundos
  - Evita llamar a la API en bucles sin pausas dentro de scripts
  - Comprueba si otro proceso está usando la misma clave al mismo tiempo
  - Si el registro contiene `Max 10/min` o `Max 5/min`, reduce la concurrencia y las solicitudes por minuto por debajo del umbral indicado
  - Si el registro contiene `daily limit exceeded`, espera a que la cuota diaria se restablezca o cambia a otro modelo/grupo disponible
  - Si el registro contiene `cooling down`, no reintentes de inmediato en cadena; espera a que termine el enfriamiento o cambia de modelo temporalmente
</Callout>

### Modelo no disponible (Model Not Available)

Comprueba que el nombre del modelo es correcto; consulta la lista de modelos recomendados en [Inicio rápido](/es/start). Algunos modelos pueden no estar disponibles aún en FishXCode.
