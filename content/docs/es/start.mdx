## 1. Preparar el entorno

### Instalar Node.js

Claude Code se instala vía npm, así que confirma primero que Node.js está listo.

```bash tab="macOS - Verificar"
node -v
npm -v
```

```bash tab="macOS - Instalar con Homebrew"
brew install node
```

```bash tab="Windows - Verificar (CMD/PowerShell)"
node -v
npm -v
```

Si no está instalado, descarga el instalador de tu plataforma en [nodejs.org/zh-cn/download](https://nodejs.cn/download/current/). Tras instalar, **en Windows hay que reiniciar**.

### Extra para Windows: instalar Git Bash

Claude Code depende de un entorno bash, así que los usuarios de Windows necesitan Git Bash:

1. Descarga desde [git-scm.com/install/windows](https://git-scm.com/install) e instala la versión correspondiente.
2. Verificación: haz clic derecho en el escritorio; si aparece la opción **Open Git Bash here**, la instalación fue correcta.

## 3. Configurar FishXCode

1. Escribe `npx zcf` en la terminal y pulsa Enter.
   Cuando aparezca `Ok to proceed? (y)`, escribe `y` y pulsa Enter.

2. Selecciona el idioma de visualización de ZCF:
   Elige **Simplified Chinese**.

3. Cuando la instalación termine, selecciona:
   `1. Full Init - Install Claude Code + Import Workflows + Configure API or CCR Proxy + Configure MCP Services`

4. ¿Modificar la configuración de idioma de las plantillas?
   Selecciona `No`

5. Idioma de salida de la IA:
   Selecciona `Simplified Chinese`

6. ¿Instalar Claude?
   Selecciona `Yes`

7. Modo de configuración de la API:
   Selecciona `Custom API Configuration`

8. Proveedor de la API:
   Selecciona `Custom Configuration`

9. Nombre de la configuración:
   Introduce un nombre personalizado en inglés

10. Tipo de autenticación:
    Selecciona `API Key`

11. URL base de la API:
    ```
    https://api.fishxcode.com
    ```
    <Callout type="idea" title="Direcciones de acceso">
      Tanto `https://api.fishxcode.com` como `https://fishxcode.com` sirven como direcciones de acceso. Se comportan igual: elige la que prefieras.
    </Callout>

12. API Key:
    Introduce la API Key creada en la consola de FishXCode (Consola → Claves API)

13. Configuración relacionada con modelos:
    Pulsa Enter para omitir con los valores por defecto

14. Tipo de flujo de trabajo:
    Selecciona `General Tools`

15. Estilo de salida:
    Elige según tu preferencia personal

16. ¿Configurar MCP?
    Selecciona `Yes`

17. Servicios MCP:
    Usa la barra espaciadora para marcar los servicios que necesites y pulsa Enter

18. Configurar CCometixLine:
    Pulsa Enter directamente

19. De vuelta en el menú principal, introduce:
    ```
    q
    ```

20. En la terminal, escribe:
    ```
    claude
    ```
    - Selecciona `Yes, I trust this folder`
    - Al elegir la API, asegúrate de seleccionar **YES (la primera opción)**

## 5. Cambiar de modelo

Escribe `/model` en la interfaz de conversación de Claude Code para cambiar de modelo:

| Opción | Modelo real | Descripción |
| - | - | - |
| **Default** | `claude-fable-5-2` + `claude-haiku-5-5` | Elige automáticamente según la tarea; recomendado para el uso diario |
| **Opus** | `claude-opus-5-5` | El mayor capacidad de razonamiento, mayor consumo |
| **Haiku** | `claude-haiku-5-5` | Ligero y rápido |

También puedes fijar el modelo con una variable de entorno:

```bash tab="macOS/Linux"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL="claude-fable-5-2"
claude
```

<Callout type="idea" title="Actualizar Claude Code">
  Si la versión del modelo no es la más reciente, ejecuta el comando de actualización y reinicia las herramientas correspondientes:

  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
</Callout>

## 6. Integración con IDE

### IntelliJ IDEA

Ruta: File → Settings → Plugins → Marketplace → busca `claude code`, encuentra **Claude Code Terminal** e instálalo:

![Instalar Claude Code Terminal](/img/start/idea-01-install.png)

Tras instalar, reinicia IDEA y verifica que el complemento se ha cargado:

![Verificar que el complemento se ha cargado](/img/start/idea-02-verify.png)

<Callout type="info">
  Si no aparece en el marketplace de complementos, tu versión de IDEA es demasiado antigua: actualiza a la última versión.
</Callout>

### VSCode

Pulsa `Ctrl + Shift + X` para abrir el panel de extensiones, busca `claude code` e instala **Claude Code for VSCode**.

![Buscar e instalar el complemento de Claude Code](/img/start/vscode-01-install.png)

Una vez instalado, el complemento ofrece tres formas de conexión:

![Opciones de conexión del complemento de Claude Code](/img/start/vscode-02-login.png)

Recomendamos conectar a FishXCode mediante `settings.json`. Haz clic en el **icono de engranaje** de la esquina inferior derecha del complemento → **Edit in settings.json**:

![Abrir settings.json para editar](/img/start/vscode-03-settings.png)

Añade lo siguiente al `settings.json` de VSCode:

```json
{
  "claudeCode.preferredLocation": "panel",
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "sustitúyelo por tu API Key" },
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.fishxcode.com/" }
  ]
}
```

<Callout type="idea" title="Direcciones de acceso">
  `ANTHROPIC_BASE_URL` también puede ser `https://fishxcode.com/`; ambas direcciones se comportan igual, elige la que prefieras.
</Callout>

![Ejemplo de configuración en settings.json](/img/start/vscode-04-config.png)

Tras guardar, **cierra y vuelve a abrir VSCode**; el complemento podrá conectarse a FishXCode con normalidad.

![Usar Claude Code en VSCode](/img/start/vscode-05-demo.gif)

## 7. Preguntas frecuentes

### Error 403

Saldo insuficiente: recarga en la consola y reintenta.

### Problemas de conexión o errores 400/401 en Windows

Vuelve a ejecutar los comandos `setx` en PowerShell para escribir las variables del sistema y abre de nuevo la terminal:

```powershell
setx ANTHROPIC_AUTH_TOKEN "sk-xxx"
setx ANTHROPIC_BASE_URL "https://api.fishxcode.com/"
```

### Aparece "Unable to connect to Anthropic services"

El error completo es este:

```
Unable to connect to Anthropic services
Failed to connect to api.anthropic.com: ERR_BAD_REQUEST
Please check your internet connection and network settings.
```

Ocurre porque Claude Code no ha completado el onboarding y sigue intentando conectar con el `api.anthropic.com` oficial. **No necesitas VPN**: añade `"hasCompletedOnboarding": true` al final de `~/.claude.json` (ojo: es el `.claude.json` del directorio home, no `.claude/settings.json`) para saltártelo:

```json
{
  "installMethod": "unknown",
  "autoUpdates": true,
  "projects": { ... },
  "hasCompletedOnboarding": true
}
```

<Callout type="idea">
  Antes de añadirlo, añade una coma al final del campo anterior (lo exige la sintaxis JSON). Tras el cambio, ejecuta `claude` de nuevo y conectará con normalidad.
</Callout>
