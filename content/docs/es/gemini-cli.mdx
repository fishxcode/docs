## Notas de la plataforma

Gemini CLI se conecta mediante el protocolo compatible con OpenAI. Si el cliente ofrece campos personalizados de Base URL / API Key, complétalos con los datos anteriores; si solo admite endpoints compatibles con OpenAI, comprueba que la URL incluya `/v1`.
