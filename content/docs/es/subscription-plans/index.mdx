El paquete mensual del pool Codex Pro funciona sobre el pool de cuentas oficiales Codex Pro y se compra por meses con un crédito fijo. Está pensado para la programación intensiva con Codex y el desarrollo de agentes. Por ahora es la única serie de paquetes a la venta y ofrece tres niveles:

| Paquete | Precio | Crédito del paquete | Multiplicador de coste real | Validez | Restablecimiento del crédito | Ideal para |
| - | - | - | - | - | - | - |
| Paquete mensual con 2000 USD de crédito | $260 | $2,000 | 0.13x | 1 mes natural | No se restablece | Desarrollo intensivo y equipos empresariales |
| Paquete mensual con 200 USD de crédito | $30 | $200 | 0.15x | 1 mes natural | No se restablece | Crédito intermedio, la opción preferida para el desarrollo diario |
| Paquete mensual con 20 USD de crédito | $3.60 | $20 | 0.18x | 1 mes natural | No se restablece | Para empezar y usar con flexibilidad |

El precio y la disponibilidad de venta se rigen por la [página de precios](https://fishxcode.com/pricing).

## Cómo usarlo después de comprarlo

1. Compra el paquete mensual de Codex con el crédito que necesites.
2. En la consola, elige el grupo `codex-sub-june`.
3. Crea un nuevo token de API con ese grupo.
4. Configura el token en un cliente compatible para empezar a usarlo, por ejemplo [Codex](/es/codex) o [Codex Desktop](/es/codex-desktop).

## Reglas de facturación

- El grupo `codex-sub-june` tiene fijado un **multiplicador de 1x**.
- Multiplicador de coste real = precio del paquete ÷ crédito del paquete.
- Cada solicitud descuenta del crédito del paquete según los tokens que consume realmente.
- El paquete es válido durante 1 mes natural.
- El crédito del paquete no se restablece y el crédito no usado no se prorroga automáticamente.

<Callout type="idea" title="Ejemplo">
  Si pagas $260 por $2,000 de crédito, el multiplicador de coste real es **0.13x**, aunque el grupo sigue mostrando un multiplicador de 1x.
</Callout>

## A tener en cuenta

<Callout type="warn" title="Solo el grupo codex-sub-june puede usar el crédito del paquete mensual">
  Para el paquete mensual de Codex, el token debe crearse en el grupo `codex-sub-june`; los demás grupos no pueden usar el crédito de este paquete.
</Callout>

- El paquete mensual no tiene crédito ilimitado: cuando se agota el crédito o vence el paquete, ya no podrás seguir usándolo.
- Si no quieres comprar un paquete mensual, también puedes llamar a los grupos de la serie Codex pagando por uso con tu saldo; consulta [Reglas de facturación y grupos](/es/billing-groups).
