## 1. Registro e inicio de sesión

### 1. Crear una cuenta

Visita [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW) para abrir la página de registro:

![Página de registro de FishXCode](/img/start/api-v2-01-home.png)

Rellena el formulario de registro: establece un nombre de usuario y una contraseña (8–128 caracteres; se recomienda incluir mayúsculas, minúsculas, números y símbolos), e indica el correo electrónico que recibirá el código de verificación:

![Rellenar los datos de registro](/img/start/api-v2-03-register-form.png)

<Callout type="idea" title="Dominios de correo admitidos">
  El registro por correo admite actualmente cuatro dominios: **qq.com, 126.com, 163.com, gmail.com**. Otros dominios podrían no recibir el código de verificación.
</Callout>

Haz clic en **Enviar código de verificación**. Tras completar la verificación humana de Cloudflare, el código se envía a tu correo. Busca el código (una combinación alfanumérica de 6 caracteres) en tu bandeja de entrada e introdúcelo en el formulario:

![Introducir el código de verificación del correo](/img/start/api-v2-02-register-verify.png)

Haz clic en **Crear cuenta** para completar el registro. La página te lleva al inicio de sesión con el mensaje «Cuenta creada. Inicia sesión, por favor».

<Callout type="warn" title="¿No recibes el código de verificación?">
  1. Comprueba que el dominio del correo está en la lista admitida (qq.com / 126.com / 163.com / gmail.com)
  2. Revisa la carpeta de correo no deseado
  3. Espera 1–2 minutos y reintenta; evita solicitudes frecuentes
  4. Si sigue sin llegar, cambia al inicio de sesión autorizado de terceros
</Callout>

### 2. Iniciar sesión

Tras registrarte, inicia sesión con tu nombre de usuario y contraseña, o usa el inicio de sesión autorizado de terceros con un clic:

![Página de inicio de sesión](/img/start/api-v2-04-login.png)

| Método de inicio de sesión | Descripción |
| - | - |
| Cuenta registrada por correo | Inicio de sesión con nombre de usuario/correo + contraseña |
| GitHub | Inicio de sesión autorizado; recomendado para desarrolladores |
| LinuxDO | Inicio de sesión autorizado para usuarios de la comunidad |
| Google | Inicio de sesión autorizado con cuenta de Google |

<Callout type="info" title="El inicio de sesión de terceros crea la cuenta automáticamente">
  La primera vez que inicies sesión con GitHub / LinuxDO / Google se crea una cuenta automáticamente; no necesitas registrarte aparte.
</Callout>

Tras iniciar sesión entras en la consola (página de resumen):

![Resumen de la consola](/img/start/api-v2-05-console.png)

## 2. Obtener una API Key

### 1. Crear una API Key

Ve a **Consola → Claves API** y haz clic en **Crear API Key** en la esquina superior derecha:

![Diálogo de creación de API Key](/img/start/api-v2-06-token-create.png)

Campos del formulario:

| Campo | Descripción |
| - | - |
| Nombre | Nombre personalizado de la clave para reconocer su propósito |
| Grupo | Determina los modelos disponibles y el multiplicador de facturación; ver abajo |
| Caducidad | Nunca / 1 mes / 1 día / 1 hora |
| Cantidad | Puedes crear varias claves de una vez (se añade un sufijo aleatorio a cada nombre) |
| Cuota ilimitada | Activada por defecto; desactívala para limitar el consumo máximo de esta clave |
| Ajustes avanzados | Lista blanca de IP (admite CIDR), permitir consultar la cuota del usuario |

- Para el **grupo**, recomendamos <LiveRatio name="claude" />: es el grupo oficial de precio completo del pool de cuentas Claude Max 20, con pleno rendimiento. Para usar un paquete mensual de Codex debes seleccionar `codex-sub-june`. Consulta todos los grupos y multiplicadores en [Reglas de facturación y grupos](/es/billing-groups).
- La **lista blanca de IP** conviene a servidores con IP de salida fija; úsala con cautela en desarrollo local, porque un cambio de IP impedirá las llamadas.

Haz clic en **Guardar cambios** para terminar. En la lista de claves, pulsa el botón **Copiar** para obtener la API Key (formato `sk-xxx`):

![Copiar la API Key](/img/start/api-v2-07-token-copy.png)

<Callout type="idea" title="Dirección de la API">
  Haz clic en **Dirección de la API** en la esquina superior derecha de la página para ver las direcciones de acceso. La consola muestra `https://fishxcode.com` por defecto; `https://api.fishxcode.com` también funciona. Ambas se comportan igual: elige la que prefieras.
</Callout>

### 2. Recargar

Ve a **Consola → Monedero**. La página tiene dos pestañas: **Recarga de saldo** y **Planes de suscripción**:

![Recarga de saldo del monedero](/img/start/api-v2-08-wallet.png)

**Recarga de saldo**: elige un importe predefinido ($1 / $5 / $10 / $100 / $500 / $1,000; los importes grandes tienen un 1%–3% de descuento) o introduce un importe personalizado, y elige el método de pago:

![Métodos de pago y códigos de canje](/img/start/api-09-payment.png)

| Método | Descripción |
| - | - |
| Alipay | El método de recarga habitual, sin mínimo |
| Waffo Pancake | Recarga mínima de $100 |
| Código de canje | Introdúcelo en la zona «¿Tienes un código de canje?» y haz clic en **Canjear saldo** |

**Planes de suscripción**: compra un paquete mensual del pool de cuentas Codex ($20 / $200 / $2,000 en tres tramos) y, tras la compra, crea claves con el grupo `codex-sub-june` para usarlo. Más detalles en [Planes de suscripción](/es/subscription-plans):

![Pestaña de planes de suscripción](/img/start/api-10-subscription.png)

<Callout type="idea" title="Ventaja para nuevos usuarios">
  Las cuentas recién registradas reciben automáticamente un saldo de prueba de **$0.2**, utilizable para probar llamadas a la API.
</Callout>

<Callout type="idea" title="Cómo funcionan los multiplicadores">
  El multiplicador del nombre del grupo es el factor de facturación: cuanto menor es el valor, menos cuesta la misma solicitud. Por ejemplo, consumir 1 unidad en un grupo `0.5x` equivale al volumen de tokens que costaría 2 unidades al precio oficial. Más detalles en [Reglas de facturación y grupos](/es/billing-groups).
</Callout>

## 3. Seguridad de la cuenta

Ve a **Consola → Seguridad y acceso** para gestionar la seguridad de tu cuenta:

![Página de seguridad y acceso](/img/start/api-12-security.png)

| Función | Descripción |
| - | - |
| Cambiar contraseña | Rótala periódicamente: 8 caracteres o más, con mayúsculas, minúsculas y números |
| Vinculación de cuentas | Tras vincular GitHub / LinuxDO / Google puedes iniciar sesión con autorización de un clic |
| Sesiones de inicio | Consulta los dispositivos conectados y cierra otras sesiones a distancia |
| Clave de acceso | Para llamar a la API del panel; créala marcando los permisos que necesites |
| Inicio con Passkey | Inicio de sesión sin contraseña mediante llave de acceso |
| Verificación en dos pasos | Añade una capa extra de seguridad a tu cuenta |

### Consejos de seguridad para las claves

- **Rota periódicamente**: cambia las claves cada 30–90 días para reducir el riesgo de fuga
- **No las guardes en texto plano**: evita escribir la API Key directamente en el código o subirla a Git; usa variables de entorno
- **Mínimo privilegio**: crea claves separadas por proyecto para facilitar la gestión y el seguimiento
- **Si una clave se filtra**: si sospechas una fuga, elimina la clave de inmediato en la página **Claves API** y crea una nueva

<Callout type="warn" title="Atención">
  Eliminar una clave es irreversible. Al eliminarla deja de funcionar de inmediato y las herramientas que la usaban no podrán seguir llamando.
</Callout>

## 4. Preguntas frecuentes

### ¿No recibes el código de verificación al registrarte?

1. Comprueba que el dominio del correo está en la lista admitida (qq.com / 126.com / 163.com / gmail.com)
2. Revisa la carpeta de correo no deseado
3. Espera 1–2 minutos y reintenta; evita solicitudes frecuentes
4. Si sigue sin llegar, usa el inicio de sesión autorizado de terceros con GitHub / LinuxDO / Google

### ¿Dónde veo mi API Key después de crearla?

Ve a **Consola → Claves API**; las claves creadas aparecen en la lista. Pulsa el botón de copiar para obtener la API Key en formato `sk-xxx`.

### ¿Y si la recarga no llega?

1. Comprueba que el pago se realizó con éxito (revisa el registro de transacciones de Alipay o de tu canal de pago)
2. Espera 1–5 minutos; puede haber un pequeño retraso del sistema
3. Actualiza la página del monedero en la consola
4. Si tras 10 minutos sigue sin llegar, contacta por [Contacto](https://fishxcode.com/contact) aportando el registro del pago

### ¿Cómo consulto el detalle del consumo?

Ve a **Consola → Registros de uso** y verás, para cada llamada a la API:

- Hora de la llamada y nombre del modelo
- Consumo de tokens y coste
- IP de la solicitud y registros detallados

Más tipos de registros (auditoría, tareas) se pueden cambiar en la barra lateral.
