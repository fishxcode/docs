## Instalación en VSCode

1. Busca [RooCode](https://marketplace.visualstudio.com/items?itemName=RooVeterinaryInc.roo-cline) en VSCode e instálalo
2. Visita [https://fishxcode.com/keys](https://fishxcode.com/keys) para obtener tu API Key

## Agregar Proveedor

Abre RooCode y agrega un proveedor compatible con OpenAI:

| Configuración | Valor |
| - | - |
| **URL base de OpenAI** | `https://api.fishxcode.com/v1` |
| **API Key** | Tu clave de FishXCode |
| **Modelo** | `gpt-6.2-sol` |

<Callout type="idea" title="Consejo">
  También puedes usar `glm-5.3-flash`, `glm-5.3-flash`, o `deepseek-v4-1-flash-1017`.
</Callout>

Guarda y comienza a usar.
