FishXCode es compatible con una variedad de modelos de IA de multiples proveedores, cubriendo diferentes casos de uso y cadenas de herramientas. Puedes elegir y cambiar de modelo libremente segun tus necesidades.

<ModelCatalog />

## Cambiar de modelo

### Claude Code

Configura el modelo principal mediante variables de entorno:

```bash tab="Linux/macOS"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL = "claude-fable-5-2"
claude
```

### Codex

Edita `~/.codex/config.toml` y cambia el campo `model`:

```toml
model = "gpt-6.2-sol"
```

### RooCode / Qwen Code

Cambia el campo **Model** directamente en la configuracion del proveedor. Se puede usar cualquier ID de modelo compatible de la lista anterior.

## Recomendaciones

<Callout type="idea" title="Mejor para codificacion">
  **claude-opus-5-5** — La mayor capacidad de codificacion general, ideal para proyectos complejos y tareas de arquitectura.
</Callout>

<Callout type="idea" title="Mejor velocidad">
  **claude-haiku-5-5** — Tiempo de respuesta mas rapido, ideal para llamadas frecuentes y completaciones en tiempo real.
</Callout>

<Callout type="idea" title="Mejor equilibrio">
  **claude-fable-5-2** — Excelente equilibrio entre velocidad y calidad, adecuado para la mayoria de las tareas de desarrollo diarias.
</Callout>
