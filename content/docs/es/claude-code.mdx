## Notas de la plataforma

Claude Code se conecta mediante el protocolo compatible con Anthropic. Si el cliente ofrece campos personalizados de Base URL / API Key, complétalos con los datos anteriores; la URL base es `https://api.fishxcode.com`. Si el cliente requiere una dirección completa, añade rutas como `/v1/messages`.
