title: 支持的模型
---

FishXCode 平台支持来自多个供应商的 AI 模型，覆盖不同的使用场景和工具链。你可以根据实际需求自由选择和切换模型。

<ModelCatalog />

## 切换模型

### Claude Code

通过环境变量设置主模型：

```bash tab="Linux/macOS"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL = "claude-fable-5-2"
claude
```

### Codex

编辑 `~/.codex/config.toml`，修改 `model` 字段：

```toml
model = "gpt-6.2-sol"
```

### RooCode / Qwen Code

在提供商配置中直接修改 **Model** 字段即可。支持填写上述任何兼容模型的 ID。

## 模型推荐

<Callout type="idea" title="最佳编码能力">
  **claude-opus-5-5** — 综合编码能力最强，适合复杂项目和架构级任务。
</Callout>

<Callout type="idea" title="最佳响应速度">
  **claude-haiku-5-5** — 响应速度最快，适合高频调用和实时补全场景。
</Callout>

<Callout type="idea" title="最佳性价比">
  **claude-fable-5-2** — 在速度和质量之间取得良好平衡，适合大多数日常开发任务。
</Callout>
