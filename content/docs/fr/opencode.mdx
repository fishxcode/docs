## Installer OpenCode

```bash tab="npm"
npm install -g opencode-ai@latest
```

```bash tab="brew"
brew install anomalyco/tap/opencode
```

```bash tab="scoop"
scoop install opencode
```

## Configurer FishXCode

1. Obtenez votre cle API sur [https://fishxcode.com/keys](https://fishxcode.com/keys)
2. Definissez la variable d'environnement :

```bash tab="Linux/macOS"
export FISHXCODE_TOKEN=sk-xxx
```

```powershell tab="Windows PowerShell"
$env:FISHXCODE_TOKEN="sk-xxx"
```

3. Creez `opencode.json` a la racine de votre projet ou dans `~/.config/opencode/` :

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "fishxcode-anthropic": {
      "npm": "@ai-sdk/anthropic",
      "name": "fishxcode-anthropic",
      "options": {
        "baseURL": "https://api.fishxcode.com/v1",
        "apiKey": "{env:FISHXCODE_TOKEN}"
      },
      "models": {
        "claude-sonnet-4-6": {
          "name": "claude-sonnet-4-6"
        }
      }
    },
    "fishxcode-openai": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "fishxcode-openai",
      "options": {
        "baseURL": "https://api.fishxcode.com/v1",
        "apiKey": "{env:FISHXCODE_TOKEN}"
      },
      "models": {
        "gpt-6.2-sol": {
          "name": "gpt-6.2-sol"
        }
      }
    }
  }
}
```

<Callout type="warn" title="Important">
  Remplacez `sk-xxx` par votre token reel obtenu depuis la [console FishXCode](https://fishxcode.com/keys).
</Callout>

## Demarrage

```bash
cd my-project
opencode
```

Une fois lance, selectionnez un modele sous le fournisseur FishXCode pour commencer.
