## Général

### Qu'est-ce que FishXCode ?

FishXCode est une plateforme tout-en-un d'accès aux modèles d'IA et de services de comptes, couvrant Claude, Codex, Kiro, Grok, les modèles nationaux et multimodaux, utilisable dans de nombreux outils et plateformes.

### Quels outils sont pris en charge ?

Les outils suivants sont actuellement pris en charge :

- **Claude Code** — la CLI officielle d'Anthropic
- **OpenAI Codex** — l'assistant de programmation officiel d'OpenAI
- **RooCode** — extension de programmation IA pour VS Code
- **Qwen Code** — outil de programmation d'Alibaba Tongyi Qianwen
- **Droid CLI** — CLI de programmation IA légère
- **OpenCode** — outil terminal de programmation IA open source

### Comment la confidentialité des données est-elle protégée ?

FishXCode agit uniquement comme relais d'API et ne stocke ni votre code ni le contenu des conversations. Toutes les requêtes sont transmises directement au fournisseur du modèle correspondant.

<Callout type="idea" title="Recommandation">
  Pour les projets sensibles, lisez la politique de confidentialité de chaque fournisseur de modèle avant usage.
</Callout>

## Comptes et clés API

### Comment s'inscrire ?

Rendez-vous sur [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW), remplissez le nom d'utilisateur, le mot de passe et l'e-mail, puis saisissez le code de vérification envoyé par e-mail pour terminer l'inscription. Vous pouvez aussi vous connecter directement via l'autorisation GitHub / LinuxDO / Google (la première autorisation crée le compte automatiquement).

<Callout type="idea" title="Domaines e-mail pris en charge">
  L'inscription par e-mail prend actuellement en charge quatre domaines : **qq.com, 126.com, 163.com, gmail.com**.
</Callout>

### Comment obtenir une clé API ?

Après l'inscription, connectez-vous à la console et allez sur la [page Clés API](https://fishxcode.com/keys) pour créer une nouvelle clé API.

### Quels moyens de recharge sont pris en charge ?

Allez dans **Console → Portefeuille** pour recharger. Pris en charge :

- **Alipay** : le moyen courant, sans minimum
- **Waffo Pancake** : recharge minimale de $100
- **Code d'échange** : saisissez-le dans la zone d'échange de la page Portefeuille

Les gros utilisateurs de Codex peuvent aussi acheter directement un forfait mensuel du pool de comptes (onglet Forfaits d'abonnement) — voir [Forfaits d'abonnement](/fr/subscription-plans).

### Combien de temps une clé API reste-t-elle valide ?

Une clé API reste valide jusqu'à sa suppression ou sa régénération manuelle. Renouvelez-la régulièrement pour la sécurité.

### Quel est mon quota d'utilisation ?

FishXCode attribue à chaque utilisateur un quota d'utilisation, ajusté dynamiquement selon les ressources de la plateforme. Surveillez les informations d'utilisation dans la console.

<Callout type="warn" title="Attention">
  Les requêtes sont refusées une fois le quota épuisé — planifiez votre usage en conséquence.
</Callout>

## Configuration des outils

### Les variables d'environnement ne prennent pas effet

Vérifiez ces causes fréquentes :

1. **Terminal non redémarré** — après modification de `.bashrc` / `.zshrc`, exécutez `source ~/.bashrc` ou ouvrez un nouveau terminal
2. **Nom de variable mal orthographié** — la casse compte ; `ANTHROPIC_BASE_URL` ne peut pas s'écrire `Anthropic_Base_Url`
3. **Guillemets ou espaces superflus** — dans `export KEY="value"`, ne laissez pas d'espaces superflus autour de la valeur

<Accordions type="single">
  <Accordion title="Commandes de vérification rapide">
    ```bash
    # Vérifier si les variables sont définies
    echo $ANTHROPIC_BASE_URL
    echo $ANTHROPIC_AUTH_TOKEN

    # Une sortie vide signifie que les variables ne sont pas en vigueur
    ```
  </Accordion>
</Accordions>

### Où se trouvent les fichiers de configuration ?

| Outil | Chemin du fichier de configuration |
| - | - |
| Claude Code | Configuration par variables d'environnement |
| Codex | `~/.codex/config.toml` et `~/.codex/auth.json` |
| RooCode | JSON des paramètres de VS Code |
| Qwen Code | Configuration par variables d'environnement |

### Impossible de me connecter à FishXCode ?

1. Confirmez que `BASE_URL` vaut `https://api.fishxcode.com/` ou `https://fishxcode.com/` (les deux fonctionnent, comportement identique)
2. Vérifiez que votre réseau atteint `fishxcode.com`
3. Sur un réseau d'entreprise, vérifiez que le paramétrage du proxy est correct

## Choix du modèle

### Comment choisir le bon modèle ?

Choisissez selon le cas d'usage :

| Cas d'usage | Modèle recommandé | Pourquoi |
| - | - | - |
| Programmation quotidienne | `claude-fable-5-2` | Équilibre entre capacité et vitesse |
| Complétion rapide | `claude-haiku-5-5` | Réponse rapide |
| Architecture complexe | `claude-fable-5-2` | Solide capacité de raisonnement |

### Quelles différences entre les modèles ?

- **Série Sonnet** : capacités complètes, adaptée à la plupart des tâches de programmation
- **Série Haiku** : légère et rapide, adaptée aux complétions simples et au formatage
- Pour les différences de capacité détaillées, reportez-vous à la documentation officielle de chaque fournisseur

### Comment changer de modèle ?

Spécifiez-le via la variable d'environnement `ANTHROPIC_MODEL` :

```bash
export ANTHROPIC_MODEL=claude-fable-5-2
```

## Dépannage

### Échec d'authentification (Auth Error)

<Callout type="warn" title="Causes fréquentes">
  - La clé a été mal saisie (espaces superflus ou incomplète)
  - La clé a été supprimée ou régénérée
  - `API_KEY` et `AUTH_TOKEN` ne sont pas définies toutes les deux
</Callout>

Solution : allez sur la [page Clés API](https://fishxcode.com/keys) pour vérifier l'état de la clé, puis copiez-la et collez-la à nouveau.

### Comment consulter et comprendre les journaux d'erreurs ?

Allez sur [Console → Journaux d'utilisation](https://fishxcode.com/usage-logs/common) et basculez le type de journal sur **Journaux d'erreurs**. Vous pouvez filtrer par heure, modèle, clé, groupe, ID de requête, message d'erreur et code de statut.

<Callout type="idea" title="Conseils de diagnostic">
  - Copiez d'abord le `request_id` de la réponse de l'API ou du journal et recherchez-le précisément dans les Journaux d'utilisation pour retrouver la même requête
  - Recherchez des mots-clés de `content` via « Message d'erreur », par exemple `Invalid token`, `Upstream request failed`
  - Agrégez rapidement les types de problème par « Code de statut », par exemple `400`, `401`, `403`, `413`, `429`, `500`, `502`, `503`, `504`
  - Si la même erreur se concentre sur un groupe, partez du groupe pour déterminer s'il s'agit d'un problème de configuration, d'usage ou de disponibilité de l'amont
</Callout>

Pour la description complète des champs, la classification des codes de statut et le tableau des erreurs courantes, voir [Guide des journaux d'erreurs](/fr/error-logs).

### Comment lire l'état de santé des groupes ?

L'état de santé des groupes sert à déterminer si un problème est une anomalie isolée de requête ou un incident concentré sur un forfait, un modèle ou un groupe d'amont. Regardez d'abord `success_rate`, `error_count` et `error_reasons`, puis utilisez le `request_id` des journaux individuels pour localiser les requêtes précises.

Pour la page d'état complète, la description des champs et le processus de diagnostic, voir [État de santé des groupes](/fr/group-health).

### Délai d'attente dépassé (Timeout)

Causes possibles :

1. Latence réseau élevée
2. Contexte de la requête très long, le modèle met plus de temps à le traiter
3. Charge du service élevée à ce moment

Suggestions : réduisez le contexte d'entrée, ou réessayez plus tard.

### Limite de fréquence ou de quota atteinte (Rate Limit)

Un code de statut `429` indique généralement des requêtes trop fréquentes. Il peut aussi signifier que le quota quotidien d'un compte d'amont est épuisé, ou que l'identifiant du modèle actuel est en période de refroidissement.

<Callout type="idea" title="Comment réagir">
  - Réduisez la fréquence des requêtes et réessayez après quelques secondes
  - Évitez d'appeler l'API en boucles sans intervalle dans vos scripts
  - Vérifiez qu'un autre processus n'utilise pas la même clé en même temps
  - Si le journal contient `Max 10/min` ou `Max 5/min`, ramenez la concurrence et les requêtes par minute sous le seuil indiqué
  - Si le journal contient `daily limit exceeded`, attendez la réinitialisation du quota quotidien, ou basculez vers un autre modèle/groupe disponible
  - Si le journal contient `cooling down`, ne réessayez pas immédiatement en rafale ; attendez la fin du refroidissement ou changez de modèle temporairement
</Callout>

### Modèle non disponible (Model Not Available)

Vérifiez que le nom du modèle est correct — voir la liste des modèles recommandés dans [Démarrage rapide](/fr/start). Certains modèles peuvent ne pas encore être disponibles sur FishXCode.
