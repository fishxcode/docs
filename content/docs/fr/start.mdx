## 1. Préparer l'environnement

### Installer Node.js

Claude Code s'installe via npm : vérifiez d'abord que Node.js est prêt.

```bash tab="macOS - Vérifier"
node -v
npm -v
```

```bash tab="macOS - Installer avec Homebrew"
brew install node
```

```bash tab="Windows - Vérifier (CMD/PowerShell)"
node -v
npm -v
```

S'il n'est pas installé, téléchargez l'installateur de votre plateforme sur [nodejs.org/zh-cn/download](https://nodejs.cn/download/current/). Après l'installation, **sous Windows, un redémarrage est nécessaire**.

### Supplément Windows : installer Git Bash

Claude Code dépend d'un environnement bash ; les utilisateurs Windows doivent installer Git Bash :

1. Téléchargement : [git-scm.com/install/windows](https://git-scm.com/install), installez la version correspondante.
2. Vérification : clic droit sur le bureau — si l'option **Open Git Bash here** apparaît, l'installation a réussi.

## 3. Configurer FishXCode

1. Tapez `npx zcf` dans le terminal et appuyez sur Entrée.
   Lorsque `Ok to proceed? (y)` apparaît, tapez `y` et appuyez sur Entrée.

2. Sélectionnez la langue d'affichage de ZCF :
   Choisissez **Simplified Chinese**.

3. Une fois l'installation terminée, sélectionnez :
   `1. Full Init - Install Claude Code + Import Workflows + Configure API or CCR Proxy + Configure MCP Services`

4. Modifier la configuration de langue des modèles ?
   Sélectionnez `No`

5. Langue de sortie de l'IA :
   Sélectionnez `Simplified Chinese`

6. Installer Claude ?
   Sélectionnez `Yes`

7. Mode de configuration de l'API :
   Sélectionnez `Custom API Configuration`

8. Fournisseur d'API :
   Sélectionnez `Custom Configuration`

9. Nom de la configuration :
   Saisissez un nom personnalisé en anglais

10. Type d'authentification :
    Sélectionnez `API Key`

11. URL de base de l'API :
    ```
    https://api.fishxcode.com
    ```
    <Callout type="idea" title="Adresses d'accès">
      `https://api.fishxcode.com` comme `https://fishxcode.com` peuvent servir d'adresses d'accès. Elles se comportent à l'identique — choisissez l'une ou l'autre.
    </Callout>

12. Clé API :
    Saisissez la clé API créée dans la console FishXCode (Console → Clés API)

13. Configuration liée aux modèles :
    Appuyez sur Entrée pour passer avec les valeurs par défaut

14. Type de workflow :
    Sélectionnez `General Tools`

15. Style de sortie :
    Choisissez selon vos préférences personnelles

16. Configurer MCP ?
    Sélectionnez `Yes`

17. Services MCP :
    Sélectionnez les services souhaités avec la barre d'espace, puis appuyez sur Entrée

18. Configurer CCometixLine :
    Appuyez directement sur Entrée

19. De retour au menu principal, tapez :
    ```
    q
    ```

20. Dans le terminal, tapez :
    ```
    claude
    ```
    - Sélectionnez `Yes, I trust this folder`
    - Pour le choix de l'API, sélectionnez impérativement **YES (la première option)**

## 5. Changer de modèle

Tapez `/model` dans l'interface de conversation de Claude Code pour changer de modèle :

| Option | Modèle réel | Description |
| - | - | - |
| **Default** | `claude-fable-5-2` + `claude-haiku-5-5` | Choisit automatiquement selon la tâche ; recommandé pour l'usage quotidien |
| **Opus** | `claude-opus-5-5` | Raisonnement le plus puissant, consommation plus élevée |
| **Haiku** | `claude-haiku-5-5` | Léger et rapide |

Vous pouvez aussi fixer le modèle via une variable d'environnement :

```bash tab="macOS/Linux"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL="claude-fable-5-2"
claude
```

<Callout type="idea" title="Mettre à niveau Claude Code">
  Si la version du modèle n'est pas la plus récente, exécutez la commande de mise à niveau puis redémarrez les outils concernés :

  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
</Callout>

## 6. Intégration IDE

### IntelliJ IDEA

Chemin : File → Settings → Plugins → Marketplace → recherchez `claude code`, trouvez **Claude Code Terminal** et installez-le :

![Installer Claude Code Terminal](/img/start/idea-01-install.png)

Après l'installation, redémarrez IDEA et vérifiez que l'extension est chargée :

![Vérifier que l'extension est chargée](/img/start/idea-02-verify.png)

<Callout type="info">
  Si vous ne la trouvez pas sur le marketplace d'extensions, votre version d'IDEA est trop ancienne — mettez à niveau vers la dernière version.
</Callout>

### VSCode

Appuyez sur `Ctrl + Shift + X` pour ouvrir le panneau des extensions, recherchez `claude code` et installez **Claude Code for VSCode**.

![Rechercher et installer l'extension Claude Code](/img/start/vscode-01-install.png)

Une fois installée, l'extension propose trois modes de connexion :

![Modes de connexion de l'extension Claude Code](/img/start/vscode-02-login.png)

Nous recommandons de connecter FishXCode via `settings.json`. Cliquez sur l'**icône d'engrenage** en bas à droite de l'extension → **Edit in settings.json** :

![Ouvrir settings.json pour modification](/img/start/vscode-03-settings.png)

Ajoutez ceci au `settings.json` de VSCode :

```json
{
  "claudeCode.preferredLocation": "panel",
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "remplacez par votre clé API" },
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.fishxcode.com/" }
  ]
}
```

<Callout type="idea" title="Adresses d'accès">
  `ANTHROPIC_BASE_URL` peut aussi valoir `https://fishxcode.com/` ; les deux adresses se comportent à l'identique, choisissez l'une ou l'autre.
</Callout>

![Exemple de configuration dans settings.json](/img/start/vscode-04-config.png)

Après enregistrement, **quittez puis rouvrez VSCode** ; l'extension pourra alors se connecter normalement à FishXCode.

![Utiliser Claude Code dans VSCode](/img/start/vscode-05-demo.gif)

## 7. Questions fréquentes

### Erreur 403

Le solde est insuffisant — rechargez dans la console puis réessayez.

### Problèmes de connexion ou erreurs 400/401 sous Windows

Réexécutez les commandes `setx` dans PowerShell pour écrire les variables système, puis rouvrez le terminal :

```powershell
setx ANTHROPIC_AUTH_TOKEN "sk-xxx"
setx ANTHROPIC_BASE_URL "https://api.fishxcode.com/"
```

### Message « Unable to connect to Anthropic services »

L'erreur complète est la suivante :

```
Unable to connect to Anthropic services
Failed to connect to api.anthropic.com: ERR_BAD_REQUEST
Please check your internet connection and network settings.
```

Cela arrive parce que Claude Code n'a pas terminé l'onboarding et tente encore de joindre le `api.anthropic.com` officiel. **Pas besoin de VPN** : ajoutez `"hasCompletedOnboarding": true` à la fin de `~/.claude.json` (attention : il s'agit du `.claude.json` du répertoire home, pas de `.claude/settings.json`) pour l'ignorer :

```json
{
  "installMethod": "unknown",
  "autoUpdates": true,
  "projects": { ... },
  "hasCompletedOnboarding": true
}
```

<Callout type="idea">
  Avant d'ajouter la ligne, ajoutez une virgule à la fin du champ précédent (exigé par la syntaxe JSON). Après la modification, relancez `claude` et la connexion fonctionne normalement.
</Callout>
