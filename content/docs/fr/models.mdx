FishXCode prend en charge une variete de modeles d'IA de plusieurs fournisseurs, couvrant differents cas d'utilisation et chaines d'outils. Vous pouvez librement choisir et changer de modele selon vos besoins.

<ModelCatalog />

## Changer de modele

### Claude Code

Definissez le modele principal via les variables d'environnement :

```bash tab="Linux/macOS"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL = "claude-fable-5-2"
claude
```

### Codex

Modifiez le fichier `~/.codex/config.toml` et changez le champ `model` :

```toml
model = "gpt-6.2-sol"
```

### RooCode / Qwen Code

Modifiez le champ **Model** directement dans la configuration du fournisseur. Tout identifiant de modele compatible liste ci-dessus peut etre utilise.

## Recommandations

<Callout type="idea" title="Meilleur pour le codage">
  **claude-opus-5-5** — Capacite de codage globale la plus forte, ideal pour les projets complexes et les taches d'architecture.
</Callout>

<Callout type="idea" title="Meilleur pour la vitesse">
  **claude-haiku-5-5** — Temps de reponse le plus rapide, ideal pour les appels frequents et les completions en temps reel.
</Callout>

<Callout type="idea" title="Meilleur equilibre">
  **claude-fable-5-2** — Excellent equilibre entre vitesse et qualite, adapte a la plupart des taches de developpement quotidiennes.
</Callout>
