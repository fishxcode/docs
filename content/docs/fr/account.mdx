## 1. Inscription et connexion

### 1. Créer un compte

Rendez-vous sur [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW) pour ouvrir la page d'inscription :

![Page d'inscription FishXCode](/img/start/api-v2-01-home.png)

Remplissez le formulaire d'inscription : définissez un nom d'utilisateur et un mot de passe (8 à 128 caractères ; lettres majuscules et minuscules, chiffres et symboles recommandés), et saisissez l'adresse e-mail qui recevra le code de vérification :

![Remplir les informations d'inscription](/img/start/api-v2-03-register-form.png)

<Callout type="idea" title="Domaines e-mail pris en charge">
  L'inscription par e-mail prend actuellement en charge quatre domaines : **qq.com, 126.com, 163.com, gmail.com**. Les autres domaines risquent de ne pas recevoir le code de vérification.
</Callout>

Cliquez sur **Envoyer le code de vérification**. Après avoir validé la vérification anti-robot Cloudflare, le code est envoyé à votre adresse e-mail. Retrouvez le code (une combinaison alphanumérique de 6 caractères) dans votre boîte de réception et saisissez-le dans le formulaire :

![Saisir le code de vérification e-mail](/img/start/api-v2-02-register-verify.png)

Cliquez sur **Créer un compte** pour terminer l'inscription. La page redirige vers la connexion avec le message « Compte créé ! Veuillez vous connecter ».

<Callout type="warn" title="Vous ne recevez pas le code de vérification ?">
  1. Vérifiez que le domaine de l'e-mail figure dans la liste prise en charge (qq.com / 126.com / 163.com / gmail.com)
  2. Consultez le dossier des indésirables
  3. Attendez 1 à 2 minutes puis réessayez ; évitez les demandes trop fréquentes
  4. S'il n'arrive toujours pas, passez à la connexion autorisée par un tiers
</Callout>

### 2. Se connecter

Après l'inscription, connectez-vous avec votre nom d'utilisateur et votre mot de passe, ou utilisez la connexion autorisée par un tiers en un clic :

![Page de connexion](/img/start/api-v2-04-login.png)

| Méthode de connexion | Description |
| - | - |
| Compte créé par e-mail | Connexion avec nom d'utilisateur/e-mail + mot de passe |
| GitHub | Connexion autorisée ; recommandée pour les développeurs |
| LinuxDO | Connexion autorisée pour les utilisateurs de la communauté |
| Google | Connexion autorisée avec un compte Google |

<Callout type="info" title="La connexion via un tiers crée le compte automatiquement">
  À la première connexion via GitHub / LinuxDO / Google, un compte est créé automatiquement — aucune inscription distincte n'est nécessaire.
</Callout>

Après la connexion, vous arrivez sur la console (page d'aperçu) :

![Aperçu de la console](/img/start/api-v2-05-console.png)

## 2. Obtenir une clé API

### 1. Créer une clé API

Allez dans **Console → Clés API** et cliquez sur **Créer une clé API** en haut à droite :

![Fenêtre de création de clé API](/img/start/api-v2-06-token-create.png)

Champs du formulaire :

| Champ | Description |
| - | - |
| Nom | Nom personnalisé de la clé pour identifier son usage |
| Groupe | Détermine les modèles disponibles et le multiplicateur de facturation ; voir ci-dessous |
| Expiration | Jamais / 1 mois / 1 jour / 1 heure |
| Quantité | Créez plusieurs clés d'un coup (un suffixe aléatoire est ajouté à chaque nom) |
| Quota illimité | Activé par défaut ; désactivez-le pour plafonner la consommation maximale de cette clé |
| Paramètres avancés | Liste blanche d'IP (CIDR pris en charge), autoriser la consultation du quota utilisateur |

- Pour le **groupe**, nous recommandons <LiveRatio name="claude" /> : il s'agit du pool de comptes officiel au prix plein Claude Max 20, avec des performances complètes. Tous les groupes et multiplicateurs sont détaillés dans [Règles de facturation et groupes](/fr/billing-groups).
- La **liste blanche d'IP** convient aux serveurs avec IP de sortie fixe ; méfiez-vous en développement local, car un changement d'IP bloquera vos appels.

Cliquez sur **Enregistrer les modifications** pour terminer. Dans la liste des clés, cliquez sur **Copier** pour récupérer la clé API (format `sk-xxx`) :

![Copier la clé API](/img/start/api-v2-07-token-copy.png)

<Callout type="idea" title="Adresse API">
  Cliquez sur **Adresse API** en haut à droite de la page pour voir les adresses d'accès. La console affiche `https://fishxcode.com` par défaut ; `https://api.fishxcode.com` fonctionne également. Les deux se comportent à l'identique — choisissez l'une ou l'autre.
</Callout>

### 2. Recharger

Allez dans **Console → Portefeuille** et restez sur l'onglet **Recharge de solde** :

![Recharge de solde du portefeuille](/img/start/api-v2-08-wallet.png)

**Recharge de solde** : choisissez un montant prédéfini ($1 / $5 / $10 / $100 / $500 / $1,000 ; les gros montants bénéficient de 1 % à 3 % de remise) ou saisissez un montant personnalisé, puis choisissez un moyen de paiement :

![Moyens de paiement et codes d'échange](/img/start/api-09-payment.png)

| Moyen | Description |
| - | - |
| Alipay | Moyen de recharge courant, sans minimum |
| Waffo Pancake | Recharge minimale de $100 |
| Code d'échange | Saisissez-le dans la zone « Vous avez un code d'échange ? » puis cliquez sur **Échanger contre du crédit** |

<Callout type="idea" title="Avantage nouveaux utilisateurs">
  Les comptes nouvellement inscrits reçoivent automatiquement un solde d'essai de **$0.2**, utilisable directement pour tester les appels API.
</Callout>

<Callout type="idea" title="Comprendre les multiplicateurs">
  Le multiplicateur figurant dans le nom du groupe est le facteur de facturation : plus la valeur est petite, moins la même requête coûte. Par exemple, consommer 1 unité sur un groupe `0.5x` correspond au volume de tokens qui coûterait 2 unités au prix officiel. Détails dans [Règles de facturation et groupes](/fr/billing-groups).
</Callout>

## 3. Sécurité du compte

Allez dans **Console → Sécurité et accès** pour gérer les paramètres de sécurité de votre compte :

![Page Sécurité et accès](/img/start/api-12-security.png)

| Fonctionnalité | Description |
| - | - |
| Changer le mot de passe | Renouvelez-le régulièrement : 8 caractères minimum, avec majuscules, minuscules et chiffres |
| Liaison de comptes | Après liaison de GitHub / LinuxDO / Google, connectez-vous en un clic via autorisation |
| Sessions de connexion | Consultez les appareils connectés et déconnectez à distance les autres sessions |
| Clé d'accès | Utilisée pour appeler l'API du tableau de bord ; créez-la en cochant les permissions voulues |
| Connexion Passkey | Connexion sans mot de passe grâce à une clé d'accès |
| Validation en deux étapes | Ajoute une couche de sécurité supplémentaire à votre compte |

### Conseils de sécurité pour les clés

- **Renouvelez régulièrement** : remplacez les clés tous les 30 à 90 jours pour réduire le risque de fuite
- **Ne stockez jamais les clés en clair** : évitez d'écrire la clé API directement dans le code ou de la pousser dans Git ; utilisez des variables d'environnement
- **Principe de moindre privilège** : créez des clés distinctes par projet pour faciliter la gestion et le suivi
- **En cas de fuite** : si vous suspectez une fuite, supprimez immédiatement la clé sur la page **Clés API** et créez-en une nouvelle

<Callout type="warn" title="Attention">
  La suppression d'une clé est irréversible. Une fois supprimée, la clé cesse de fonctionner immédiatement et les outils qui l'utilisent ne peuvent plus appeler.
</Callout>

## 4. Questions fréquentes

### Vous ne recevez pas le code de vérification à l'inscription ?

1. Vérifiez que le domaine de l'e-mail figure dans la liste prise en charge (qq.com / 126.com / 163.com / gmail.com)
2. Consultez le dossier des indésirables / spams
3. Attendez 1 à 2 minutes puis réessayez ; évitez les demandes trop fréquentes
4. S'il n'arrive toujours pas, utilisez la connexion autorisée par GitHub / LinuxDO / Google

### Où retrouver ma clé API après sa création ?

Allez dans **Console → Clés API** ; les clés créées apparaissent dans la liste. Cliquez sur le bouton de copie pour récupérer la clé API au format `sk-xxx`.

### Que faire si la recharge n'arrive pas ?

1. Vérifiez que le paiement a abouti (consultez l'historique des transactions d'Alipay ou de votre canal de paiement)
2. Attendez 1 à 5 minutes ; le système peut avoir un léger délai
3. Actualisez la page Portefeuille de la console
4. Si rien n'est arrivé après 10 minutes, contactez-nous via [Contact](https://fishxcode.com/contact) en fournissant le justificatif de paiement

### Comment consulter le détail de la consommation ?

Allez dans **Console → Journaux d'utilisation** et retrouvez, pour chaque appel API :

- L'heure de l'appel et le nom du modèle
- La consommation de tokens et le coût
- L'IP de la requête et les enregistrements détaillés

D'autres types de journaux (audit, tâches) sont accessibles via la barre latérale.
