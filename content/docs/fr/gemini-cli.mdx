## Notes sur la plateforme

Gemini CLI se connecte via le protocole compatible OpenAI. Si le client propose des champs personnalisés Base URL / API Key, renseignez-les avec les informations ci-dessus ; s'il ne prend en charge que les points de terminaison compatibles OpenAI, vérifiez que l'URL contient `/v1`.

## Facultatif : Importation en un clic avec CC Switch

Si vous gérez plusieurs canaux Gemini, vous pouvez utiliser [CC Switch](https://github.com/farion1231/cc-switch) pour basculer rapidement ; si FishXCode est votre seul canal, la configuration par variables d'environnement ci-dessus suffit généralement.

Dans la page **Clés API** de la console FishXCode, trouvez la ligne de la clé visée et cliquez sur **Ouvrir le menu → CC Switch** :

![Choisir Remplir dans CC Switch dans la console FishXCode](/img/start/gemini-cli/cc-switch-import-channel.png)

La console affiche le formulaire « Remplir dans CC Switch ». Choisissez `Gemini` pour **Application**, gardez **Nom** à `FishXCode` (facile à reconnaître dans la liste des canaux), choisissez `gemini-3.6-flash` comme **Modèle principal**, puis cliquez sur **Ouvrir CC Switch** :

| Champ | Valeur recommandée FishXCode |
| - | - |
| Application | `Gemini` |
| Nom | `FishXCode` |
| Modèle principal | `gemini-3.6-flash` |

CC Switch affiche le dialogue « Confirmer l'importation du fournisseur ». Vérifiez que le point d'accès API est `https://fishxcode.com` et le modèle `gemini-3.6-flash`, puis cliquez sur **Importer** :

![Confirmer l'importation de FishXCode dans CC Switch](/img/start/gemini-cli/cc-switch-select-model.png)

Après l'importation, FishXCode apparaît dans la liste des fournisseurs :

![FishXCode importé et visible dans la liste des fournisseurs](/img/start/gemini-cli/cc-switch-import-success.png)

<Callout type="warn" title="Remarque">
  Lorsque « Basculer vers ce fournisseur juste après l'importation » est activé, CC Switch réécrit la configuration locale de Gemini CLI (`~/.gemini/.env`). Pour revenir au canal officiel, resélectionnez-le dans CC Switch afin de ne pas envoyer de requêtes vers une adresse inattendue.
</Callout>
