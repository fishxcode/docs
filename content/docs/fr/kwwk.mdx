## Notes sur la plateforme

kwwk se connecte via le protocole compatible OpenAI. Si le client propose des champs personnalisés Base URL / API Key, renseignez-les avec les informations ci-dessus ; s'il ne prend en charge que les points de terminaison compatibles OpenAI, vérifiez que l'URL contient `/v1`.
