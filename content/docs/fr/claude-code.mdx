## Notes sur la plateforme

Claude Code se connecte via le protocole compatible Anthropic. Si le client propose des champs personnalisés Base URL / API Key, renseignez-les avec les informations ci-dessus ; l'URL de base est `https://api.fishxcode.com`. Si le client exige une adresse complète, ajoutez des chemins comme `/v1/messages`.
