Le forfait mensuel du pool Codex Pro s'appuie sur le pool de comptes Codex Pro officiel. Il s'achète au mois avec un crédit fixe et convient à la programmation Codex intensive et au développement d'agents. C'est actuellement la seule série de forfaits en vente, déclinée en trois paliers :

| Forfait | Prix | Crédit du forfait | Multiplicateur de coût réel | Validité | Réinitialisation du crédit | Usage conseillé |
| - | - | - | - | - | - | - |
| Forfait mensuel de $2,000 de crédit | $260 | $2,000 | 0.13x | 1 mois civil | Aucune | Développement intensif et équipes d'entreprise |
| Forfait mensuel de $200 de crédit | $30 | $200 | 0.15x | 1 mois civil | Aucune | Crédit intermédiaire, le meilleur choix pour le développement quotidien |
| Forfait mensuel de $20 de crédit | $3.60 | $20 | 0.18x | 1 mois civil | Aucune | Découverte du service, usage flexible |

Les prix et la disponibilité indiqués sur la [page Tarifs](https://fishxcode.com/pricing) font foi.

## Utilisation après achat

1. Achetez le forfait mensuel Codex correspondant au crédit souhaité.
2. Dans la console, sélectionnez le groupe `codex-sub-june`.
3. Créez un nouveau token API dans ce groupe.
4. Configurez le token dans un client compatible, par exemple [Codex](/fr/codex) ou [Codex Desktop](/fr/codex-desktop), et le tour est joué.

## Règles de facturation

- Le groupe `codex-sub-june` a un **multiplicateur fixe de 1x**.
- Multiplicateur de coût réel = prix du forfait ÷ crédit du forfait.
- Les requêtes sont déduites du crédit du forfait selon la consommation réelle de tokens.
- Le forfait est valable 1 mois civil.
- Le crédit du forfait n'est pas réinitialisé, et le crédit non utilisé n'est pas reporté automatiquement.

<Callout type="idea" title="Exemple">
  Pour $260, vous obtenez $2,000 de crédit, soit un multiplicateur de coût réel de **0.13x** ; le groupe affiche pourtant toujours un multiplicateur de 1x.
</Callout>

## Points d'attention

<Callout type="warn" title="Seul le groupe codex-sub-june peut utiliser le crédit du forfait mensuel">
  Pour le forfait mensuel Codex, vous devez créer les tokens dans le groupe `codex-sub-june` ; les autres groupes ne peuvent pas utiliser le crédit du forfait.
</Callout>

- Le forfait mensuel n'est pas illimité : une fois le crédit épuisé ou le forfait expiré, vous ne pouvez plus l'utiliser.
- Si vous ne souhaitez pas acheter de forfait mensuel, vous pouvez aussi appeler les groupes de la série Codex à l'usage, sur votre solde. Voir [Règles de facturation et groupes](/fr/billing-groups).
