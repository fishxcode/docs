Codex Pro 号池月包基于 Codex Pro 官方号池，按固定额度按月购买，适合高频 Codex 编程与 Agent 开发。目前在售的套餐只有这一个系列，提供三档：

| 套餐 | 售价 | 套餐额度 | 实际成本倍率 | 有效期 | 额度重置 | 适合 |
| - | - | - | - | - | - | - |
| 2000 美元额度月包 | $260 | $2,000 | 0.13x | 1 个自然月 | 不重置 | 高频开发与企业团队 |
| 200 美元额度月包 | $30 | $200 | 0.15x | 1 个自然月 | 不重置 | 中等额度，日常开发优选 |
| 20 美元额度月包 | $3.60 | $20 | 0.18x | 1 个自然月 | 不重置 | 入门体验，灵活使用 |

价格与可售状态以 [定价页](https://fishxcode.com/pricing) 为准。

## 购买后如何使用

1. 购买对应额度的 Codex 月包套餐。
2. 在控制台选择 `codex-sub-june` 分组。
3. 使用该分组新建 API 令牌。
4. 将令牌配置到支持的客户端即可使用，例如 [Codex](/codex)、[Codex Desktop](/codex-desktop)。

## 计费规则

- `codex-sub-june` 分组固定为 **1x 倍率**。
- 实际成本倍率 = 套餐售价 ÷ 套餐额度。
- 请求按实际 Token 消耗扣减套餐额度。
- 套餐有效期为 1 个自然月。
- 套餐额度不重置，未使用额度不会自动续期。

<Callout type="idea" title="例子">
  $260 购买 $2,000 额度，实际成本倍率为 **0.13x**，但分组显示的倍率仍然是 1x。
</Callout>

## 注意事项

<Callout type="warn" title="只有 codex-sub-june 分组能用月包额度">
  Codex 月包必须使用 `codex-sub-june` 分组创建令牌，其他分组不适用该套餐额度。
</Callout>

- 月包不是无限额度，额度耗尽或套餐到期后将无法继续使用。
- 不想买月包时，也可以用余额按量调用 Codex 系列分组，见 [计费规则与分组](/billing-groups)。
