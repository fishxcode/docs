  Hermes Agent 是 Nous Research 推出的通用 AI Agent，支援 CLI 對話、工具呼叫、記憶、技能、閘道器和定時任務。它既可以連線官方支援的雲服務，也可以接入任意 OpenAI 相容端點。

  - 官方網站：[https://hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com)
  - 文件：[https://hermes-agent.nousresearch.com/docs](https://hermes-agent.nousresearch.com/docs)
  - GitHub：[https://github.com/NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)
  - Web3Hermes：[https://web3hermes.com](https://web3hermes.com)
</Callout>

## 前提條件

- 已獲取 FishXCode API Key（[控制台獲取](https://fishxcode.com/console/token)）
- 本機可用 `git`
- 本機可用 `python3`

## 安裝 Hermes

<Callout type="info" title="環境要求">
  - macOS / Linux / WSL2
  - Windows 可通過 PowerShell 直接安裝，但仍推薦優先使用 WSL2
  - 安裝器會自動處理 Python、Node.js、ripgrep、ffmpeg 等依賴，無需手動預裝
</Callout>

### 推薦：安裝 Web3Hermes

如果你希望使用更適合中國大陸使用者的桌面瀏覽器介面，推薦優先安裝 [Web3Hermes](https://web3hermes.com)。它是基於 Hermes Agent 的輕量級 Web 介面，官方 README 見：[Web3CZ/Web3Hermes](https://raw.githubusercontent.com/Web3CZ/Web3Hermes/refs/heads/main/README.md)。

```bash
git clone https://github.com/Web3CZ/Web3Hermes.git
cd Web3Hermes
python3 bootstrap.py
```

也可以在專案目錄內使用啟動指令碼：

```bash
./start.sh
```

服務預設會在 `http://127.0.0.1:8787` 啟動。

### 安裝 Hermes Agent CLI

```bash tab="中國大陸映象（推薦）"
curl -fsSL https://res1.hermesagent.org.cn/install.sh | bash
```

```bash tab="官方安裝器"
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

```powershell tab="Windows PowerShell"
irm https://res1.hermesagent.org.cn/install.ps1 | iex
```

安裝完成後重新載入終端配置：

```bash
source ~/.zshrc
```

如果你使用的是 `bash`，請改為：

```bash
source ~/.bashrc
```

如果你使用 Windows PowerShell，關閉並重新開啟終端即可。

<Callout type="idea" title="提示">
  如果你在中國大陸網路環境下安裝，優先使用 `https://hermesagent.org.cn` 提供的映象入口，成功率通常更高。
</Callout>

## 配置 FishXCode

Hermes 官方推薦優先使用 `hermes model` 進行互動式配置。對於 FishXCode，這裡選擇 **Custom endpoint** 即可，因為 FishXCode 提供 OpenAI 相容介面。

如果你想在安裝後一次性完成初始化，也可以執行：

```bash
hermes setup
```

如果只想補配工具許可權，可以執行：

```bash
hermes tools
```

### 方式一：使用 `hermes model` 互動式配置（推薦）

執行：

```bash
hermes model
```

按提示填寫以下內容：

- Provider：`Custom endpoint (self-hosted / VLLM / etc.)`
- API base URL：`https://api.fishxcode.com/v1`
- API key：你的 FishXCode Token
- Model name：`gpt-6.2-sol`
- Context length：建議至少填寫 `65536`

配置完成後，Hermes 會把模型、提供商和地址寫入 `~/.hermes/config.yaml`。

<Callout type="warn" title="重要">
  Hermes 對可工作的模型上下文有最低要求。自定義端點下請優先選擇上下文視窗不低於 `64K` 的模型，否則多步工具呼叫和長上下文任務可能直接被拒絕或表現異常。
</Callout>

### 方式二：手動編輯配置檔案

Hermes 的主配置檔案位於 `~/.hermes/config.yaml`。如果目錄不存在，可以先建立：

```bash
mkdir -p ~/.hermes
touch ~/.hermes/config.yaml
touch ~/.hermes/.env
```

然後在 `~/.hermes/.env` 中寫入你的 Token：

```bash
OPENAI_API_KEY=sk-你的FishXCode-Token
```

再把以下內容寫入 `~/.hermes/config.yaml`：

```yaml
model:
  default: gpt-6.2-sol
  provider: custom
  base_url: https://api.fishxcode.com/v1
```

<Callout type="idea" title="提示">
  Hermes 對自定義端點會優先讀取 `config.yaml` 中的 `provider`、`default`、`base_url`，API Key 則可以直接寫在 `config.yaml`，也可以像上面這樣放到 `~/.hermes/.env` 的 `OPENAI_API_KEY` 中。為了避免明文寫金鑰，推薦使用 `.env`。
</Callout>

## 切換模型

如果你想使用其他 FishXCode 支援的模型，只需要修改 `model.default`，或者重新執行 `hermes model`。

例如：

```yaml
model:
  default: claude-fable-5-2
  provider: custom
  base_url: https://api.fishxcode.com/v1
```

<Callout type="warn" title="注意">
  這裡的前提是該模型可以通過 FishXCode 的 OpenAI 相容入口訪問，並且上下文視窗滿足 Hermes 的最低要求。如果你不確定具體模型 ID，先參考 [支援的模型](/zh-TW/models) 頁面，再填入 `default` 欄位。
</Callout>

## 啟動使用

直接進入對話：

```bash
hermes
```

也可以直接發起一條測試訊息：

```bash
hermes chat -q "用一句話回覆：FishXCode 已連線"
```

如果你已經配置成功，在會話內還可以用 `/model` 切換到已經接入過的模型。

## 驗證配置

優先做這三個檢查：

```bash
hermes doctor
```

```bash
hermes config check
```

```bash
hermes chat -q "請只回復 ok" -Q
```

如果最後一條命令能正常返回內容，說明 FishXCode 接入已經生效。

## 常見問題

### 為什麼要選 `Custom endpoint`？

因為 Hermes 官方把任意 OpenAI 相容介面統一歸類為 `provider: custom`。FishXCode 的接入方式正符合這個模式，所以不需要額外寫 Hermes 專用介面卡。

### `OPENAI_BASE_URL` 或 `LLM_MODEL` 為什麼不生效？

Hermes 官方已經移除了這兩個舊環境變數的讀取邏輯。現在模型、提供商和端點地址以 `~/.hermes/config.yaml` 為準，不應再依賴舊變數。

### 配置了 Key 但還是認證失敗怎麼辦？

按下面順序排查：

1. 確認 `base_url` 寫的是 `https://api.fishxcode.com/v1`
2. 確認 Token 來自 [FishXCode 控制台](https://fishxcode.com/console/token)
3. 確認 `model.default` 填的是有效模型 ID，例如 `gpt-6.2-sol`
4. 確認模型上下文不低於 `65536`
5. 執行 `hermes config check` 與 `hermes doctor` 檢視具體報錯

### Windows 能直接安裝嗎？

可以通過 PowerShell 安裝，但從穩定性和相容性看，仍然推薦優先使用 WSL2。對於瀏覽器自動化、依賴管理和類 Unix 工作流，WSL2 的體驗通常更穩。
