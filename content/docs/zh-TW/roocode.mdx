## 在 VSCode 中安裝 RooCode

1. 在 VSCode 中搜索 [RooCode](https://marketplace.visualstudio.com/items?itemName=RooVeterinaryInc.roo-cline) 並安裝
2. 訪問 [https://fishxcode.com/console/token](https://fishxcode.com/console/token) 獲取你的 API Key

## 新增提供商

完成 RooCode 安裝後，開啟 RooCode，選擇配置提供商，新增一個 OpenAI Compatible 的供應商：

| 配置項 | 值 |
| - | - |
| **OpenAI 基礎 URL** | `https://api.fishxcode.com/v1` |
| **API 金鑰** | 你在 FishXCode 建立的 Key |
| **模型** | `gpt-5` |

<Callout type="idea" title="提示">
  你也可以將模型修改為 `glm-4.5`、`glm-4.6` 或 `deepseek-v3.1` 等其他模型。
</Callout>

配置完成後，儲存即可使用。
