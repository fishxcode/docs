## 一、獲取 API Key

### 1. 註冊帳號

訪問 [fishxcode.com](https://fishxcode.com/register?aff=9CTW)，點選**註冊**：

![FishXCode 首頁](/img/start/api-01-home.png)

選擇註冊方式（GitHub、LinuxDO 或使用者名稱註冊）：

![註冊方式選擇](/img/start/api-02-register.png)

填寫使用者名稱、密碼和確認密碼完成註冊：

![填寫註冊資訊](/img/start/api-03-register-form.png)

### 2. 登入

註冊完成後使用使用者名稱和密碼登入：

![登入頁面](/img/start/api-04-login.png)

登入後進入控制台：

![控制台首頁](/img/start/api-05-console.png)

### 3. 建立令牌

進入**控制台 → 令牌管理 → 新增令牌**，填寫表單：

![新增令牌](/img/start/api-06-token-create.png)

- **令牌分組**建議選擇 **官渠**，該分組包含全系列 Claude 模型，會根據任務複雜度自動選擇，無需手動切換。具體渠道和模型以官網實際為準，請前往 [定價頁](https://fishxcode.com/pricing) 檢視最新資訊。

建立完成後在令牌列表點選**複製**按鈕獲取 API Key（格式為 `sk-xxx`）：

![複製令牌](/img/start/api-07-token-copy.png)

### 4. 充值

進入**控制台 → 錢包管理**，支援支付寶、微信或兌換碼：

![充值頁面](/img/start/api-08-wallet.png)

| 方式 | 操作路徑 |
| - | - |
| 支付寶 | 輸入/選擇金額 → 支付寶 |
| 微信 | 輸入/選擇金額 → 微信 |
| 兌換碼 | 兌換碼區域輸入 → 點選兌換額度 |

<Callout type="idea" title="倍率說明">
  分組名稱中的 `0.5x倍率` 表示消費倍率，數值越小獲得更多 Token，如 `0.5x` 即 1 元可使用官方 1000 萬 Token（官方原價 500 萬）。
</Callout>

## 二、令牌管理

### 令牌分組說明

建立令牌時需要選擇分組，不同分組決定了可用的模型範圍和消費倍率：

| 分組型別 | 說明 | 適用場景 |
| - | - | - |
| **官渠** | 包含全系列 Claude 模型，自動路由 | 推薦大多數使用者使用 |
| **低倍率分組** | 消費倍率更低，價效比更高 | 高頻呼叫、成本敏感場景 |

<Callout type="idea" title="推薦">
  如果你不確定選哪個分組，直接選擇 **官渠** 即可。系統會根據任務複雜度自動選擇最合適的模型。
</Callout>

### 令牌安全建議

- **定期輪換**：建議每 30-90 天更換一次令牌，降低洩露風險
- **不要明文儲存**：避免將 API Key 直接寫入程式碼或提交到 Git 倉庫，推薦使用環境變數
- **許可權最小化**：為不同專案建立獨立的令牌，便於管理和追蹤
- **洩露處理**：如果懷疑令牌洩露，立即在控制台刪除該令牌並建立新的

### 修改與刪除令牌

在**控制台 → 令牌管理**頁面：

- **檢視詳情**：點選令牌名稱檢視分組、模型範圍和建立時間
- **複製令牌**：點選列表中的複製按鈕
- **刪除令牌**：點選刪除按鈕，刪除後該令牌立即失效，使用該令牌的工具將無法繼續呼叫

<Callout type="warn" title="注意">
  刪除操作不可撤銷，請確認不再使用後再刪除。
</Callout>

## 三、帳戶安全

### 密碼與登入安全

- 使用**強密碼**（8 位以上，包含大小寫字母和數字）
- 不要在多個平臺使用相同密碼
- 如忘記密碼，可在登入頁面通過找回密碼流程重置

### 第三方登入繫結

FishXCode 支援以下第三方登入方式：

| 方式 | 說明 |
| - | - |
| **GitHub** | 推薦開發者使用，一鍵授權登入 |
| **LinuxDO** | 社群使用者可直接登入 |

繫結第三方帳號後，可直接使用對應平臺授權登入，無需輸入密碼。

### 異常檢測與處理

如果你發現以下異常情況，建議立即採取措施：

1. **消費異常增加** → 檢查令牌是否洩露，必要時刪除所有令牌並重新建立
2. **無法登入** → 嘗試找回密碼；如仍無法解決，聯絡官方支援
3. **餘額異常扣減** → 在使用日誌中排查具體呼叫記錄，確認是否為正常消耗

<Callout type="idea" title="聯絡支援">
  遇到帳戶異常問題，請通過 [聯絡我們](https://fishxcode.com/contact) 頁面獲取幫助。
</Callout>

## 四、常見問題

### 註冊時收不到驗證碼？

1. 檢查郵箱是否填寫正確（注意拼寫和域名）
2. 檢視垃圾郵件/垃圾箱資料夾
3. 等待 1-2 分鐘後重試，避免頻繁請求
4. 如仍無法收到，嘗試更換郵箱或使用第三方登入

### 令牌建立後在哪裡檢視？

進入 **控制台 → 令牌管理**，已建立的令牌會在列表中顯示。點選複製按鈕即可獲取 `sk-xxx` 格式的 API Key。

### 充值未到賬怎麼辦？

1. 確認支付是否成功（檢視支付寶/微信的交易記錄）
2. 等待 1-5 分鐘，系統可能存在短暫延遲
3. 重新整理控制台錢包頁面
4. 如超過 10 分鐘仍未到賬，請聯絡官方客服並提供支付截圖

### 如何檢視消費明細？

進入 **控制台 → 使用日誌**，可檢視每次 API 呼叫的：

- 呼叫時間和模型名稱
- Token 消耗量和費用
- 請求 IP 和詳細記錄
