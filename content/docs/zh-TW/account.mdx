## 一、註冊與登入

### 1. 註冊帳號

造訪 [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW)，進入註冊頁：

![FishXCode 註冊頁](/img/start/api-v2-01-home.png)

填寫註冊表單：設定使用者名稱、密碼（8–128 個字元，建議包含大小寫字母、數字和符號），並填寫用於接收驗證碼的電子郵件：

![填寫註冊資訊](/img/start/api-v2-03-register-form.png)

<Callout type="idea" title="支援的電子郵件網域">
  電子郵件註冊目前支援 **qq.com、126.com、163.com、gmail.com** 四個網域，其他網域可能無法接收驗證碼。
</Callout>

點選**傳送驗證碼**，完成 Cloudflare 人機驗證後，驗證碼會寄到你的信箱。在收件匣中找到驗證碼（6 位英數組合），填入表單：

![輸入電子郵件驗證碼](/img/start/api-v2-02-register-verify.png)

點選**建立帳戶**完成註冊，頁面會跳轉到登入頁並提示「帳戶已建立！請登入」。

<Callout type="warn" title="收不到驗證碼？">
  1. 確認電子郵件網域在支援清單內（qq.com / 126.com / 163.com / gmail.com）
  2. 查看垃圾郵件資料夾
  3. 等待 1–2 分鐘後重試，避免頻繁請求
  4. 如仍無法收到，改用第三方授權登入
</Callout>

### 2. 登入

註冊完成後使用使用者名稱和密碼登入，也可以使用第三方帳號一鍵授權登入：

![登入頁面](/img/start/api-v2-04-login.png)

| 登入方式 | 說明 |
| - | - |
| 電子郵件註冊帳號 | 使用者名稱/電子郵件 + 密碼登入 |
| GitHub | 授權登入，推薦開發者使用 |
| LinuxDO | 社群使用者授權登入 |
| Google | Google 帳號授權登入 |

<Callout type="info" title="第三方授權即註冊">
  使用 GitHub / LinuxDO / Google 首次授權登入時會自動建立帳號，無需另外註冊。
</Callout>

登入後進入控制台（概覽頁）：

![控制台概覽](/img/start/api-v2-05-console.png)

## 二、取得 API Key

### 1. 建立 API 金鑰

進入**控制台 → API 金鑰**，點選右上角**建立 API 金鑰**：

![建立 API 金鑰彈窗](/img/start/api-v2-06-token-create.png)

表單欄位說明：

| 欄位 | 說明 |
| - | - |
| 名稱 | 自訂金鑰名稱，便於識別用途 |
| 分組 | 決定可用模型與消費倍率，見下方說明 |
| 到期時間 | 永不 / 1 個月 / 1 天 / 1 小時 |
| 數量 | 可一次批次建立多個（名稱自動加隨機後綴） |
| 無限配額 | 預設開啟；關閉後可限制該金鑰的最大消耗額度 |
| 進階設定 | IP 白名單（支援 CIDR）、允許查詢使用者額度 |

- **分組**建議選擇 **claude**（1.5x），該分組為 Claude Max 20 官方正價號池、滿血效能。使用 Codex 月包時必須選 `codex-sub-june`。全部分組和倍率見 [計費規則與分組](/zh-TW/billing-groups)。
- **IP 白名單**適合伺服器固定出口 IP；本機開發請謹慎使用，IP 變動後會導致無法呼叫。

點選**儲存變更**完成建立。在金鑰列表點選**複製**按鈕取得 API Key（格式為 `sk-xxx`）：

![複製 API 金鑰](/img/start/api-v2-07-token-copy.png)

<Callout type="idea" title="API 位址">
  點選頁面右上角 **API 位址** 可查看接入位址。控制台預設顯示 `https://fishxcode.com`；`https://api.fishxcode.com` 同樣可用，兩者行為一致，任選其一。
</Callout>

### 2. 儲值

進入**控制台 → 錢包**，頁面分**餘額儲值**和**訂閱方案**兩個分頁：

![錢包餘額儲值](/img/start/api-v2-08-wallet.png)

**餘額儲值**：選擇預設金額（$1 / $5 / $10 / $100 / $500 / $1,000，大額有 1%–3% 優惠）或輸入自訂金額，然後選擇付款方式：

![付款方式與兌換碼](/img/start/api-09-payment.png)

| 方式 | 說明 |
| - | - |
| 支付寶（alipay） | 主流儲值方式，無最低限額 |
| Waffo Pancake | 最低儲值 $100 |
| 兌換碼 | 在「有兌換碼嗎？」區域輸入後點選**兌換額度** |

**訂閱方案**：購買 Codex 號池月包（$20 / $200 / $2,000 三檔額度），購買後用 `codex-sub-june` 分組建立金鑰使用，詳見 [訂閱方案](/zh-TW/subscription-plans)：

![訂閱方案分頁](/img/start/api-10-subscription.png)

<Callout type="idea" title="新使用者好禮">
  新註冊帳號會自動獲得 **$0.2** 試用餘額，可直接用來測試 API 呼叫。
</Callout>

<Callout type="idea" title="倍率說明">
  分組名稱中的倍率表示消費係數，數值越小同一請求扣費越少。如 `0.5x` 分組消費 1 元相當於官方原價 2 元的 Token 量。詳見 [計費規則與分組](/zh-TW/billing-groups)。
</Callout>

## 三、帳戶安全

進入**控制台 → 安全與存取**管理帳戶安全設定：

![安全與存取頁面](/img/start/api-12-security.png)

| 功能 | 說明 |
| - | - |
| 變更密碼 | 定期更換，8 位以上、含大小寫字母和數字 |
| 帳戶綁定 | 綁定 GitHub / LinuxDO / Google 後可一鍵授權登入 |
| 登入工作階段 | 查看目前登入裝置，可遠端登出其他工作階段 |
| 存取權杖 | 呼叫面板 API 時使用，依權限勾選建立 |
| Passkey 登入 | 通行金鑰登入，免密碼 |
| 兩步驟驗證 | 為帳戶增加額外安全層 |

### 金鑰安全建議

- **定期輪替**：建議每 30–90 天更換一次金鑰，降低外洩風險
- **不要明文儲存**：避免將 API Key 直接寫入程式碼或提交到 Git 儲存庫，建議使用環境變數
- **權限最小化**：為不同專案建立獨立的金鑰，便於管理和追蹤
- **外洩處理**：如果懷疑金鑰外洩，立即在 **API 金鑰** 頁面刪除該金鑰並建立新的

<Callout type="warn" title="注意">
  刪除金鑰無法復原，刪除後該金鑰立即失效，使用它的工具將無法繼續呼叫。
</Callout>

## 四、常見問題

### 註冊時收不到驗證碼？

1. 確認電子郵件網域在支援清單內（qq.com / 126.com / 163.com / gmail.com）
2. 查看垃圾郵件/垃圾匣資料夾
3. 等待 1–2 分鐘後重試，避免頻繁請求
4. 如仍無法收到，改用 GitHub / LinuxDO / Google 第三方授權登入

### API 金鑰建立後在哪裡查看？

進入 **控制台 → API 金鑰**，已建立的金鑰會顯示在列表中。點選複製按鈕即可取得 `sk-xxx` 格式的 API Key。

### 儲值未入帳怎麼辦？

1. 確認付款是否成功（查看支付寶等通路的交易紀錄）
2. 等待 1–5 分鐘，系統可能存在短暫延遲
3. 重新整理控制台錢包頁面
4. 如超過 10 分鐘仍未入帳，請透過 [聯絡我們](https://fishxcode.com/contact) 提供付款紀錄取得協助

### 如何查看消費明細？

進入 **控制台 → 使用日誌**，可查看每次 API 呼叫的：

- 呼叫時間和模型名稱
- Token 消耗量和費用
- 請求 IP 和詳細紀錄

更多日誌類型（稽核日誌、任務日誌）可在側邊欄切換查看。
