> 首次使用？請先完成 [帳戶註冊與充值](/zh-TW/account)，並在 [FishXCode 控制台](https://fishxcode.com/keys) 獲取 API Key。

## 一、開啟 WorkBuddy 配置檔案

WorkBuddy 支援通過本地 `models.json` 接入自定義模型。配置檔案位置：

- macOS / Linux：`~/.workbuddy/models.json`
- Windows：`C:\Users\<使用者名稱>\.workbuddy\models.json`

如果目錄或檔案不存在，請先建立。

## 二、配置 FishXCode 第三方模型

WorkBuddy 的第三方模型配置使用 OpenAI Chat Completions 相容協議。這裡的 `vendor: "OpenAI"` 表示介面協議，不代表模型只能是 OpenAI 模型；Claude 模型也可以通過 FishXCode 的 OpenAI 相容介面呼叫。

將下面內容寫入 `~/.workbuddy/models.json`：

```json
{
  "models": [
    {
      "id": "gpt-6.2-sol",
      "name": "FishXCode GPT-5.5",
      "vendor": "OpenAI",
      "url": "https://api.fishxcode.com/v1/chat/completions",
      "apiKey": "sk-你的FishXCode-Token",
      "maxInputTokens": 200000,
      "maxOutputTokens": 8192
    },
    {
      "id": "claude-opus-5-5",
      "name": "FishXCode Claude Opus 4.7",
      "vendor": "OpenAI",
      "url": "https://api.fishxcode.com/v1/chat/completions",
      "apiKey": "sk-你的FishXCode-Token",
      "maxInputTokens": 200000,
      "maxOutputTokens": 8192
    }
  ],
  "availableModels": [
    "gpt-6.2-sol",
    "claude-opus-5-5"
  ]
}
```

<Callout type="warn" title="重要">
  - 請將 `sk-你的FishXCode-Token` 替換為你在 FishXCode 控制台建立的實際 API Key。
  - `availableModels` 必須包含上面 `models[].id` 中的模型 ID，否則 WorkBuddy 可能不會在下拉式清單中顯示。
  - `url` 需要填寫完整 Chat Completions 地址：`https://api.fishxcode.com/v1/chat/completions`。
</Callout>

## 三、保留騰訊 Token Plan 與 FishXCode

如果你還需要保留騰訊官方 Token Plan，可以把官方模型和 FishXCode 模型放在同一個 `models.json` 中：

```json
{
  "models": [
    {
      "id": "tc-code-latest",
      "name": "Auto",
      "vendor": "OpenAI",
      "url": "https://api.lkeap.cloud.tencent.com/plan/v3/chat/completions",
      "apiKey": "your-token-plan-api-key",
      "maxInputTokens": 100000,
      "maxOutputTokens": 4096
    },
    {
      "id": "hunyuan-2.0-instruct",
      "name": "Tencent HY 2.0 Instruct",
      "vendor": "OpenAI",
      "url": "https://api.lkeap.cloud.tencent.com/plan/v3/chat/completions",
      "apiKey": "your-token-plan-api-key",
      "maxInputTokens": 100000,
      "maxOutputTokens": 4096
    },
    {
      "id": "gpt-6.2-sol",
      "name": "FishXCode GPT-5.5",
      "vendor": "OpenAI",
      "url": "https://api.fishxcode.com/v1/chat/completions",
      "apiKey": "sk-你的FishXCode-Token",
      "maxInputTokens": 200000,
      "maxOutputTokens": 8192
    },
    {
      "id": "claude-opus-5-5",
      "name": "FishXCode Claude Opus 4.7",
      "vendor": "OpenAI",
      "url": "https://api.fishxcode.com/v1/chat/completions",
      "apiKey": "sk-你的FishXCode-Token",
      "maxInputTokens": 200000,
      "maxOutputTokens": 8192
    }
  ],
  "availableModels": [
    "tc-code-latest",
    "hunyuan-2.0-instruct",
    "gpt-6.2-sol",
    "claude-opus-5-5"
  ]
}
```

## 四、重啟並驗證

1. 儲存 `models.json`
2. 完全退出 WorkBuddy
3. 重新啟動 WorkBuddy
4. 開啟模型選擇區域
5. 選擇 `gpt-6.2-sol` 或 `claude-opus-5-5`
6. 傳送一個簡單問題驗證響應

## 常見問題

### 看不到新增模型

優先檢查 `availableModels` 是否包含對應模型 ID，再檢查 `models.json` 是否為合法 JSON。

### 呼叫失敗或紅色異常

請檢查 `url` 是否為完整地址 `https://api.fishxcode.com/v1/chat/completions`，不要只填寫 `https://api.fishxcode.com/v1`。

### 鑑權失敗

請重新複製控制台中的 API Key，確認沒有多餘空格或換行。
