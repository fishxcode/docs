FishXCode 平臺支援來自多個供應商的 AI 模型，覆蓋不同的使用場景和工具鏈。你可以根據實際需求自由選擇和切換模型。

<ModelCatalog />

## 切換模型

### Claude Code

通過環境變數設定主模型：

```bash tab="Linux/macOS"
export ANTHROPIC_MODEL=claude-fable-5-2
claude
```

```powershell tab="Windows PowerShell"
$env:ANTHROPIC_MODEL = "claude-fable-5-2"
claude
```

### Codex

編輯 `~/.codex/config.toml`，修改 `model` 欄位：

```toml
model = "gpt-6.2-sol"
```

### RooCode / Qwen Code

在提供商配置中直接修改 **Model** 欄位即可。支援填寫上述任何相容模型的 ID。
