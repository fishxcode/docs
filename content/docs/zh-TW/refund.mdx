**生效日期：2026年11月24日**

本政策適用於 FishXCode 平臺內的充值餘額退款與 Codex 套餐折算。若本政策與其他頁面存在不一致，以本政策為準。

## 一、適用範圍

- **充值餘額退款**：適用於使用者主動充值形成的帳戶餘額。
- **Codex 套餐折算**：適用於仍在有效期內、且滿足折算條件的 Codex 套餐。

## 二、充值餘額退款

- 使用者主動充值形成的帳戶餘額，支援按 **1:1** 退回至原支付方式。
- 退款過程中產生的支付通道手續費、銀行手續費或其他相關費用，由使用者自行承擔。
- 原路退款的到賬時間，以對應支付渠道、銀行或支付機構的實際處理時效為準。
- 如遇支付渠道限制、帳戶異常或風控稽核，平臺可能要求使用者補充身份或訂單資訊後處理。

## 三、Codex 套餐退款與折算

對符合條件的 Codex 套餐，平臺將按照以下規則計算可返還額度，並支援退回帳戶餘額或原支付方式。具體退款路徑以系統實際支援情況、支付渠道能力及稽核結果為準。

### 1. 計算公式

**可退金額 = 套餐折算基價 -（從計費生效至申請退款時的總計 Token 消耗 × 按量消耗比例）**

其中：

- **套餐折算基價**：以對應支付訂單的實付金額為準
- **總計 Token 消耗**：指從套餐計費生效開始至提交退款申請時，套餐項下實際發生的累計 Token 消耗
- **按量消耗比例**：指申請退款時系統對對應模型、分組或服務生效的按量計費換算標準
- 若計算結果小於 **0**，則按 **0** 處理
- 如退回帳戶餘額，最終結果將按照系統當時生效的額度換算規則轉換為帳戶餘額

### 2. 折算規則

- 僅處理當前仍在有效期內且命中活動範圍的套餐；已過期、已作廢、未命中的套餐不會進入折算。
- 只有能關聯到歷史成功支付訂單的購買套餐才可申請折算；贈送、兌換、後臺補發等沒有支付訂單的套餐不參與折算。
- 每個可折算套餐都會展示對應支付訂單的實付價格，折算基價以該訂單實付金額為準。
- Codex 套餐的退款與折算，基於套餐實際使用情況按量核算，不再按固定週期天數平均折算。
- 平臺將以申請退款時可核驗的累計 Token 消耗記錄、當時生效的按量計費標準及相關係統規則，綜合核定可退金額。
- 鑑於計費價格可能隨市場與服務成本變化而調整，Codex 套餐相關的退款、折算申請或費用爭議，平臺可結合申請時的市場價格與系統規則進行處理。

### 3. 提交與稽核規則

- 提交申請後，命中的舊套餐會立即暫時停用，等待管理員稽核期間將無法繼續使用這些套餐權益。
- 稽核通過後，系統將按稽核結果退回帳戶餘額或原支付方式，並將這些舊套餐正式作廢；稽核拒絕則恢復原套餐的可用狀態。
- 如退回帳戶餘額，該部分餘額仍按您當前系統適用的標準錢包計費規則扣減，與普通充值餘額一致。
- 該操作提交後不可自行撤銷；如您仍希望繼續使用原套餐權益，請勿提交申請。

## 四、不支援退款或折算的情形

- 已過期、已作廢或不在活動範圍內的套餐。
- 無法關聯到成功支付訂單的套餐或權益。
- 贈送、兌換、後臺補發、活動贈送等非實際支付取得的權益。
- 已明確標註為不可退款的特殊套餐或特殊活動商品。
- 因使用者帳戶異常、欺詐風險、違規使用等情形被限制處理的訂單。

## 五、申請與處理說明

- 使用者應通過平臺提供的退款、折算或售後入口提交申請，並以系統展示的可退範圍、可折算範圍及稽核結果為準。
- 平臺有權基於訂單狀態、支付記錄、套餐狀態、風控結果進行人工或系統稽核。
- 如使用者對稽核結果存在異議，可聯絡平臺客服並提供訂單號、支付記錄和相關說明進行復核。

## 六、政策更新

FishXCode 可根據業務規則、支付通道要求或法律法規更新本政策。更新後的版本將在平臺公示，並自公示或標註生效日期起生效。
