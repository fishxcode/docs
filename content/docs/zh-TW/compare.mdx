## 如何選擇

<Callout type="idea" title="偏好終端工作流">
  如果你習慣在終端中完成所有操作，推薦 **Claude Code** 或 **OpenAI Codex**。兩者都提供流暢的命令列體驗，其中 Claude Code 配置最簡單，Codex 則額外支援 VSCode。
</Callout>

<Callout type="idea" title="偏好 VSCode 圖形化">
  如果你更喜歡在 VSCode 中操作，推薦 **RooCode** 或 **OpenAI Codex**。RooCode 提供純圖形化體驗且配置簡單，Codex 則兼具終端和編輯器兩種模式。
</Callout>

<Callout type="idea" title="追求最簡配置">
  如果你希望最快上手，推薦 **Claude Code**、**RooCode** 或 **Qwen Code**。三者均可在數分鐘內完成配置並開始使用。
</Callout>

<Callout type="idea" title="需要高度自定義">
  如果你需要靈活的模型配置和超大上下文支援，推薦 **Droid CLI**。它支援自定義模型引數，最大可配置 128 萬 Token 上下文。
</Callout>

<Callout type="idea" title="中文開發場景">
  如果你的專案以中文為主，推薦 **Qwen Code**。它對中文程式碼註釋和文件有更好的理解和生成能力。
</Callout>
