**生效日期：2026年2月11日**

FishXCode 嚴格遵守《中華人民共和國個人資訊保護法》、《網路安全法》、《資料安全法》及相關法律法規。

## 一、我們收集哪些資訊及用途

| 場景 | 收集內容 | 用途 |
| - | - | - |
| 帳戶註冊 | 手機號或電子郵箱、密碼、使用者名稱 | 建立帳號、驗證身份、維護帳戶安全 |
| API 使用 | 呼叫時間、請求路徑、消耗 Token 數 | 服務計費、防欺詐和濫用 |
| 裝置與網路 | IP 地址、裝置識別符號、瀏覽器型別、作業系統 | 保障服務安全穩定執行 |
| 支付 | 由第三方（支付寶、微信支付）處理 | 完成交易；FishXCode 不儲存完整銀行卡資訊 |
| 客服溝通 | 聯絡方式、通訊記錄 | 驗證身份、解決問題 |

<Callout type="idea" title="關於模型訓練">
  除非您主動開啟"歷史記錄"或"除錯模式"等可選功能，FishXCode **不會**使用您的輸入或輸出來訓練 AI 模型。
</Callout>

## 二、資訊共享與披露

- **第三方模型提供商**：為響應您的 API 請求，我們必須將輸入內容傳輸給您選擇的提供商（建議您查閱其隱私政策）。
- **授權合作伙伴**：雲服務商、資料分析服務商等，須簽署嚴格的資料保護協議。
- **法律要求**：根據法律法規或政府主管部門要求，我們可能共享資訊。
- 我們**不會出售**您的個人資訊，不會進行未經授權的公開披露。

## 三、資料的跨境傳輸

FishXCode 運營實體位於中國境內，個人資訊儲存在境內。如確需跨境傳輸，將嚴格遵守國家網信部門規定，並依法取得您的單獨同意。

## 四、儲存與安全

- **儲存期限**：僅在實現目的所必需期間及法律要求期限內保留；超期後刪除或匿名化處理。
- **安全措施**：加密、去標識化、訪問控制、定期安全審計。

## 五、您的權利

根據《個人資訊保護法》，您享有以下權利：

- **查閱與複製**：查閱、複製您的個人資訊
- **更正**：更正不準確或不完整的資訊
- **刪除**：在特定情形下申請刪除
- **撤回同意**：隨時撤回基於同意處理的授權
- **登出帳戶**：登出後將停止處理並依法刪除或匿名化個人資訊

行使權利請通過下方聯絡方式提交申請，我們將在 15 個工作日內答覆（可能需要身份驗證）。

## 六、未成年人保護

我們的服務主要面向成年人，**不會故意收集未成年人的個人資訊**。如發現未成年人未經監護人同意提供了個人資訊，請立即聯絡我們。

## 七、政策更新

若變更實質性影響您的權利，我們將通過網站顯著位置公告或向註冊郵箱傳送通知告知您。
