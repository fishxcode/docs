Codex 系列按 **額度 + 有效期** 管理，常見形態包括包月、包周、包日。購買後系統會自動生成對應的套餐訪問令牌，可直接使用，也可以在令牌管理中基於套餐建立子令牌給團隊或他人使用。

檢視當前在售 [Codex 系列套餐](https://fishxcode.com/pricing?currency=CNY&tab=subscription-plans&plan_series=codex)

## 一、套餐說明

- 套餐包含可用額度和有效期。
- 到期後套餐權益失效。
- 額度是否按日、按周、按月或自定義週期重置，以套餐配置為準。可在套餐管理取消每日套餐使用限制，消耗總額度。
- 支援團隊管理和多人使用。不同額度的套餐適用於不同規模和使用強度的團隊。
- 團隊或他人通過基於套餐建立的令牌呼叫時，會一併計入套餐總額度。
- 套餐可提供發票。

## 二、計費口徑

- **套餐額度**：套餐內可使用的額度總量或週期額度。
- **有效期**：包月、包周、包日等時間限制。
- **重置規則**：可以不重置，也可能按天、周、月或自定義週期重置。
- **適用範圍**：套餐可用的模型、分組和介面型別，以套餐頁為準。
- **令牌消耗**：自動生成的套餐令牌，以及基於套餐建立的團隊令牌，都會消耗該套餐額度。

## 三、購買前確認

- 套餐有效期。
- 套餐總額度和週期額度。
- 當前工具使用的模型是否在套餐範圍內。
- 套餐權益、可用模型、分組、重置規則和售後規則。
- 套餐額度是否匹配團隊規模、成員數量和預期使用強度。
- 是否需要給團隊成員或其他服務單獨建立令牌，並設定令牌額度和過期時間。

## 四、購買和續費入口

[codex系列套餐](https://fishxcode.com/pricing?currency=CNY&tab=subscription-plans&plan_series=codex)

使用者可以在 **套餐管理列表** 和 **套餐管理詳情** 中購買 Codex 系列套餐。進入購買頁後，先確認套餐權益、有效期、額度、開放購買時間、支付方式和購買須知，再完成支付。

![購買訂閱套餐示例](/img/plans/buyplan.png)

續費需要同時滿足以下條件：

- 套餐仍然有效。
- 套餐未下架。
- 套餐開啟了可續費。
- 當前時間處於套餐允許的續費視窗內。

通常情況下，套餐到期前 3 天內可以續費；套餐到期後令牌不可用，需要重新購買或聯絡售後處理。具體續費視窗以套餐頁面展示為準。

## 五、優惠碼

如果有優惠碼，可以在購買時輸入並校驗。優惠碼只在校驗通過且當前支付方式支援時生效；以購買頁最終展示的應付金額和優惠規則為準。

## 六、支付後自動生成套餐令牌

支付成功後，系統會在 [控制台 → 令牌管理](https://fishxcode.com/console/token) 自動生成一個套餐訪問令牌。令牌名稱字首為：

```text
Subscription Access - 套餐id
```

該令牌會繫結本次購買的套餐，用於消耗套餐額度和繼承套餐有效期、分組、模型限制等規則。

![令牌管理中的套餐令牌示例](/img/plans/tokens.png)

## 七、基於套餐建立團隊令牌

購買者可以在 [控制台 → 令牌管理](https://fishxcode.com/console/token) 基於套餐建立新的令牌，用於團隊成員、專案服務或其他使用方。

建立時重點確認：

- **基於套餐建立**：選擇對應的訂閱套餐。
- **名稱**：用於區分成員、專案或服務。
- **令牌分組**：預設使用使用者分組，也可以按管理需要選擇分組。
- **過期時間**：控制該令牌可使用到什麼時候。
- **新建數量**：批次建立時會在名稱後自動新增隨機字尾。
- **套餐令牌額度**：限制該令牌最多可消耗的套餐額度。

團隊令牌的消耗會計入原套餐總額度。建議給不同成員、專案或服務建立獨立令牌，便於後續按令牌統計、限制和排查。

![基於套餐建立令牌示例](/img/plans/create.png)

## 八、檢視使用日誌和團隊指標

套餐令牌和團隊令牌的使用記錄可以在 [控制台 → 使用日誌](https://fishxcode.com/console/log) 查詢。排查單次請求時，優先按時間、模型、Token、分組、請求 ID 或狀態碼篩選；欄位含義可參考 [錯誤日誌說明](/zh-TW/error-logs)。

團隊相關指標可以在 **使用日誌 → 分組健康狀態** 檢視。該檢視可以按分組、使用者、令牌維度統計請求數、成功率、消耗、快取命中、平均耗時和最近請求時間，適合判斷套餐下不同團隊成員或服務的使用情況。詳細欄位說明可參考 [分組健康狀態](/zh-TW/group-health)。

![分組健康狀態示例](/img/plans/statistics.png)

## 九、到期與上限

套餐時間過期後，該套餐關聯的自動生成令牌和基於套餐建立的團隊令牌都會不可用。

達到週期額度上限後，可以在套餐管理中取消套餐上限，讓後續請求繼續消耗套餐總額度。是否可取消、取消後如何生效，以套餐管理頁面展示為準。

如果已經消耗完套餐總額度，建議聯絡我們進行直接續費，優先沿用當前套餐和原有令牌。直接續費可以避免重新購買套餐後生成新的 Key，減少團隊成員、專案服務和客戶端配置中的 Key 更新成本。

仍在續費視窗內且套餐支援續費時，可以續費當前套餐；不滿足續費條件時，需要重新購買或聯絡售後確認是否可直接續費。

## 十、退款說明

退款規則以購買頁、套餐說明和 [退款政策](/zh-TW/refund) 為準。遇到交付、令牌或額度異常時，請提供訂單號、套餐名稱、令牌名稱、請求時間和請求 ID，便於排查。
