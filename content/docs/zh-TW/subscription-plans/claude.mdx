Claude 系列通過 [ClaudeMax](https://claudemax.fishxcode.com/) 提供 Claude Max 訂閱協助和 Claude Code 託管服務。它面向想穩定使用 Claude Code 的中文開發者，解決支付、帳號狀態、網路和本地環境配置問題。

## 一、解決的核心問題

很多使用者不是不會用 Claude Code，而是卡在開通和穩定使用前的基礎條件：

- **美區支付門檻**：沒有 SSN / ITIN，國內卡容易風控，找代付費率高且不穩定。
- **帳號狀態不穩定**：自行註冊或臨時渠道可能遇到風控、訂閱中斷、售後不清晰，影響長期開發節奏。
- **網路訪問不穩定**：Anthropic 直連可能出現 `403`、超時或連線質量波動，VPS 預設線路也可能對 API 不穩定。

ClaudeMax 的處理方式是：代為完成 Claude Max 訂閱，預裝 Claude Code 環境，配置低延遲中轉，並提供本地專案掛載工具。使用者拿到連線資訊後，通過 SSH 進入伺服器即可開始使用 Claude Code。

## 二、套餐說明

- 這是官方號訂閱權益，不是普通餘額按量扣費。
- 套餐面向 Claude Code 使用場景，包含 Claude Max 訂閱協助、海外伺服器、低延遲中轉和 Claude Code 環境。
- 常見套餐包括 ClaudeMax x5 和 ClaudeMax x20。個人使用通常選擇 ClaudeMax x5；團隊、重度使用、長會話和團隊 PoC 通常選擇 ClaudeMax x20。
- 帳號個人獨享，不與他人共用；用量歸購買者使用。
- 可支援本地專案掛載，便於原生代碼與伺服器程式碼雙向同步。
- 支援開具發票。
- 可用模型、次數、有效期、交付方式、開通時間、售後和保障規則，以購買頁展示為準。

## 四、訂閱流程

1. 開啟 [ClaudeMax](https://claudemax.fishxcode.com/) 或 FishXCode 訂閱套餐頁。
2. 選擇 ClaudeMax x5、ClaudeMax x20 或頁面展示的其他 Claude 系列套餐。個人使用優先看 x5；團隊或重度使用優先看 x20。
3. 確認套餐包含內容、有效期、帳號保障、開通方式、發票和售後規則。
4. 完成支付。
5. 按頁面、站內通知或客服訊息獲取交付資訊。常見交付內容包括伺服器連線方式、SSH 使用方式、卡密或其他開通說明。
6. 使用 SSH 進入托管伺服器，執行預裝的 Claude Code 環境開始開發。
7. 如需編輯本地專案，可按頁面說明使用本地專案掛載工具，將原生代碼與伺服器環境同步。

標註為人工發放或需提前預定的套餐，需要等待管理員處理。頁面展示的 30 分鐘內開通、提前預定聯絡等說明，以購買頁實際狀態為準。大量訂購請提前預約聯絡，避免庫存、伺服器和帳號交付排期影響使用。

## 五、與自己訂閱的區別

| 專案 | 自己訂閱 Claude Max | ClaudeMax |

| Claude Code 環境 | 自己安裝、維護和排障 | 伺服器環境預裝，SSH 直連使用 |

| 帳號狀態 | 官方規則和帳號異常自行處理 | 按頁面規則提供帳號異常或訂閱中斷保障 |
| 成本結構 | 官方訂閱費之外，還可能需要伺服器和中轉成本 | 套餐價格包含 Max 訂閱、伺服器和中轉 |

## 七、適用場景

- 不方便使用美區支付或海外帳號條件的開發者。
- 想快速使用 Claude Code，不想自己安裝和維護環境的使用者。
- 需要更穩定網路連線和低延遲訪問 Anthropic 的使用者。
- 需要本地專案掛載、遠端編輯和長期開發環境的個人或小團隊。
- 希望有發票、售後和帳號異常保障的企業或團隊使用者。

## 八、安全性和伺服器交付

ClaudeMax 交付的是獨立伺服器環境和帳號使用環境，使用者通過 SSH 進入伺服器使用 Claude Code。若對應伺服器支援轉讓，可以按售後規則協助轉讓伺服器或使用權，具體以實際交付形態和頁面說明為準。

請妥善保管伺服器連線資訊、卡密、帳號資訊和相關憑證，不要公開轉發給無關人員。

## 九、轉讓、封號和退款

- Claude 系列按 Claude 工具鏈和 ClaudeMax 託管服務使用，不按通用餘額處理。
- 不同套餐對應的帳號權益、使用強度、穩定性保障和可用模型可能不同。
- 套餐交付後請妥善儲存連線資訊、卡密、帳號資訊或相關憑證，不要公開轉發。
- 如果伺服器、訂閱狀態或帳號狀態異常，請按頁面售後規則聯絡支援處理。

轉讓規則：

- 首次轉讓免費。
- 第二次及以後轉讓，每次收取 50 元伺服器費用。
- 是否可轉讓，取決於具體伺服器、帳號和交付形態；以客服確認結果為準。

封號和退款規則：

- 如果帳號異常或封號符合保障範圍，可以按剩餘未使用天數比例退款。
- 示例：套餐已使用 10 天，剩餘 20 天，則按剩餘 20 天對應額度退款。
- 如果希望繼續使用，可以補齊已使用 10 天對應的費用，由我們重新開新號繼續交付。
- 如果因非法用途、違規使用或不合理使用導致封禁，不予退款。請合理、正規使用 ClaudeMax 和 Claude Code。
