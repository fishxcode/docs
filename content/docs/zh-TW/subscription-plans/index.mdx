## 一、套餐分類

| 系列 | 入口 | 說明 |
| - | - | - |
| Claude 系列 | [Claude 系列](/zh-TW/subscription-plans/claude) | ClaudeMax 官方號訂閱與 Claude Code 託管服務 |
| Codex 系列 | [Codex 系列](/zh-TW/subscription-plans/codex) | 按額度和有效期管理，適合個人或團隊按額度使用 |
| 按次系列 | [按次系列](/zh-TW/subscription-plans/by-number-of-times) | 按成功請求次數累計，支援 Claude、Codex 相關模型 |

## 二、規則摘要

- Claude 系列是官方號訂閱，購買入口見 [Claude 系列](/zh-TW/subscription-plans/claude)。
- Codex 系列是按量額度 + 有效期限制，不是單純按次售賣。
- 按次系列是按次套餐，日上限、月上限和總次數以套餐配置為準，可用於對應的 Claude 和 Codex 系列模型。
- Claude Opus 4.8 和 GPT-5.5 在按次數系列中按 `2.5 × 實際成功請求次數` 累計。
- 如果需要理解模型價格、令牌分組、倍率和套餐適用範圍之間的關係，請先看 [站點計費規則與分組簡介](/zh-TW/billing-groups)。

## 三、購買流程

1. 開啟 [定價頁](https://fishxcode.com/pricing?currency=CNY&tab=subscription-plans)。
2. 切換到“訂閱套餐”。
3. 按系列篩選 Claude、Codex 或 按次套餐。
4. 檢視套餐詳情，確認價格、有效期、額度、次數、適用模型、重置規則和購買限制。
5. 支付後，在控制台的套餐或訂閱頁面檢視狀態。
6. 如套餐生成獨立 Key，按頁面提示覆制 Base URL 和 Key，並配置到對應工具中。

## 四、說明

### 價格以定價頁為準

套餐價格、庫存、限購、優惠和可售狀態會調整。文件只寫規則，具體價格以官網定價頁為準。

### 按次不等於所有模型都按 1 次扣

By number of times 系列以成功請求次數為基礎。Claude Opus 4.8 和 GPT-5.5 按 `2.5 × 實際成功請求次數` 累計。

### Codex 系列和 By number of times 系列的區別

Codex 系列看額度和有效期；By number of times 系列看請求次數、每日上限、每月上限和總次數。

### 到期、用完或達到上限

達到有效期、總額度、總次數、每日上限或每月上限後，系統按套餐規則限制繼續使用。後續可等待週期重置、購買新套餐，或改用餘額。

### 使用異常

先確認套餐有效期、當日或當月上限、模型適用範圍。再檢視 [錯誤日誌說明](/zh-TW/error-logs) 和 [分組健康狀態](/zh-TW/group-health)。聯絡售後時請提供訂單號、請求時間和請求 ID。
