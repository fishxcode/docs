Codex Pro 號池月包基於 Codex Pro 官方號池，按固定額度按月購買，適合高頻 Codex 程式設計與 Agent 開發。目前在售的套餐只有這一個系列，提供三檔：

| 套餐 | 售價 | 套餐額度 | 實際成本倍率 | 有效期 | 額度重置 | 適合 |
| - | - | - | - | - | - | - |
| 2000 美元額度月包 | $260 | $2,000 | 0.13x | 1 個自然月 | 不重置 | 高頻開發與企業團隊 |
| 200 美元額度月包 | $30 | $200 | 0.15x | 1 個自然月 | 不重置 | 中等額度，日常開發優選 |
| 20 美元額度月包 | $3.60 | $20 | 0.18x | 1 個自然月 | 不重置 | 入門體驗，靈活使用 |

價格與可售狀態以 [定價頁](https://fishxcode.com/pricing) 為準。

## 購買後如何使用

1. 購買對應額度的 Codex 月包套餐。
2. 在控制台選擇 `codex-sub-june` 分組。
3. 使用該分組新建 API 令牌。
4. 將令牌配置到支援的客戶端即可使用，例如 [Codex](/zh-TW/codex)、[Codex Desktop](/zh-TW/codex-desktop)。

## 計費規則

- `codex-sub-june` 分組固定為 **1x 倍率**。
- 實際成本倍率 = 套餐售價 ÷ 套餐額度。
- 請求按實際 Token 消耗扣減套餐額度。
- 套餐有效期為 1 個自然月。
- 套餐額度不重置，未使用額度不會自動續期。

<Callout type="idea" title="例子">
  $260 購買 $2,000 額度，實際成本倍率為 **0.13x**，但分組顯示的倍率仍然是 1x。
</Callout>

## 注意事項

<Callout type="warn" title="只有 codex-sub-june 分組能用月包額度">
  Codex 月包必須使用 `codex-sub-june` 分組建立令牌，其他分組不適用該套餐額度。
</Callout>

- 月包不是無限額度，額度耗盡或套餐到期後將無法繼續使用。
- 不想買月包時，也可以用餘額按量呼叫 Codex 系列分組，見 [計費規則與分組](/zh-TW/billing-groups)。
