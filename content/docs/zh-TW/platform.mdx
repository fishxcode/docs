## 一、平臺概述

FishXCode 是一個面向開發者和團隊使用的 AI 接入平臺。你可以把它理解成一個統一入口：前面是官網、定價和文件，後面是控制台、令牌、充值、發票和使用記錄。

平臺圍繞主流 AI 模型提供中轉服務，具體渠道和模型以官網實際為準，請前往 [定價頁](https://fishxcode.com/pricing) 檢視。使用者從註冊開始，到建立令牌、選擇套餐、接入工具、檢視消耗，整套流程都在同一個系統裡完成。

## 三、控制台功能速查

登入後所有操作集中在控制台，可按使用場景快速定位：

### 開通使用

1. 註冊帳號 → 登入控制台
2. **令牌管理**：建立 API Key（選擇合適的分組）
3. 將 Base URL 和 API Key 配置到你的工具中

### 購買與充值

- **套餐管理**：檢視可用套餐，訂閱適合的方案
- **充值頁面**：支援支付寶、微信和兌換碼
- **餘額檢視**：Dashboard 首頁即時顯示

### 使用管理

- **使用日誌**：檢視每次呼叫記錄，包含模型、消耗、IP 等詳情
- **令牌管理**：檢視令牌狀態、分組範圍，刪除不再使用的令牌
- **個人設定**：修改預設分組、檢視簽到獎勵和基礎統計

### 售後與支援

- **發票管理**：企業或有報銷需求的使用者提交開票申請
- **邀請返利**：通過邀請連結拉新並檢視獎勵收益
- **服務狀態**：排查呼叫異常時檢視各分組是否正常
- **聯絡我們**：處理使用問題、採購溝通和售後支援
