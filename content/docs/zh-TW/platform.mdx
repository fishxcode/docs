## 一、平台概述

FishXCode 是一個面向開發者和團隊使用的 AI 接入平台。你可以把它理解成一個統一入口：前面是官網、定價和文件，後面是控制台、金鑰、儲值、發票和使用紀錄。

平台圍繞主流 AI 模型提供中轉服務，具體通路和模型以官網實際為準，請前往 [定價頁](https://fishxcode.com/pricing) 查看。使用者從註冊開始，到建立金鑰、接入工具、查看消耗，整套流程都在同一個系統裡完成。

## 三、控制台功能速查

登入後所有操作集中在控制台，可依使用情境快速定位：

### 開通使用

1. 註冊帳號 → 登入控制台
2. **API 金鑰**：建立 API Key（選擇合適的分組）
3. 將 Base URL 和 API Key 設定到你的工具中

### 購買與儲值

- **錢包 → 餘額儲值**：支援支付寶、Waffo Pancake 和兌換碼
- **餘額查看**：錢包頁與概覽頁即時顯示

### 使用管理

- **使用日誌**：查看每次呼叫紀錄，包含模型、消耗、IP 等詳情
- **API 金鑰**：查看金鑰狀態、分組範圍，刪除或停用不再使用的金鑰
- **個人資料**：查看每日登入獎勵和基礎統計

### 售後與支援

- **邀請回饋**：錢包頁底部查看推薦計畫的邀請連結與獎勵收益
- **服務狀態**：排查呼叫異常時查看各分組是否正常
- **聯絡我們**：處理使用問題、採購溝通和售後支援
