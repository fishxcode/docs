## 平台說明

Claude Code 使用 Anthropic 相容協定接入。若該用戶端提供自訂 Base URL / API Key 欄位，請依上方資訊填寫；基礎網址為 `https://api.fishxcode.com`，若用戶端要求完整位址，再按 `/v1/messages` 等路徑補全。
