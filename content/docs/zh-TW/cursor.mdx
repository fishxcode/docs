navTitle: Cursor
---

> 首次使用？請先完成 [帳戶註冊與充值](/zh-TW/account)，並在控制台獲取 API Key。

## 一、開啟 Cursor 設定

開啟 Cursor，點選右上角設定圖示進入設定頁面。

## 二、進入 Models

在左側選單中點選 **Models**，進入模型與 API 配置區域。

## 三、新增模型並填寫 API Key / Base URL

先點選 **新增模型**，然後在 OpenAI API 配置區域填寫：

- **API Key**：FishXCode 控制台生成的 key
- **Base URL**：`https://api.fishxcode.com/v1`

![Cursor Models 配置示例](/img/start/cursor.png)

圖中標註：

1. 設定入口
2. Models 選單
3. 新增模型
4. API Key 輸入框
5. Base URL 輸入框

## 四、儲存並驗證可用

1. 新建對話
2. 選擇剛啟用的模型
3. 傳送測試提示詞
4. 收到正常響應即接入成功
