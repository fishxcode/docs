## 一、注册与登录

### 1. 注册账号

访问 [fishxcode.com/register](https://fishxcode.com/register?aff=9CTW)，进入注册页：

![FishXCode 注册页](/img/start/api-v2-01-home.png)

填写注册表单：设置用户名、密码（8–128 个字符，建议包含大小写字母、数字和符号），并填写用于接收验证码的电子邮件：

![填写注册信息](/img/start/api-v2-03-register-form.png)

<Callout type="idea" title="支持的邮箱域名">
  邮箱注册当前支持 **qq.com、126.com、163.com、gmail.com** 四个域名，其他域名可能无法接收验证码。
</Callout>

点击**发送验证码**，完成 Cloudflare 人机验证后，验证码会发送到你的邮箱。在收件箱中找到验证码（6 位字母数字组合），填入表单：

![输入邮箱验证码](/img/start/api-v2-02-register-verify.png)

点击**创建账户**完成注册，页面会跳转到登录页并提示「账户已创建！请登录」。

<Callout type="warn" title="收不到验证码？">
  1. 确认邮箱域名在支持列表内（qq.com / 126.com / 163.com / gmail.com）
  2. 查看垃圾邮件文件夹
  3. 等待 1–2 分钟后重试，避免频繁请求
  4. 如仍无法收到，改用第三方授权登录
</Callout>

### 2. 登录

注册完成后使用用户名和密码登录，也可以使用第三方账号一键授权登录：

![登录页面](/img/start/api-v2-04-login.png)

| 登录方式 | 说明 |
| - | - |
| 邮箱注册账号 | 用户名/邮箱 + 密码登录 |
| GitHub | 授权登录，推荐开发者使用 |
| LinuxDO | 社区用户授权登录 |
| Google | Google 账号授权登录 |

<Callout type="info" title="第三方授权即注册">
  使用 GitHub / LinuxDO / Google 首次授权登录时会自动创建账号，无需单独注册。
</Callout>

登录后进入控制台（概览页）：

![控制台概览](/img/start/api-v2-05-console.png)

## 二、获取 API Key

### 1. 创建 API 密钥

进入**控制台 → API 密钥**，点击右上角**创建 API 密钥**：

![创建 API 密钥弹窗](/img/start/api-v2-06-token-create.png)

表单字段说明：

| 字段 | 说明 |
| - | - |
| 名称 | 自定义密钥名称，便于识别用途 |
| 分组 | 决定可用模型与消费倍率，见下方说明 |
| 过期时间 | 永不 / 1 个月 / 1 天 / 1 小时 |
| 数量 | 可一次批量创建多个（名称自动加随机后缀） |
| 无限配额 | 默认开启；关闭后可限制该密钥的最大消耗额度 |
| 高级设置 | IP 白名单（支持 CIDR）、允许查询用户额度 |

- **分组**建议选择 <LiveRatio name="claude" />，该分组为 Claude Max 20 官方正价号池、满血性能。全部分组和倍率见 [计费规则与分组](/billing-groups)。
- **IP 白名单**适合服务端固定出口 IP；本地开发慎用，IP 变化后会导致无法调用。

点击**保存更改**完成创建。在密钥列表点击**复制**按钮获取 API Key（格式为 `sk-xxx`）：

![复制 API 密钥](/img/start/api-v2-07-token-copy.png)

<Callout type="idea" title="API 地址">
  点击页面右上角 **API 地址** 可查看接入地址。控制台默认展示 `https://fishxcode.com`；`https://api.fishxcode.com` 同样可用，两者行为一致，任选其一。
</Callout>

### 2. 充值

进入**控制台 → 钱包**，在**余额充值**标签页充值：

![钱包余额充值](/img/start/api-v2-08-wallet.png)

选择预设金额（$1 / $5 / $10 / $100 / $500 / $1,000，大额有 1%–3% 优惠）或输入自定义金额，然后选择付款方式：

![付款方式与兑换码](/img/start/api-09-payment.png)

| 方式 | 说明 |
| - | - |
| 支付宝（alipay） | 主流充值方式，无最低限额 |
| Waffo Pancake | 最低充值 $100 |
| 兑换码 | 在「有兑换码吗？」区域输入后点击**兑换额度** |

<Callout type="idea" title="新用户福利">
  新注册账号会自动获得 **$0.2** 试用余额，可直接用来测试 API 调用。
</Callout>

<Callout type="idea" title="倍率说明">
  分组名称中的倍率表示消费系数，数值越小同一请求扣费越少。如 `0.5x` 分组消费 1 元相当于官方原价的 2 元 Token 量。详见 [计费规则与分组](/billing-groups)。
</Callout>

## 三、账户安全

进入**控制台 → 安全与访问**管理账户安全设置：

![安全与访问页面](/img/start/api-12-security.png)

| 功能 | 说明 |
| - | - |
| 更改密码 | 定期更换，8 位以上、含大小写字母和数字 |
| 账户绑定 | 绑定 GitHub / LinuxDO / Google 后可一键授权登录 |
| 登录会话 | 查看当前登录设备，可远程退出其他会话 |
| 访问令牌 | 调用面板 API 时使用，按权限勾选创建 |
| Passkey 登录 | 通行密钥登录，免密码 |
| 两步验证 | 为账户添加额外安全层 |

### 令牌安全建议

- **定期轮换**：建议每 30–90 天更换一次密钥，降低泄露风险
- **不要明文存储**：避免将 API Key 直接写入代码或提交到 Git 仓库，推荐使用环境变量
- **权限最小化**：为不同项目创建独立的密钥，便于管理和追踪
- **泄露处理**：如果怀疑密钥泄露，立即在 **API 密钥** 页面删除该密钥并创建新的

<Callout type="warn" title="注意">
  删除密钥操作不可撤销，删除后该密钥立即失效，使用它的工具将无法继续调用。
</Callout>

## 四、常见问题

### 注册时收不到验证码？

1. 确认邮箱域名在支持列表内（qq.com / 126.com / 163.com / gmail.com）
2. 查看垃圾邮件/垃圾箱文件夹
3. 等待 1–2 分钟后重试，避免频繁请求
4. 如仍无法收到，改用 GitHub / LinuxDO / Google 第三方授权登录

### API 密钥创建后在哪里查看？

进入 **控制台 → API 密钥**，已创建的密钥会在列表中显示。点击复制按钮即可获取 `sk-xxx` 格式的 API Key。

### 充值未到账怎么办？

1. 确认支付是否成功（查看支付宝等渠道的交易记录）
2. 等待 1–5 分钟，系统可能存在短暂延迟
3. 刷新控制台钱包页面
4. 如超过 10 分钟仍未到账，请通过 [联系我们](https://fishxcode.com/contact) 提供支付记录获取帮助

### 如何查看消费明细？

进入 **控制台 → 使用日志**，可查看每次 API 调用的：

- 调用时间和模型名称
- Token 消耗量和费用
- 请求 IP 和详细记录

更多日志类型（审计日志、任务日志）可在侧边栏切换查看。
