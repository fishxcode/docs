## 平台说明

Gemini CLI 使用 OpenAI 兼容协议接入。若该客户端提供自定义 Base URL / API Key 字段，请按上方信息填写；若仅支持 OpenAI 兼容端点，请确认接口地址包含 `/v1`。

## 可选：用 CC Switch 一键导入

如果你同时维护多个 Gemini 渠道，可以使用 [CC Switch](https://github.com/farion1231/cc-switch) 做快速切换；如果只使用 FishXCode，上方的环境变量配置通常已经足够。

进入 FishXCode 控制台的 **API 密钥** 页，找到目标密钥所在行，点击右侧 **打开菜单 → CC Switch**：

![在 FishXCode 控制台选择填入 CC Switch](/img/start/gemini-cli/cc-switch-import-channel.png)

控制台会弹出「填入 CC Switch」表单，**应用**选择 `Gemini`，**名称**建议填 `FishXCode`（便于在渠道列表中识别），**主模型**选择 `gemini-3.6-flash`，然后点击 **打开 CC Switch**：

| 字段 | FishXCode 推荐值 |
| - | - |
| 应用 | `Gemini` |
| 名称 | `FishXCode` |
| 主模型 | `gemini-3.6-flash` |

CC Switch 会弹出「确认导入供应商配置」，核对 API 端点为 `https://fishxcode.com`、模型为 `gemini-3.6-flash` 后点击 **导入**：

![在 CC Switch 确认导入 FishXCode 配置](/img/start/gemini-cli/cc-switch-select-model.png)

导入成功后，FishXCode 会出现在供应商列表中：

![FishXCode 导入成功并出现在供应商列表](/img/start/gemini-cli/cc-switch-import-success.png)

<Callout type="warn" title="注意">
  「导入后立即切换到这个供应商」开启时，CC Switch 会改写 Gemini CLI 的本地配置（`~/.gemini/.env`）。切回官方渠道时记得在 CC Switch 里重新选择，避免请求发到不预期的地址。
</Callout>
